### 文章 23：ASP.NET Core 测试：单元测试、集成测试与 WebApplicationFactory

**文件**：`posts/dotnet/aspnet-core-testing.mdx`

**plan.md 覆盖要点**：
- 单元测试（xUnit / NUnit / MSTest）
- Mock（Moq / NSubstitute）
- 集成测试（`WebApplicationFactory`）
- API 测试（HttpClient）
- 数据库测试（Testcontainers / SQLite / InMemory）
- 业务逻辑放 Service 便于测试
- Controller 测试不要过多 Mock
- 关键 API 做集成测试
- 数据库行为不要完全依赖 EF InMemory

**建议结构**：
1. 引言 —— 为什么测试、测试层次
2. 单元测试基础 —— xUnit 项目创建、Fact/Theory、断言
3. Mock 依赖 —— Moq 基础、模拟接口、验证调用
4. Service 层单元测试 —— 完整示例
5. 集成测试与 WebApplicationFactory —— 创建测试 Server、发送 HTTP 请求
6. API 集成测试 —— 完整 CRUD 测试
7. 数据库测试策略 —— SQLite / Testcontainers、EF InMemory 的局限
8. 测试组织与命名
9. 常见问题
10. 总结

### 文章 24：ASP.NET Core 安全基础：CORS、CSRF、限流与安全响应头

**文件**：`posts/dotnet/aspnet-core-security.mdx`

**plan.md 覆盖要点**：
- HTTPS
- CORS
- CSRF
- XSS 基础防护
- SQL 注入防护
- 文件上传安全
- Rate Limiting
- 安全响应头
- 敏感配置管理
- Data Protection
- 密码哈希
- Token 过期与吊销策略

**建议结构**：
1. 引言 —— 安全是系统设计的一部分，不是上线前补丁
2. HTTPS —— 强制 HTTPS、HSTS
3. CORS —— 跨域策略、常见配置错误
4. CSRF —— Cookie 场景下的跨站请求伪造防护
5. XSS 基础防护 —— 输出编码、Content-Security-Policy
6. SQL 注入防护 —— 参数化查询、EF Core 的保护
7. Rate Limiting —— 限流策略、固定窗口/滑动窗口
8. 安全响应头 —— X-Content-Type-Options、X-Frame-Options 等
9. 敏感配置管理 —— 不在代码和日志中暴露密钥
10. Data Protection —— 数据保护 API 基础
11. 密码哈希 —— 不用 MD5/SHA，使用 BCrypt/Argon2
12. 总结
