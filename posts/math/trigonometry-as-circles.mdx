# 三角函数即圆周：图形学数学的第四层基石

前三层我们学会了：函数处理数字，向量处理箭头，矩阵变换空间。但有一种现象这些工具都不太擅长描述——**周期运动**。

物体绕圈转、水面起伏、呼吸灯闪烁、角色手臂摆动……这些"去了又来"的循环，需要一种新工具。三角函数就是这个工具。

但如果你只是死记 $\sin = \frac{\text{对边}}{\text{斜边}}$，你永远不会理解为什么 Shader 里到处都是 `sin`。三角函数的灵魂不在三角形里，在**圆**里。

---

## 一、 核心直觉：三角函数是圆上的投影

想象一个点在单位圆上匀速移动。点的**高度**（y 坐标）随角度变化——这就是 $\sin$。点的**水平位置**（x 坐标）随角度变化——这就是 $\cos$。

$$ \text{圆上的点} = (\cos\theta,\ \sin\theta) $$

$\sin$ 和 $\cos$ 不是两个独立的函数，它们是**同一个圆周运动的两个分量**——水平和垂直。

<ShaderPreview title="sin/cos = 圆上的点" code={`
varying vec2 vUv;
uniform float uTime;

void main() {
    vec2 uv = vUv * 2.0 - 1.0;
    
    vec3 color = vec3(0.05, 0.05, 0.08);
    
    float circle = smoothstep(0.01, 0.003, abs(length(uv) - 0.5));
    color = mix(color, vec3(0.3), circle);
    
    float angle = uTime * 0.8;
    vec2 point = vec2(cos(angle), sin(angle)) * 0.5;
    
    float radius = smoothstep(0.008, 0.002, length(uv - clamp(dot(uv, normalize(point)), 0.0, 0.5) * normalize(point)));
    color = mix(color, vec3(0.8), radius);
    
    float dotP = smoothstep(0.03, 0.01, length(uv - point));
    color = mix(color, vec3(1.0, 0.8, 0.2), dotP);
    
    float projY = smoothstep(0.005, 0.001, abs(uv.x - point.x)) * step(0.0, uv.y) * step(uv.y, point.y);
    float projYLine = smoothstep(0.008, 0.002, abs(uv.x - point.x)) * step(0.0, uv.y - point.y) * step(uv.y, 0.0);
    color = mix(color, vec3(0.2, 0.85, 0.3), max(projY, projYLine));
    
    float projX = smoothstep(0.005, 0.001, abs(uv.y - point.y)) * step(0.0, uv.x) * step(uv.x, point.x);
    float projXLine = smoothstep(0.008, 0.002, abs(uv.y - point.y)) * step(0.0, uv.x - point.x) * step(uv.x, 0.0);
    color = mix(color, vec3(0.9, 0.3, 0.3), max(projX, projXLine));
    
    float axisX = smoothstep(0.005, 0.001, abs(uv.y));
    float axisY = smoothstep(0.005, 0.001, abs(uv.x));
    color = mix(color, vec3(0.2), max(axisX, axisY));
    
    gl_FragColor = vec4(color, 1.0);
}
`} />

:::tip 一句话记住
**$\sin$ = 圆上点的高度，$\cos$ = 圆上点的水平位置。** 两者合起来就是圆上的点坐标 $(\cos\theta, \sin\theta)$。
:::

## 二、 弧度制：GPU 的语言

GPU 内部只认**弧度**，不认角度。

- 角度制：一圈 = 360°
- 弧度制：一圈 = $2\pi$ ≈ 6.283

换算：$\text{弧度} = \text{角度} \times \frac{\pi}{180}$，$\text{角度} = \text{弧度} \times \frac{180}{\pi}$

为什么用弧度？因为弧度有**几何含义**：$\theta$ 弧度 = 单位圆上对应弧的长度。

```glsl
const float PI = 3.14159265;
const float TAU = 6.28318530;
const float HALF_PI = 1.5707963;

float val = sin(uTime);
float val = sin(degrees * PI / 180.0);
```

:::warning 最常见的 Bug
在 Shader 里传入角度值但忘了转弧度。`sin(90.0)` 结果不是 1，而是 `sin(90弧度)` ≈ 0.894。GLSL 没有报错，只是结果完全不对。
:::

## 三、 sin / cos 的图形与波形

把圆上的点"展开"到时间轴上，就得到了波形——$\sin$ 和 $\cos$ 都是**正弦波**，只是相位差了 90°。

<FunctionPlotter
  xMin={0} xMax={7} yMin={-1.5} yMax={1.5}
  expressions={[
    { expr: "sin(x)", color: "#ff6b6b" },
    { expr: "cos(x)", color: "#4d96ff" },
    { expr: "0.5*sin(2*x)", color: "#6bcb77" },
  ]}
  editable={false}
/>

**波形三要素**：

| 参数 | 公式 | 含义 | 效果 |
|------|------|------|------|
| **振幅** $A$ | $A\sin(x)$ | 波的高度 | $A=2$ 波更高 |
| **频率** $f$ | $\sin(f \cdot x)$ | 单位时间内振几次 | $f=2$ 波更密 |
| **相位** $\phi$ | $\sin(x + \phi)$ | 波的起始偏移 | $\phi=\frac{\pi}{2}$ 就变成 cos |

**通用正弦波**：$y = A \sin(f \cdot x + \phi)$

### Shader 中最常见的波形公式

```glsl
float pulse = sin(uTime * speed) * 0.5 + 0.5;
float glow = pow(sin(uTime) * 0.5 + 0.5, 2.0);
float wave = sin(uv.x * 10.0 + uTime * 2.0) * 0.1;
vec2 path = vec2(sin(uTime * 3.0), sin(uTime * 2.0));
```

<ShaderPreview title="正弦波驱动动画：水面波纹" code={`
varying vec2 vUv;
uniform float uTime;

void main() {
    vec2 uv = vUv;
    
    float wave1 = sin(uv.x * 15.0 + uTime * 2.0) * 0.03;
    float wave2 = sin(uv.x * 25.0 - uTime * 1.5 + uv.y * 8.0) * 0.015;
    float wave3 = sin(uv.y * 20.0 + uTime * 1.0) * 0.01;
    
    float distortedY = uv.y + wave1 + wave2 + wave3;
    
    vec3 deep = vec3(0.02, 0.05, 0.15);
    vec3 mid = vec3(0.05, 0.2, 0.4);
    vec3 surface = vec3(0.15, 0.45, 0.65);
    
    float t = smoothstep(0.0, 1.0, distortedY);
    vec3 color = mix(deep, mid, smoothstep(0.0, 0.5, t));
    color = mix(color, surface, smoothstep(0.5, 1.0, t));
    
    float highlight = pow(max(0.0, sin(uv.x * 30.0 + uTime * 3.0 + uv.y * 10.0)), 8.0) * 0.3;
    color += vec3(highlight);
    
    gl_FragColor = vec4(color, 1.0);
}
`} />

## 四、 tan 与反三角函数

### 1. tan：斜率的化身

$$ \tan\theta = \frac{\sin\theta}{\cos\theta} = \frac{y}{x} $$

$\tan$ 是圆上点到原点连线的**斜率**。当 $\theta \to 90°$ 时，$\cos \to 0$，$\tan \to \infty$。

在图形学中 $\tan$ 用得不多，但在**透视投影**的视场角（FOV）计算中会出现：

```glsl
float top = tan(fov / 2.0) * near;
```

### 2. 反三角函数：从值反推角度

| 函数 | 输入范围 | 输出范围 | 用途 |
|------|----------|----------|------|
| $\arcsin$ | $[-1, 1]$ | $[-\frac{\pi}{2}, \frac{\pi}{2}]$ | 从 $\sin$ 值反推角度 |
| $\arccos$ | $[-1, 1]$ | $[0, \pi]$ | 从点积反推夹角 |
| $\arctan$ | $(-\infty, \infty)$ | $(-\frac{\pi}{2}, \frac{\pi}{2})$ | 从斜率反推角度 |

**最常见的用法**：从点积反推两向量的夹角

```glsl
float angle = acos(clamp(dot(normalize(a), normalize(b)), -1.0, 1.0));
```

:::warning acos 的数值陷阱
`dot` 的结果可能因为浮点误差略微超出 $[-1, 1]$，导致 `acos` 返回 `NaN`。务必 clamp。
:::

### 3. atan2：朝向问题的终极武器

$\arctan$ 有个致命问题：$\frac{y}{x}$ 和 $\frac{-y}{-x}$ 的结果一样，无法区分方向。

`atan2(y, x)` 解决了这个问题——它分别接收 $y$ 和 $x$，输出**完整的 $[-\pi, \pi]$ 角度**，能区分四个象限。

<ShaderPreview title="atan2 = 2D 角度场" code={`
varying vec2 vUv;
uniform float uTime;

void main() {
    vec2 uv = vUv * 2.0 - 1.0;
    
    float angle = atan(uv.y, uv.x);
    
    float t = (angle + 3.14159) / 6.28318;
    
    vec3 color = vec3(0.05, 0.05, 0.08);
    
    float h = t * 6.0;
    float s = 0.8;
    float l = 0.5;
    
    float c = (1.0 - abs(2.0 * l - 1.0)) * s;
    float x2 = c * (1.0 - abs(mod(h, 2.0) - 1.0));
    float m = l - c / 2.0;
    
    vec3 rgb;
    if (h < 1.0) rgb = vec3(c, x2, 0.0);
    else if (h < 2.0) rgb = vec3(x2, c, 0.0);
    else if (h < 3.0) rgb = vec3(0.0, c, x2);
    else if (h < 4.0) rgb = vec3(0.0, x2, c);
    else if (h < 5.0) rgb = vec3(x2, 0.0, c);
    else rgb = vec3(c, 0.0, x2);
    
    color = rgb + m;
    
    float dist = length(uv);
    color *= smoothstep(1.2, 0.0, dist);
    
    float dotO = smoothstep(0.03, 0.01, dist);
    color = mix(color, vec3(1.0), dotO);
    
    gl_FragColor = vec4(color, 1.0);
}
`} />

**atan2 的典型用途**：

```glsl
float r = length(vec2(x, z));
float theta = atan(z, x);

float targetAngle = atan(target.x - pos.x, target.z - pos.z);

float angle = atan(point.y, point.x);
bool inCone = abs(angle) < halfConeAngle;

float ring = atan(uv.y - 0.5, uv.x - 0.5) / 6.28318 + 0.5;
```

:::important atan2 的参数顺序
**`atan2(y, x)`** ——第一个参数是 y，第二个是 x。GLSL、C、Python 都是这个顺序。
:::

## 五、 正弦波与参数方程：让东西动起来

### 1. 参数方程：用参数画路径

- **圆**：$x = \cos t,\ y = \sin t$
- **椭圆**：$x = a\cos t,\ y = b\sin t$
- **利萨如图形**：$x = \sin(at + \phi),\ y = \sin(bt)$

<ShaderPreview title="利萨如图形：两个 sin 的舞蹈" code={`
varying vec2 vUv;
uniform float uTime;

void main() {
    vec2 uv = vUv * 2.0 - 1.0;
    
    vec3 color = vec3(0.05, 0.05, 0.08);
    
    float a = 3.0;
    float b = 2.0;
    float delta = uTime * 0.3;
    
    float minDist = 1.0;
    for (int i = 0; i < 200; i++) {
        float t = float(i) / 200.0 * 6.28318;
        vec2 pt = vec2(sin(a * t + delta), sin(b * t)) * 0.7;
        float d = length(uv - pt);
        minDist = min(minDist, d);
    }
    
    float curve = smoothstep(0.015, 0.003, minDist);
    color = mix(color, vec3(0.3, 0.7, 1.0), curve);
    
    float t0 = mod(uTime * 1.5, 6.28318);
    vec2 current = vec2(sin(a * t0 + delta), sin(b * t0)) * 0.7;
    float dotP = smoothstep(0.035, 0.01, length(uv - current));
    color = mix(color, vec3(1.0, 0.8, 0.2), dotP);
    
    gl_FragColor = vec4(color, 1.0);
}
`} />

### 2. 动画路径：用 sin 驱动运动

正弦波让运动**自然**——因为自然界充满了正弦运动：钟摆、弹簧、声波、光波。

```glsl
float y = amplitude * sin(uTime * frequency) * exp(-uTime * damping);

vec2 pos = center + vec2(cos(uTime * speed), sin(uTime * speed)) * radius;

float progress = sin(uTime * speed) * 0.5 + 0.5;
```

### 3. 波形组合：傅里叶的思想雏形

任何周期波形都可以用多个不同频率的 $\sin$ 叠加出来：

<ShaderPreview title="叠加 sin 制造复杂波" code={`
varying vec2 vUv;
uniform float uTime;

void main() {
    vec2 uv = vUv;
    vec3 color = vec3(0.05, 0.05, 0.08);
    
    float x = uv.x * 6.0;
    
    float wave1 = sin(x + uTime) * 0.5;
    float d1 = smoothstep(0.01, 0.002, abs(uv.y - 0.5 - wave1 * 0.3));
    color = mix(color, vec3(0.9, 0.3, 0.3), d1);
    
    float wave2 = sin(x * 2.0 - uTime * 1.5) * 0.25;
    float d2 = smoothstep(0.01, 0.002, abs(uv.y - 0.5 - wave2 * 0.3));
    color = mix(color, vec3(0.2, 0.85, 0.3), d2);
    
    float wave3 = sin(x * 3.0 + uTime * 2.0) * 0.12;
    float d3 = smoothstep(0.01, 0.002, abs(uv.y - 0.5 - wave3 * 0.3));
    color = mix(color, vec3(0.3, 0.5, 0.9), d3);
    
    float combined = wave1 + wave2 + wave3;
    float dc = smoothstep(0.012, 0.003, abs(uv.y - 0.5 - combined * 0.3));
    color = mix(color, vec3(1.0), dc);
    
    float midLine = smoothstep(0.003, 0.001, abs(uv.y - 0.5));
    color = mix(color, vec3(0.2), midLine);
    
    gl_FragColor = vec4(color, 1.0);
}
`} />

```glsl
float wave = sin(uv.x * 10.0 + uTime * 2.0) * 0.5
           + sin(uv.x * 20.0 - uTime * 3.0) * 0.25
           + sin(uv.x * 5.0 + uTime * 0.5) * 0.3;
```

低频 = 大波浪，高频 = 小涟漪，叠加起来就是真实水面。

## 六、 三角恒等式：Shader 优化的利器

### 1. 毕达哥拉斯恒等式

$$ \sin^2\theta + \cos^2\theta = 1 $$

知道 $\sin$ 就能免费得到 $\cos$：

```glsl
float s = sin(angle);
float c = sqrt(1.0 - s * s);
```

### 2. 和角公式

$$ \sin(a + b) = \sin a \cos b + \cos a \sin b $$
$$ \cos(a + b) = \cos a \cos b - \sin a \sin b $$

这就是旋转矩阵相乘等于角度相加的数学基础。

### 3. 半角公式

$$ \sin\frac{\theta}{2} = \pm\sqrt{\frac{1 - \cos\theta}{2}} $$
$$ \cos\frac{\theta}{2} = \pm\sqrt{\frac{1 + \cos\theta}{2}} $$

**四元数**的构造就用半角公式——$q = (\sin\frac{\theta}{2} \cdot \vec{a},\ \cos\frac{\theta}{2})$。

### 4. 万能优化：sin 的快速近似

```glsl
float fastSin(float x) {
    float PI = 3.14159;
    float TAU = 6.28318;
    x = fract(x / TAU) * TAU - PI;
    return x * (1.0 - abs(x) / PI) * (1.0 + 0.2 * abs(x) / PI);
}
```

## 七、 三角函数速查表

| 操作 | 公式 / 代码 | 用途 |
|------|-------------|------|
| 圆上点 | $(\cos\theta, \sin\theta)$ | 旋转、圆周运动 |
| 0~1 振荡 | `sin(t) * 0.5 + 0.5` | 呼吸灯、闪烁 |
| 波形动画 | `sin(x * freq + time * speed)` | 水面、旗帜 |
| 两向量夹角 | `acos(clamp(dot(na, nb), -1.0, 1.0))` | 光照角度判断 |
| 2D 朝向 | `atan(y, x)` | 极坐标、扇形检测 |
| 透视 FOV | `tan(fov/2) * near` | 投影矩阵 |
| sin/cos 互推 | $\cos = \sqrt{1-\sin^2}$ | 优化 |
| 角度→弧度 | `rad = deg * PI / 180.0` | GPU 只认弧度 |

## 小结

三角函数是连接**直线世界与圆周世界**的桥梁。关键只有五件事：

1. **sin/cos = 圆上点的坐标**：看到 sin 就想到高度，看到 cos 就想到水平位置
2. **弧度制**：GPU 只认弧度，$2\pi$ = 一整圈，忘了转换是最常见的 Bug
3. **正弦波**：振幅 × sin(频率 × x + 相位) = 万能动画公式
4. **atan2**：朝向问题的终极解决方案，区分四个象限
5. **三角恒等式**：Shader 优化的工具，半角公式是四元数的基础

当你看到 `sin` 就想到圆，看到 `sin(t) * 0.5 + 0.5` 就想到 0→1→0→1 的脉冲，看到 `atan2` 就想到"求朝向角度"，这一层就算通关了。下一层，我们要把向量、矩阵、三角函数全部串起来——坐标系与变换流水线。
