# C# 并发编程完全指南

## 为什么需要并发编程？

### 单线程的局限

```csharp
// 单线程：任务必须顺序执行
DownloadFile("file1.zip");  // 耗时 5 秒
DownloadFile("file2.zip");  // 耗时 5 秒
DownloadFile("file3.zip");  // 耗时 5 秒
// 总耗时：15 秒
```

### 多线程的优势

```csharp
// 多线程：任务可以并行执行
Task.Run(() => DownloadFile("file1.zip"));
Task.Run(() => DownloadFile("file2.zip"));
Task.Run(() => DownloadFile("file3.zip"));
// 总耗时：约 5 秒（如果有足够的 CPU 核心）
```

**并发编程的应用场景：**
- 🌐 **Web 服务器**：同时处理多个请求
- 📥 **文件下载**：同时下载多个文件
- 🎮 **游戏开发**：渲染、物理、AI 并行处理
- 📊 **数据处理**：并行处理大量数据
- 🖥️ **UI 应用**：保持界面响应


```csharp

Console.WriteLine($"状态：{thread.ThreadState}");  // Running
```

### 3. 前台线程 vs 后台线程


## 第二部分：线程安全问题

### 1. 竞态条件（Race Condition）

```csharp
// ❌ 不安全的代码
class Counter
{
    private int count = 0;
    
    public void Increment()
    {
        count++;  // 不是原子操作！
    }
    
    public int GetCount() => count;
}

// 测试
var counter = new Counter();
var tasks = new Task[10];

for (int i = 0; i < 10; i++)
{
    tasks[i] = Task.Run(() =>
    {
        for (int j = 0; j < 1000; j++)
        {
            counter.Increment();
        }
    });
}

Task.WaitAll(tasks);
Console.WriteLine($"期望：10000，实际：{counter.GetCount()}");
// 实际结果可能小于 10000！
```

**问题分析：**
```
count++ 实际上是三个操作：
1. 读取 count 的值
2. 将值加 1
3. 写回 count

线程 A：读取 count = 5
线程 B：读取 count = 5
线程 A：计算 5 + 1 = 6
线程 B：计算 5 + 1 = 6
线程 A：写入 count = 6
线程 B：写入 count = 6
结果：count = 6（应该是 7）
```

### 2. 死锁（Deadlock）

```csharp
// ❌ 死锁示例
object lock1 = new object();
object lock2 = new object();

Task task1 = Task.Run(() =>
{
    lock (lock1)
    {
        Console.WriteLine("Task 1 获得 lock1");
        Thread.Sleep(100);
        
        lock (lock2)  // 等待 lock2
        {
            Console.WriteLine("Task 1 获得 lock2");
        }
    }
});

Task task2 = Task.Run(() =>
{
    lock (lock2)
    {
        Console.WriteLine("Task 2 获得 lock2");
        Thread.Sleep(100);
        
        lock (lock1)  // 等待 lock1
        {
            Console.WriteLine("Task 2 获得 lock1");
        }
    }
});

// Task 1 持有 lock1，等待 lock2
// Task 2 持有 lock2，等待 lock1
// 死锁！
```

### 1. lock 语句

```csharp
// ✅ 使用 lock 保证线程安全
class SafeCounter
{
    private int count = 0;
    private readonly object lockObj = new object();
    
    public void Increment()
    {
        lock (lockObj)
        {
            count++;
        }
    }
    
    public int GetCount()
    {
        lock (lockObj)
        {
            return count;
        }
    }
}

// lock 的本质
lock (lockObj)
{
    // 临界区代码
}

// 等价于
bool lockTaken = false;
try
{
    Monitor.Enter(lockObj, ref lockTaken);
    // 临界区代码
}
finally
{
    if (lockTaken)
        Monitor.Exit(lockObj);
}
```

### 2. Monitor 类

```csharp
class MonitorExample
{
    private readonly object lockObj = new object();
    
    public void Method1()
    {
        if (Monitor.TryEnter(lockObj, TimeSpan.FromSeconds(1)))
        {
            try
            {
                Console.WriteLine("获得锁");
                // 临界区代码
            }
            finally
            {
                Monitor.Exit(lockObj);

        else
        {
            Console.WriteLine("无法获得锁");

    // Wait 和 Pulse：线程间通信
    public void Producer()
    {
        lock (lockObj)
        {
            // 生产数据

            // 通知等待的线程
            Monitor.Pulse(lockObj);
        }
    }
    
    public void Consumer()
    {
        lock (lockObj)
        {
            // 等待数据
            Monitor.Wait(lockObj);
            
            // 消费数据
            Console.WriteLine("消费数据");
        }
    }
}
```

### 5. ReaderWriterLockSlim

```csharp
// 读写锁：允许多个读取者，但只允许一个写入者
class ReaderWriterExample
{
    private readonly ReaderWriterLockSlim rwLock = new ReaderWriterLockSlim();
    private readonly Dictionary<int, string> data = new Dictionary<int, string>();
    
    public string Read(int key)
    {
        rwLock.EnterReadLock();
        try
        {
            return data.TryGetValue(key, out var value) ? value : null;
        }
        finally
        {
            rwLock.ExitReadLock();
        }
    }
    
    public void Write(int key, string value)
    {
        rwLock.EnterWriteLock();
        try
        {
            data[key] = value;
        }
        finally
        {
            rwLock.ExitWriteLock();
        }
    }
    
    // 可升级读锁
    public void UpgradeableRead(int key)
    {
        rwLock.EnterUpgradeableReadLock();
        try
        {
            if (!data.ContainsKey(key))
            {
                rwLock.EnterWriteLock();
                try
                {
                    data[key] = "default";
                }
                finally
                {
                    rwLock.ExitWriteLock();
                }
            }
        }
        finally
        {
            rwLock.ExitUpgradeableReadLock();
        }
    }
}
```

### 案例 2：限流下载器

```csharp
public class RateLimitedDownloader
{
    private readonly HttpClient httpClient;
    private readonly SemaphoreSlim semaphore;
    private readonly int requestsPerSecond;
    
    public RateLimitedDownloader(int maxConcurrent, int requestsPerSecond)
    {
        this.httpClient = new HttpClient();
        this.semaphore = new SemaphoreSlim(maxConcurrent);
        this.requestsPerSecond = requestsPerSecond;
    }
    
    public async Task<List<string>> DownloadAllAsync(List<string> urls)
    {
        var results = new ConcurrentBag<string>();
        var rateLimiter = new SemaphoreSlim(requestsPerSecond);
        
        // 定时释放限流信号量
        _ = Task.Run(async () =>
        {
            while (true)
            {
                await Task.Delay(1000);
                for (int i = 0; i < requestsPerSecond; i++)
                {
                    rateLimiter.Release();
                }
            }
        });
        
        var tasks = urls.Select(async url =>
        {
            await semaphore.WaitAsync();
            await rateLimiter.WaitAsync();
            
            try
            {
                var content = await httpClient.GetStringAsync(url);
                results.Add(content);
                Console.WriteLine($"下载完成：{url}");
            }
            finally
            {
                semaphore.Release();
            }
        });
        
        await Task.WhenAll(tasks);
        return results.ToList();
    }
}
```

### 案例 3：缓存系统

```csharp
public class ThreadSafeCache<TKey, TValue>
{
    private readonly ConcurrentDictionary<TKey, CacheItem<TValue>> cache;
    private readonly ReaderWriterLockSlim cleanupLock;
    private readonly Timer cleanupTimer;
    
    public ThreadSafeCache(TimeSpan cleanupInterval)
    {
        cache = new ConcurrentDictionary<TKey, CacheItem<TValue>>();
        cleanupLock = new ReaderWriterLockSlim();
        cleanupTimer = new Timer(
            Cleanup,
            null,
            cleanupInterval,
            cleanupInterval);
    }
    
    public void Set(TKey key, TValue value, TimeSpan expiration)
    {
        var item = new CacheItem<TValue>
        {
            Value = value,
            ExpiresAt = DateTime.UtcNow.Add(expiration)
        };
        
        cache.AddOrUpdate(key, item, (k, old) => item);
    }
    
    public bool TryGet(TKey key, out TValue value)
    {
        if (cache.TryGetValue(key, out var item))
        {
            if (item.ExpiresAt > DateTime.UtcNow)
            {
                value = item.Value;
                return true;
            }
            
            // 过期，移除
            cache.TryRemove(key, out _);
        }
        
        value = default;
        return false;
    }
    
    public async Task<TValue> GetOrAddAsync(
        TKey key,
        Func<Task<TValue>> factory,
        TimeSpan expiration)
    {
        if (TryGet(key, out var value))
        {
            return value;
        }
        
        value = await factory();
        Set(key, value, expiration);
        return value;
    }
    
    private void Cleanup(object state)
    {
        cleanupLock.EnterWriteLock();
        try
        {
            var now = DateTime.UtcNow;
            var expiredKeys = cache
                .Where(kvp => kvp.Value.ExpiresAt <= now)
                .Select(kvp => kvp.Key)
                .ToList();
            
            foreach (var key in expiredKeys)
            {
                cache.TryRemove(key, out _);
            }
            
            Console.WriteLine($"清理了 {expiredKeys.Count} 个过期项");
        }
        finally
        {
            cleanupLock.ExitWriteLock();
        }
    }
}

public class CacheItem<T>
{
```

## 第八部分：性能优化

### 1. 避免过度并行

```csharp
// ❌ 错误：为小任务创建过多线程
Parallel.For(0, 10, i =>
{
    Console.WriteLine(i);  // 太简单，不值得并行
});

// ✅ 正确：只对耗时任务并行
Parallel.For(0, 10, i =>
{
    ProcessLargeDataSet(i);  // 耗时操作
});
```

### 2. 使用对象池

```csharp
// 使用 ArrayPool 减少分配
var pool = ArrayPool<byte>.Shared;
byte[] buffer = pool.Rent(1024);

try
{
    // 使用 buffer
}
finally
{
    pool.Return(buffer);
}
```

### 3. 避免锁竞争

```csharp
// ❌ 锁粒度太大
class BadExample
{
    private readonly object lockObj = new object();
    private int count1 = 0;
    private int count2 = 0;
    
    public void IncrementCount1()
    {
        lock (lockObj)  // 锁住了两个计数器
        {
            count1++;
        }
    }
    
    public void IncrementCount2()
    {
        lock (lockObj)  // 不必要的锁竞争
        {
            count2++;
        }
    }
}

// ✅ 使用细粒度锁或无锁
class GoodExample
{
    private int count1 = 0;
    private int count2 = 0;
    
    public void IncrementCount1()
    {
        Interlocked.Increment(ref count1);  // 无锁
    }
    
    public void IncrementCount2()
    {
        Interlocked.Increment(ref count2);  // 无锁
    }
}
```

### 4. 使用 Lazy 延迟初始化

```csharp
public class ExpensiveResource
{
    private static readonly Lazy<ExpensiveResource> instance =
        new Lazy<ExpensiveResource>(() => new ExpensiveResource(), 
            LazyThreadSafetyMode.ExecutionAndPublication);
    
    public static ExpensiveResource Instance => instance.Value;
    
    private ExpensiveResource()
    {
        // 昂贵的初始化
        Thread.Sleep(2000);
    }
}
```

## 并发编程最佳实践

### 1. 优先使用高级抽象

```
推荐顺序：
1. async/await
2. Task 和 Task.Run
3. Parallel 和 PLINQ
4. 并发集合
5. lock 和同步原语
6. Thread（尽量避免）
```

### 2. 避免死锁

```csharp
// ✅ 始终按相同顺序获取锁
lock (lock1)
{
    lock (lock2)
    {
        // 安全
    }
}

// ✅ 使用超时
if (Monitor.TryEnter(lockObj, TimeSpan.FromSeconds(1)))
{
    try
    {
        // 临界区
    }
    finally
    {
        Monitor.Exit(lockObj);
    }
}
```

### 3. 正确处理异常

```csharp
// ✅ Task 中的异常处理
var task = Task.Run(() =>
{
    throw new Exception("错误");
});

try
{
    await task;
}
catch (Exception ex)
{
    Console.WriteLine($"捕获异常：{ex.Message}");
}

// ✅ 并行操作的异常处理
try
{
    Parallel.For(0, 100, i =>
    {
        if (i == 50)
            throw new Exception($"错误在 {i}");
    });
}
catch (AggregateException ex)
{
    foreach (var inner in ex.InnerExceptions)
    {
        Console.WriteLine(inner.Message);
    }
}
```

```csharp
public async Task ProcessDataAsync(CancellationToken cancellationToken)
```
