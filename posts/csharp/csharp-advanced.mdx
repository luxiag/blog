## 1. 泛型（Generics）

泛型允许你编写类型安全且可重用的代码，而无需为每种类型重复编写代码。

### 为什么需要泛型？

**没有泛型的困境：**

```csharp
// 只能存储 int 的栈
class IntStack
{
    private int[] items = new int[100];
    private int count = 0;

    public void Push(int item) { items[count++] = item; }
    public int Pop() { return items[--count]; }
}

// 想存储 string？需要再写一个类
class StringStack
{
    private string[] items = new string[100];
    private int count = 0;

    public void Push(string item) { items[count++] = item; }
    public string Pop() { return items[--count]; }
}
```

**使用泛型的优雅方案：**

```csharp
class Stack<T>
{
    private T[] items = new T[100];
    private int count = 0;

    public void Push(T item)
    {
        items[count++] = item;
    }

    public T Pop()
    {
        return items[--count];
    }

    public int Count => count;
}

// 使用
Stack<int> intStack = new Stack<int>();
intStack.Push(1);
intStack.Push(2);
Console.WriteLine(intStack.Pop());  // 2

Stack<string> stringStack = new Stack<string>();
stringStack.Push("Hello");
stringStack.Push("World");
Console.WriteLine(stringStack.Pop());  // World
```

### 泛型约束

限制泛型参数必须满足特定条件：

```csharp
// 约束 T 必须是类
class Repository<T> where T : class
{
    private List<T> items = new List<T>();

    public void Add(T item) => items.Add(item);
    public T Get(int index) => items[index];
}

// 约束 T 必须有无参构造函数
class Factory<T> where T : new()
{
    public T Create()
    {
        return new T();
    }
}

// 约束 T 必须实现 IComparable 接口
class Sorter<T> where T : IComparable<T>
{
    public void Sort(List<T> list)
    {
        list.Sort();
    }
}

// 多个约束
class Manager<T> where T : class, IDisposable, new()
{
    public T CreateAndManage()
    {
        T item = new T();
        // ... 管理逻辑
        return item;
    }
}
```

### 泛型方法

```csharp
class Utility
{
    // 泛型方法：交换两个变量的值
    public static void Swap<T>(ref T a, ref T b)
    {
        T temp = a;
        a = b;
        b = temp;
    }

    // 泛型方法：查找数组中的元素
    public static int FindIndex<T>(T[] array, T value) where T : IEquatable<T>
    {
        for (int i = 0; i < array.Length; i++)
        {
            if (array[i].Equals(value))
                return i;
        }
        return -1;
    }
}

// 使用
int x = 10, y = 20;
Utility.Swap(ref x, ref y);
Console.WriteLine($"x={x}, y={y}");  // x=20, y=10

string[] names = { "Alice", "Bob", "Charlie" };
int index = Utility.FindIndex(names, "Bob");
Console.WriteLine(index);  // 1
```

## 2. 委托与事件（Delegates & Events）

委托是类型安全的函数指针，事件是基于委托的发布-订阅模式。

### 委托基础

```csharp
// 定义委托类型
delegate int MathOperation(int a, int b);

class Calculator
{
    // 符合委托签名的方法
    public static int Add(int a, int b) => a + b;
    public static int Subtract(int a, int b) => a - b;
    public static int Multiply(int a, int b) => a * b;

    public static void ExecuteOperation(int x, int y, MathOperation operation)
    {
        int result = operation(x, y);
        Console.WriteLine($"结果：{result}");
    }
}

// 使用
Calculator.ExecuteOperation(10, 5, Calculator.Add);       // 15
Calculator.ExecuteOperation(10, 5, Calculator.Subtract);  // 5
Calculator.ExecuteOperation(10, 5, Calculator.Multiply);  // 50
```

### 内置委托：Action、Func、Predicate

```csharp
// Action：无返回值的委托
Action<string> print = message => Console.WriteLine(message);
print("Hello");

// Func：有返回值的委托
Func<int, int, int> add = (a, b) => a + b;
Console.WriteLine(add(3, 4));  // 7

// Predicate：返回 bool 的委托
Predicate<int> isEven = num => num % 2 == 0;
Console.WriteLine(isEven(4));  // True
Console.WriteLine(isEven(5));  // False
```

### 多播委托

```csharp
class Logger
{
    public delegate void LogHandler(string message);

    public static void LogToConsole(string message)
    {
        Console.WriteLine($"[Console] {message}");
    }

    public static void LogToFile(string message)
    {
        Console.WriteLine($"[File] {message}");
    }

    public static void LogToDatabase(string message)
    {
        Console.WriteLine($"[Database] {message}");
    }
}

// 多播委托：一次调用，多个方法执行
Logger.LogHandler logger = Logger.LogToConsole;
logger += Logger.LogToFile;
logger += Logger.LogToDatabase;

logger("应用程序启动");
// 输出：
// [Console] 应用程序启动
// [File] 应用程序启动
// [Database] 应用程序启动
```

### 事件（Events）

事件是委托的封装，提供了更好的封装性。

```csharp
class Button
{
    // 定义事件
    public event EventHandler Clicked;

    public void Click()
    {
        Console.WriteLine("按钮被点击");
        // 触发事件
        Clicked?.Invoke(this, EventArgs.Empty);
    }
}

class Program
{
    static void Main()
    {
        Button button = new Button();

        // 订阅事件
        button.Clicked += OnButtonClicked;
        button.Clicked += (sender, e) => Console.WriteLine("匿名处理器");

        // 触发事件
        button.Click();
    }

    static void OnButtonClicked(object sender, EventArgs e)
    {
        Console.WriteLine("按钮点击事件处理器被调用");
    }
}
```

### 自定义事件参数

```csharp
// 自定义事件参数
class PriceChangedEventArgs : EventArgs
{
    public decimal OldPrice { get; set; }
    public decimal NewPrice { get; set; }
}

class Product
{
    private decimal price;

    public event EventHandler<PriceChangedEventArgs> PriceChanged;

    public decimal Price
    {
        get => price;
        set
        {
            if (price != value)
            {
                decimal oldPrice = price;
                price = value;

                // 触发事件
                PriceChanged?.Invoke(this, new PriceChangedEventArgs
                {
                    OldPrice = oldPrice,
                    NewPrice = value
                });
            }
        }
    }
}

// 使用
Product product = new Product();
product.PriceChanged += (sender, e) =>
{
    Console.WriteLine($"价格从 {e.OldPrice} 变为 {e.NewPrice}");
};

product.Price = 100;  // 价格从 0 变为 100
product.Price = 150;  // 价格从 100 变为 150
```

## 3. 异步编程（Async/Await）

异步编程让你的应用程序在等待 I/O 操作时不会阻塞，提高响应性和性能。

### 同步 vs 异步

```csharp
using System.Net.Http;
using System.Threading.Tasks;

class WebDownloader
{
    // 同步方法（会阻塞）
    public static string DownloadSync(string url)
    {
        using (HttpClient client = new HttpClient())
        {
            // 阻塞当前线程，直到下载完成
            return client.GetStringAsync(url).Result;
        }
    }

    // 异步方法（不阻塞）
    public static async Task<string> DownloadAsync(string url)
    {
        using (HttpClient client = new HttpClient())
        {
            // 不阻塞，释放线程去做其他事情
            return await client.GetStringAsync(url);
        }
    }
}

// 使用
async Task Main()
{
    Console.WriteLine("开始下载...");
    
    string content = await WebDownloader.DownloadAsync("https://example.com");
    
    Console.WriteLine($"下载完成，长度：{content.Length}");
}
```

### async/await 基础

```csharp
class CoffeeShop
{
    // 模拟耗时操作
    public static async Task<string> BrewCoffeeAsync()
    {
        Console.WriteLine("开始煮咖啡...");
        await Task.Delay(3000);  // 模拟 3 秒
        Console.WriteLine("咖啡煮好了！");
        return "☕ 咖啡";
    }

    public static async Task<string> ToastBreadAsync()
    {
        Console.WriteLine("开始烤面包...");
        await Task.Delay(2000);  // 模拟 2 秒
        Console.WriteLine("面包烤好了！");
        return "🍞 面包";
    }

    public static async Task<string> FryEggAsync()
    {
        Console.WriteLine("开始煎蛋...");
        await Task.Delay(1000);  // 模拟 1 秒
        Console.WriteLine("鸡蛋煎好了！");
        return "🍳 鸡蛋";
    }
}

// 顺序执行（总共 6 秒）
async Task MakeBreakfastSequential()
{
    var coffee = await CoffeeShop.BrewCoffeeAsync();
    var bread = await CoffeeShop.ToastBreadAsync();
    var egg = await CoffeeShop.FryEggAsync();
    
    Console.WriteLine($"早餐准备好了：{coffee} + {bread} + {egg}");
}

// 并发执行（总共 3 秒）
async Task MakeBreakfastConcurrent()
{
    Task<string> coffeeTask = CoffeeShop.BrewCoffeeAsync();
    Task<string> breadTask = CoffeeShop.ToastBreadAsync();
    Task<string> eggTask = CoffeeShop.FryEggAsync();

    // 等待所有任务完成
    await Task.WhenAll(coffeeTask, breadTask, eggTask);

    Console.WriteLine($"早餐准备好了：{coffeeTask.Result} + {breadTask.Result} + {eggTask.Result}");
}
```

### 异步最佳实践

```csharp
class BestPractices
{
    // ✅ 好的做法：使用 async/await
    public async Task<int> GetDataAsync()
    {
        await Task.Delay(1000);
        return 42;
    }

    // ❌ 不好的做法：async void（除了事件处理器）
    // public async void BadMethodAsync() { }

    // ✅ 异步方法命名以 Async 结尾
    public async Task<string> FetchUserDataAsync(int userId)
    {
        await Task.Delay(100);
        return $"User {userId}";
    }

    // ✅ 使用 ConfigureAwait(false) 避免死锁（库代码中）
    public async Task<string> LibraryMethodAsync()
    {
        await Task.Delay(1000).ConfigureAwait(false);
        return "Data";
    }

    // ✅ 取消令牌支持
    public async Task<string> LongRunningTaskAsync(CancellationToken cancellationToken)
    {
        for (int i = 0; i < 10; i++)
        {
            cancellationToken.ThrowIfCancellationRequested();
            await Task.Delay(1000, cancellationToken);
        }
        return "Completed";
    }
}
```

## 4. LINQ 高级用法

LINQ 不仅可以查询，还有很多强大的操作符。

### 复杂查询

```csharp
class Order
{
    public int Id { get; set; }
    public string Customer { get; set; }
    public decimal Total { get; set; }
    public DateTime Date { get; set; }
}

List<Order> orders = new List<Order>
{
    new Order { Id = 1, Customer = "Alice", Total = 100, Date = DateTime.Now.AddDays(-5) },
    new Order { Id = 2, Customer = "Bob", Total = 200, Date = DateTime.Now.AddDays(-3) },
    new Order { Id = 3, Customer = "Alice", Total = 150, Date = DateTime.Now.AddDays(-1) },
    new Order { Id = 4, Customer = "Charlie", Total = 300, Date = DateTime.Now }
};

// 分组
var groupedByCustomer = orders.GroupBy(o => o.Customer);
foreach (var group in groupedByCustomer)
{
    Console.WriteLine($"{group.Key}: {group.Sum(o => o.Total)} 元");
}

// 连接（Join）
List<string> customers = new List<string> { "Alice", "Bob" };
var joinResult = from c in customers
                 join o in orders on c equals o.Customer
                 select new { Customer = c, OrderId = o.Id, Total = o.Total };

// 投影（Select Many）
List<string[]> arrays = new List<string[]>
{
    new[] { "a", "b" },
    new[] { "c", "d" }
};
var flattened = arrays.SelectMany(arr => arr);  // a, b, c, d

// 聚合
var stats = orders.Aggregate(
    new { Count = 0, Total = 0m },
    (acc, order) => new { Count = acc.Count + 1, Total = acc.Total + order.Total }
);
Console.WriteLine($"订单数：{stats.Count}，总额：{stats.Total}");
```

### 延迟执行与立即执行

```csharp
List<int> numbers = new List<int> { 1, 2, 3, 4, 5 };

// 延迟执行：查询定义时不执行
var query = numbers.Where(n => n > 2);
numbers.Add(6);  // 修改源数据
foreach (var num in query)  // 执行时才会查询
{
    Console.WriteLine(num);  // 3, 4, 5, 6
}

// 立即执行：使用 ToList()、ToArray()、Count() 等
var list = numbers.Where(n => n > 2).ToList();
numbers.Add(7);  // 修改源数据
foreach (var num in list)
{
    Console.WriteLine(num);  // 3, 4, 5, 6（不包括 7）
}
```

## 5. 扩展方法（Extension Methods）

扩展方法允许你为现有类型添加新方法，而无需修改原始类型。

```csharp
public static class StringExtensions
{
    // 扩展 string 类型
    public static bool IsValidEmail(this string email)
    {
        return email.Contains("@") && email.Contains(".");
    }

    public static string Truncate(this string text, int maxLength)
    {
        if (text.Length <= maxLength)
            return text;
        return text.Substring(0, maxLength) + "...";
    }

    public static int WordCount(this string text)
    {
        return text.Split(new[] { ' ', '\t', '\n' }, StringSplitOptions.RemoveEmptyEntries).Length;
    }
}

public static class IntExtensions
{
    // 扩展 int 类型
    public static bool IsEven(this int number)
    {
        return number % 2 == 0;
    }

    public static bool IsPrime(this int number)
    {
        if (number < 2) return false;
        for (int i = 2; i <= Math.Sqrt(number); i++)
        {
            if (number % i == 0) return false;
        }
        return true;
    }
}

// 使用
string email = "test@example.com";
Console.WriteLine(email.IsValidEmail());  // True

string text = "这是一段很长的文本内容";
Console.WriteLine(text.Truncate(5));  // 这是一段很...

int num = 17;
Console.WriteLine(num.IsEven());   // False
Console.WriteLine(num.IsPrime());  // True
```

## 6. 特性（Attributes）

特性是为代码元素添加元数据的方式。

### 内置特性

```csharp
using System;
using System.ComponentModel;

class Product
{
    // Obsolete：标记过时的成员
    [Obsolete("请使用 NewMethod 代替")]
    public void OldMethod()
    {
        Console.WriteLine("旧方法");
    }

    public void NewMethod()
    {
        Console.WriteLine("新方法");
    }

    // Description：添加描述
    [Description("产品名称")]
    public string Name { get; set; }

    // DefaultValue：默认值
    [DefaultValue(0)]
    public int Stock { get; set; }
}
```

### 自定义特性

```csharp
// 定义自定义特性
[AttributeUsage(AttributeTargets.Class | AttributeTargets.Method, AllowMultiple = true)]
class AuthorAttribute : Attribute
{
    public string Name { get; set; }
    public string Date { get; set; }

    public AuthorAttribute(string name)
    {
        Name = name;
        Date = DateTime.Now.ToString("yyyy-MM-dd");
    }
}

// 使用自定义特性
[Author("张三")]
[Author("李四")]
class MyClass
{
    [Author("王五")]
    public void MyMethod()
    {
    }
}

// 读取特性
class AttributeReader
{
    public static void ReadAttributes()
    {
        Type type = typeof(MyClass);
        
        // 读取类上的特性
        var classAttributes = type.GetCustomAttributes(typeof(AuthorAttribute), false);
        foreach (AuthorAttribute attr in classAttributes)
        {
            Console.WriteLine($"类作者：{attr.Name}，日期：{attr.Date}");
        }

        // 读取方法上的特性
        var method = type.GetMethod("MyMethod");
        var methodAttributes = method.GetCustomAttributes(typeof(AuthorAttribute), false);
        foreach (AuthorAttribute attr in methodAttributes)
        {
            Console.WriteLine($"方法作者：{attr.Name}，日期：{attr.Date}");
        }
    }
}
```

## 7. 反射（Reflection）

反射允许在运行时检查和操作类型、成员和对象。

```csharp
using System;
using System.Reflection;

class Person
{
    public string Name { get; set; }
    public int Age { get; set; }

    public void SayHello()
    {
        Console.WriteLine($"你好，我是 {Name}");
    }

    private void PrivateMethod()
    {
        Console.WriteLine("这是私有方法");
    }
}

class ReflectionDemo
{
    public static void Demo()
    {
        // 获取类型信息
        Type type = typeof(Person);
        Console.WriteLine($"类型名称：{type.Name}");
        Console.WriteLine($"命名空间：{type.Namespace}");

        // 获取属性
        PropertyInfo[] properties = type.GetProperties();
        Console.WriteLine("\n属性列表：");
        foreach (var prop in properties)
        {
            Console.WriteLine($"- {prop.Name} ({prop.PropertyType.Name})");
        }

        // 获取方法
        MethodInfo[] methods = type.GetMethods();
        Console.WriteLine("\n方法列表：");
        foreach (var method in methods)
        {
            Console.WriteLine($"- {method.Name}");
        }

        // 动态创建对象
        object person = Activator.CreateInstance(type);

        // 设置属性值
        PropertyInfo nameProp = type.GetProperty("Name");
        nameProp.SetValue(person, "张三");

        PropertyInfo ageProp = type.GetProperty("Age");
        ageProp.SetValue(person, 25);

        // 调用方法
        MethodInfo sayHelloMethod = type.GetMethod("SayHello");
        sayHelloMethod.Invoke(person, null);

        // 调用私有方法
        MethodInfo privateMethod = type.GetMethod("PrivateMethod", 
            BindingFlags.NonPublic | BindingFlags.Instance);
        privateMethod.Invoke(person, null);
    }
}
```

## 8. 表达式树（Expression Trees）

表达式树将代码表示为数据结构，常用于 LINQ to SQL 等场景。

```csharp
using System;
using System.Linq.Expressions;

class ExpressionTreeDemo
{
    public static void Demo()
    {
        // Lambda 表达式
        Func<int, int, int> add = (a, b) => a + b;
        Console.WriteLine(add(3, 4));  // 7

        // 表达式树
        Expression<Func<int, int, int>> addExpression = (a, b) => a + b;
        
        // 分析表达式树
        Console.WriteLine($"表达式类型：{addExpression.NodeType}");
        Console.WriteLine($"表达式体：{addExpression.Body}");
        Console.WriteLine($"参数：{string.Join(", ", addExpression.Parameters)}");

        // 编译并执行
        var compiled = addExpression.Compile();
        Console.WriteLine(compiled(3, 4));  // 7

        // 手动构建表达式树
        ParameterExpression param = Expression.Parameter(typeof(int), "x");
        ConstantExpression constant = Expression.Constant(10);
        BinaryExpression multiply = Expression.Multiply(param, constant);
        
        Expression<Func<int, int>> multiplyExpression = 
            Expression.Lambda<Func<int, int>>(multiply, param);
        
        var multiplyFunc = multiplyExpression.Compile();
        Console.WriteLine(multiplyFunc(5));  // 50
    }
}
```

## 9. 实战：插件系统

综合运用反射、特性等高级特性，创建一个简单的插件系统：

```csharp
using System;
using System.Collections.Generic;
using System.Linq;
using System.Reflection;

// 插件接口
interface IPlugin
{
    string Name { get; }
    string Version { get; }
    void Execute();
}

// 插件特性
[AttributeUsage(AttributeTargets.Class)]
class PluginAttribute : Attribute
{
    public string Description { get; set; }
    public bool AutoLoad { get; set; }
}

// 插件实现
[Plugin(Description = "日志插件", AutoLoad = true)]
class LoggerPlugin : IPlugin
{
    public string Name => "Logger";
    public string Version => "1.0.0";

    public void Execute()
    {
        Console.WriteLine("[Logger] 插件执行中...");
    }
}

[Plugin(Description = "数据库插件", AutoLoad = false)]
class DatabasePlugin : IPlugin
{
    public string Name => "Database";
    public string Version => "2.0.0";

    public void Execute()
    {
        Console.WriteLine("[Database] 插件执行中...");
    }
}

// 插件管理器
class PluginManager
{
    private List<IPlugin> plugins = new List<IPlugin>();

    public void LoadPlugins()
    {
        // 获取当前程序集中的所有类型
        Assembly assembly = Assembly.GetExecutingAssembly();
        Type[] types = assembly.GetTypes();

        foreach (Type type in types)
        {
            // 检查是否实现了 IPlugin 接口
            if (typeof(IPlugin).IsAssignableFrom(type) && !type.IsInterface)
            {
                // 检查是否有 Plugin 特性
                var pluginAttr = type.GetCustomAttribute<PluginAttribute>();
                
                if (pluginAttr != null && pluginAttr.AutoLoad)
                {
                    // 创建插件实例
                    IPlugin plugin = (IPlugin)Activator.CreateInstance(type);
                    plugins.Add(plugin);
                    
                    Console.WriteLine($"加载插件：{plugin.Name} v{plugin.Version}");
                    Console.WriteLine($"描述：{pluginAttr.Description}");
                }
            }
        }
    }

    public void ExecuteAll()
    {
        Console.WriteLine("\n执行所有插件：");
        foreach (var plugin in plugins)
        {
            plugin.Execute();
        }
    }

    public void ListPlugins()
    {
        Console.WriteLine("\n已加载的插件：");
        foreach (var plugin in plugins)
        {
            Console.WriteLine($"- {plugin.Name} v{plugin.Version}");
        }
    }
}

// 使用
class Program
{
    static void Main()
    {
        PluginManager manager = new PluginManager();
        manager.LoadPlugins();
        manager.ListPlugins();
        manager.ExecuteAll();
    }
}
```
