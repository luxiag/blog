# Entity Framework Core 完全指南

## 什么是 Entity Framework Core？

**Entity Framework Core（EF Core）** 是微软开发的**对象关系映射（ORM）**框架，它让你可以用 C# 对象来操作数据库，而不需要编写 SQL 语句。

### 为什么使用 EF Core？

**没有 ORM 的困境：**
```csharp
// 手动编写 SQL，容易出错
string sql = "SELECT * FROM Users WHERE Id = @id";
using (var connection = new SqlConnection(connectionString))
{
    var command = new SqlCommand(sql, connection);
    command.Parameters.AddWithValue("@id", userId);
    connection.Open();
    var reader = command.ExecuteReader();
    // 手动映射到对象...
}
```

**使用 EF Core：**
```csharp
// 简洁、类型安全
var user = await context.Users.FindAsync(userId);
```

### EF Core 的优势

✅ **类型安全**：编译时检查，减少运行时错误  
✅ **LINQ 查询**：用 C# 语法查询数据库  
✅ **自动迁移**：数据库结构变更自动管理  
✅ **跨数据库**：支持 SQL Server、MySQL、PostgreSQL、SQLite 等  
✅ **变更追踪**：自动跟踪对象变化  
✅ **延迟加载**：按需加载关联数据

## 核心概念

### 1. 实体（Entity）

实体是映射到数据库表的 C# 类。

```csharp
public class User
{
    public int Id { get; set; }              // 主键
    public string Name { get; set; }         // 映射到 Name 列
    public string Email { get; set; }
    public DateTime CreatedAt { get; set; }
}
```

### 2. DbContext

`DbContext` 是 EF Core 的核心类，代表数据库会话。

```csharp
using Microsoft.EntityFrameworkCore;

public class AppDbContext : DbContext
{
    // DbSet 代表数据库中的表
    public DbSet<User> Users { get; set; }
    public DbSet<Post> Posts { get; set; }
    
    // 配置数据库连接
    protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
    {
        optionsBuilder.UseSqlite("Data Source=app.db");
    }
}
```

### 3. 使用 DbContext

```csharp
// 创建数据库上下文
using (var context = new AppDbContext())
{
    // 查询
    var users = context.Users.ToList();
    
    // 添加
    context.Users.Add(new User { Name = "张三" });
    
    // 保存更改
    context.SaveChanges();
}
```

## 第一个 EF Core 应用

### 1. 定义实体

```csharp
public class Blog
{
    public int Id { get; set; }
    public string Title { get; set; }
    public string Url { get; set; }
    public DateTime CreatedAt { get; set; }
    
    // 导航属性：一个博客有多篇文章
    public List<Post> Posts { get; set; }
}

public class Post
{
    public int Id { get; set; }
    public string Title { get; set; }
    public string Content { get; set; }
    public DateTime PublishedAt { get; set; }
    
    // 外键
    public int BlogId { get; set; }
    
    // 导航属性：一篇文章属于一个博客
    public Blog Blog { get; set; }
}
```

### 2. 创建 DbContext

```csharp
public class BlogDbContext : DbContext
{
    public DbSet<Blog> Blogs { get; set; }
    public DbSet<Post> Posts { get; set; }
    
    protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
    {
        optionsBuilder.UseSqlite("Data Source=blog.db");
    }
    
    // 模型配置（可选）
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // 配置 Blog 实体
        modelBuilder.Entity<Blog>(entity =>
        {
            entity.HasKey(e => e.Id);
            entity.Property(e => e.Title).IsRequired().HasMaxLength(200);
            entity.Property(e => e.Url).HasMaxLength(500);
        });
        
        // 配置 Post 实体
        modelBuilder.Entity<Post>(entity =>
        {
            entity.HasKey(e => e.Id);
            entity.Property(e => e.Title).IsRequired().HasMaxLength(200);
            
            // 配置关系：一个博客有多篇文章
            entity.HasOne(p => p.Blog)
                  .WithMany(b => b.Posts)
                  .HasForeignKey(p => p.BlogId);
        });
    }
}
```

## CRUD 操作

### 创建（Create）

```csharp
// 添加单个实体
var user = new User { Name = "张三", Email = "zhang@example.com" };
context.Users.Add(user);
await context.SaveChangesAsync();

// 添加多个实体
var users = new List<User>
{
    new User { Name = "李四", Email = "li@example.com" },
    new User { Name = "王五", Email = "wang@example.com" }
};
context.Users.AddRange(users);
await context.SaveChangesAsync();
```

### 读取（Read）

```csharp
// 查询所有
var allUsers = await context.Users.ToListAsync();

// 根据 ID 查询
var user = await context.Users.FindAsync(1);

// 条件查询
var activeUsers = await context.Users
    .Where(u => u.IsActive)
    .ToListAsync();

// 单个结果
var firstUser = await context.Users.FirstOrDefaultAsync();
var specificUser = await context.Users
    .FirstOrDefaultAsync(u => u.Email == "zhang@example.com");

// 排序
var sortedUsers = await context.Users
    .OrderBy(u => u.Name)
    .ToListAsync();

// 分页
int pageSize = 10;
int pageNumber = 1;
var pagedUsers = await context.Users
    .Skip((pageNumber - 1) * pageSize)
    .Take(pageSize)
    .ToListAsync();

// 投影（只选择部分字段）
var userNames = await context.Users
    .Select(u => new { u.Id, u.Name })
    .ToListAsync();

// 聚合
var userCount = await context.Users.CountAsync();
var averageAge = await context.Users.AverageAsync(u => u.Age);
var maxAge = await context.Users.MaxAsync(u => u.Age);
```

### 更新（Update）

```csharp
// 方式 1：先查询，再修改
var user = await context.Users.FindAsync(1);
if (user != null)
{
    user.Name = "张三（已修改）";
    user.Email = "newemail@example.com";
    await context.SaveChangesAsync();
}

// 方式 2：直接更新（不查询）
var userToUpdate = new User { Id = 1, Name = "新名字", Email = "new@example.com" };
context.Users.Update(userToUpdate);
await context.SaveChangesAsync();

// 方式 3：批量更新（EF Core 7+）
await context.Users
    .Where(u => u.IsActive == false)
    .ExecuteUpdateAsync(setters => setters
        .SetProperty(u => u.IsActive, true)
        .SetProperty(u => u.UpdatedAt, DateTime.Now));
```

### 删除（Delete）

```csharp
// 方式 1：先查询，再删除
var user = await context.Users.FindAsync(1);
if (user != null)
{
    context.Users.Remove(user);
    await context.SaveChangesAsync();
}

// 方式 2：直接删除（不查询）
var userToDelete = new User { Id = 1 };
context.Users.Remove(userToDelete);
await context.SaveChangesAsync();

// 方式 3：批量删除（EF Core 7+）
await context.Users
    .Where(u => u.CreatedAt < DateTime.Now.AddYears(-1))
    .ExecuteDeleteAsync();
```

## 高级查询

### 延迟加载（Lazy Loading）

```csharp
// 安装包
// dotnet add package Microsoft.EntityFrameworkCore.Proxies

// 启用延迟加载
protected override void OnConfiguring(DbContextOptionsBuilder optionsBuilder)
{
    optionsBuilder
        .UseLazyLoadingProxies()
        .UseSqlite("Data Source=app.db");
}

// 导航属性需要是 virtual
public class Blog
{
    public int Id { get; set; }
    public string Title { get; set; }
    
    // virtual 关键字
    public virtual List<Post> Posts { get; set; }
}

// 使用（自动加载关联数据）
var blog = await context.Blogs.FindAsync(1);
// 访问 Posts 时自动从数据库加载
foreach (var post in blog.Posts)
{
    Console.WriteLine(post.Title);
}
```

### 显式加载（Explicit Loading）

```csharp
var blog = await context.Blogs.FindAsync(1);

// 显式加载文章
await context.Entry(blog)
    .Collection(b => b.Posts)
    .LoadAsync();

// 显式加载并过滤
await context.Entry(blog)
    .Collection(b => b.Posts)
    .Query()
    .Where(p => p.PublishedAt > DateTime.Now.AddDays(-7))
    .LoadAsync();
```

### 预加载（Eager Loading）

```csharp
// Include：加载一级关联
var blogs = await context.Blogs
    .Include(b => b.Posts)
    .ToListAsync();

// ThenInclude：加载多级关联
var blogs = await context.Blogs
    .Include(b => b.Posts)
        .ThenInclude(p => p.Comments)
    .ToListAsync();

// 多个 Include
var blogs = await context.Blogs
    .Include(b => b.Posts)
    .Include(b => b.Author)
    .ToListAsync();

// 过滤包含的数据（EF Core 5+）
var blogs = await context.Blogs
    .Include(b => b.Posts.Where(p => p.IsPublished))
    .ToListAsync();
```

### 原始 SQL 查询

```csharp
// 查询实体
var users = await context.Users
    .FromSqlRaw("SELECT * FROM Users WHERE Age > {0}", 18)
    .ToListAsync();

// 查询标量值
```

### 2. DbContext 配置

```csharp
public class BlogDbContext : DbContext
{
    public DbSet<User> Users { get; set; }
    public DbSet<Post> Posts { get; set; }
    public DbSet<Comment> Comments { get; set; }
    public DbSet<Tag> Tags { get; set; }
    
    public BlogDbContext(DbContextOptions<BlogDbContext> options)
        : base(options)
    {
    }
    
    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        // User 配置
        modelBuilder.Entity<User>(entity =>
        {
            entity.HasKey(e => e.Id);
            entity.HasIndex(e => e.Email).IsUnique();
            entity.Property(e => e.CreatedAt).HasDefaultValueSql("GETDATE()");
        });
        
        // Post 配置
        modelBuilder.Entity<Post>(entity =>
        {
            entity.HasKey(e => e.Id);
            entity.HasIndex(e => e.Title);
            
            entity.HasOne(p => p.Author)
                  .WithMany(u => u.Posts)
                  .HasForeignKey(p => p.AuthorId)
                  .OnDelete(DeleteBehavior.Cascade);
        });
        
        // Comment 配置
        modelBuilder.Entity<Comment>(entity =>
        {
            entity.HasKey(e => e.Id);
            
            entity.HasOne(c => c.Post)
                  .WithMany(p => p.Comments)
                  .HasForeignKey(c => c.PostId)
                  .OnDelete(DeleteBehavior.Cascade);
                  
            entity.HasOne(c => c.User)
                  .WithMany(u => u.Comments)
                  .HasForeignKey(c => c.UserId)
                  .OnDelete(DeleteBehavior.Restrict);
        });
        
        // Tag 配置（多对多）
        modelBuilder.Entity<Post>()
            .HasMany(p => p.Tags)
            .WithMany(t => t.Posts)
            .UsingEntity(j => j.ToTable("PostTags"));
    }
}
```

### 3. 仓储模式（Repository Pattern）

```csharp
public interface IRepository<T> where T : class
{
    Task<T> GetByIdAsync(int id);
    Task<List<T>> GetAllAsync();
    Task<T> AddAsync(T entity);
    Task UpdateAsync(T entity);
    Task DeleteAsync(int id);
}

public class Repository<T> : IRepository<T> where T : class
{
    protected readonly BlogDbContext context;
    protected readonly DbSet<T> dbSet;
    
    public Repository(BlogDbContext context)
    {
        this.context = context;
        this.dbSet = context.Set<T>();
    }
    
    public virtual async Task<T> GetByIdAsync(int id)
    {
        return await dbSet.FindAsync(id);
    }
    
    public virtual async Task<List<T>> GetAllAsync()
    {
        return await dbSet.ToListAsync();
    }
    
    public virtual async Task<T> AddAsync(T entity)
    {
        await dbSet.AddAsync(entity);
        await context.SaveChangesAsync();
        return entity;
    }
    
    public virtual async Task UpdateAsync(T entity)
    {
        dbSet.Update(entity);
        await context.SaveChangesAsync();
    }
    
    public virtual async Task DeleteAsync(int id)
    {
        var entity = await GetByIdAsync(id);
        if (entity != null)
        {
            dbSet.Remove(entity);
            await context.SaveChangesAsync();
        }
    }
}

// 特定仓储
public interface IPostRepository : IRepository<Post>
{
    Task<List<Post>> GetRecentPostsAsync(int count);
    Task<List<Post>> GetPostsByAuthorAsync(int authorId);
    Task<Post> GetPostWithCommentsAsync(int id);
}

public class PostRepository : Repository<Post>, IPostRepository
{
    public PostRepository(BlogDbContext context) : base(context)
    {
    }
    
    public async Task<List<Post>> GetRecentPostsAsync(int count)
    {
        return await dbSet
            .OrderByDescending(p => p.PublishedAt)
            .Take(count)
            .Include(p => p.Author)
            .ToListAsync();
    }
    
    public async Task<List<Post>> GetPostsByAuthorAsync(int authorId)
    {
        return await dbSet
            .Where(p => p.AuthorId == authorId)
            .OrderByDescending(p => p.PublishedAt)
            .ToListAsync();
    }
    
    public async Task<Post> GetPostWithCommentsAsync(int id)
    {
        return await dbSet
            .Include(p => p.Author)
            .Include(p => p.Comments)
                .ThenInclude(c => c.User)
            .Include(p => p.Tags)
            .FirstOrDefaultAsync(p => p.Id == id);
    }
}
```

```csharp
// Program.cs
var builder = WebApplication.CreateBuilder(args);

// 注册 DbContext
builder.Services.AddDbContext<BlogDbContext>(options =>
    options.UseSqlite(builder.Configuration.GetConnectionString("DefaultConnection")));

builder.Services.AddScoped<IPostRepository, PostRepository>();

[ApiController]
[Route("api/[controller]")]
public class PostsController : ControllerBase

    private readonly IPostRepository postRepository;

    {
        this.postRepository = postRepository;
    }
    
    [HttpGet]
    public async Task<ActionResult<List<Post>>> GetAll()
    {
        var posts = await postRepository.GetAllAsync();
        return Ok(posts);
    }
    
    [HttpGet("recent/{count}")]
    public async Task<ActionResult<List<Post>>> GetRecent(int count)
    {
        var posts = await postRepository.GetRecentPostsAsync(count);
        return Ok(posts);
    }
    
    [HttpGet("{id}")]
    public async Task<ActionResult<Post>> GetById(int id)
    {
        var post = await postRepository.GetPostWithCommentsAsync(id);
        if (post == null)
            return NotFound();
            
        return Ok(post);
    }
    
    [HttpPost]
    public async Task<ActionResult<Post>> Create([FromBody] Post post)
    {
        post.PublishedAt = DateTime.Now;
        var created = await postRepository.AddAsync(post);
        return CreatedAtAction(nameof(GetById), new { id = created.Id }, created);
    }
}
```

```csharp
        AuthorName = p.Author.Username,
        CommentCount = p.Comments.Count
    })
    .ToListAsync();
```

### 3. 批量操作

```csharp
// 使用 AddRange 而不是多次 Add
context.Users.AddRange(users);
await context.SaveChangesAsync();
```
