# 纹理大师：GLSL 中的贴图艺术与未来之路

在 3D 渲染中，纹理让模型从"灰模"变得栩栩如生。但对 Shader 程序员来说，纹理不只是一张 JPG——它是一个**只读的二维数组**，可以存储颜色、高度、法线，甚至任意数据。

前置阅读：
- [GLSL 新手指南](/posts/glsl/getting-started-with-glsl)——你需要理解 uniform 和 sampler2D
- [法线深入](/posts/glsl/understanding-normals)——法线贴图是纹理的重要应用

## 一、纹理采样：把图片贴上去

GLSL 中读取纹理颜色叫**采样 (Sampling)**，需要两个东西：

1. `uniform sampler2D uTexture;`：纹理数据
2. `varying vec2 vUv;`：采样坐标 (0.0 到 1.0)

核心函数：`texture2D(uTexture, vUv)` → 返回 `vec4` (RGBA)

<ShaderPreview title="Texture Simulation" code={`
varying vec2 vUv;

vec3 getTexture(vec2 uv) {
    vec2 grid = step(0.5, fract(uv * 10.0));
    float check = mod(grid.x + grid.y, 2.0);
    return vec3(check);
}

void main() {
    vec3 color = getTexture(vUv);
    gl_FragColor = vec4(color, 1.0);
}
`} />

## 二、纹理参数：Wrap、Filter、Format

纹理不只是"一张图"。GPU 如何处理坐标超出 [0,1] 的情况？如何处理放大缩小时的像素？这些由三个参数控制。

### 1. Wrap Mode：坐标超出 [0,1] 怎么办？

| 模式 | 效果 | 用途 |
|---|---|---|
| ClampToEdge | 超出部分用边缘颜色 | 避免边缘接缝 |
| Repeat | 无限重复 | 瓷砖、网格 |
| MirroredRepeat | 镜像重复 | 避免重复感太强 |

<ShaderPreview title="Wrap Modes" code={`
varying vec2 vUv;

vec3 getTexture(vec2 uv) {
    vec2 grid = step(0.5, fract(uv * 3.0));
    float check = mod(grid.x + grid.y, 2.0);
    return vec3(check * 0.8 + 0.1);
}

void main() {
    // 左: Repeat (fract 无限重复)
    // 中: MirroredRepeat (镜像)
    // 右: Clamp (clamp 到 0~1)

    float mode = vUv.x;

    // 超出 [0,1] 的 UV 范围
    vec2 uv = (vUv - 0.5) * 3.0;

    vec3 color;
    if (mode < 0.33) {
        // Repeat: fract
        color = getTexture(fract(uv));
    } else if (mode < 0.66) {
        // MirroredRepeat
        vec2 mUV = mod(uv, 4.0);
        mUV = mix(mUV, 2.0 - mUV, step(2.0, mUV));
        // 简化的镜像：每两格镜像一次
        vec2 f = fract(uv);
        float quadrant = floor(mod(uv.x, 2.0));
        if (quadrant > 0.5) f.x = 1.0 - f.x;
        quadrant = floor(mod(uv.y, 2.0));
        if (quadrant > 0.5) f.y = 1.0 - f.y;
        color = getTexture(f);
    } else {
        // Clamp
        color = getTexture(clamp(uv, 0.0, 1.0));
    }

    // 分割线
    float div1 = smoothstep(0.005, 0.0, abs(vUv.x - 0.33));
    float div2 = smoothstep(0.005, 0.0, abs(vUv.x - 0.66));
    color = mix(color, vec3(1.0, 0.3, 0.0), div1 + div2);

    gl_FragColor = vec4(color, 1.0);
}
`} />

在 Three.js 中设置：

```javascript
const texture = new THREE.TextureLoader().load('image.jpg');
texture.wrapS = THREE.RepeatWrapping;       // 水平方向重复
texture.wrapT = THREE.MirroredRepeatWrapping; // 垂直方向镜像重复
texture.repeat.set(3, 3);                    // 重复 3×3 次
```

### 2. Filter Mode：放大缩小时怎么插值？

| 模式 | 放大时 | 缩小时 | 性能 |
|---|---|---|---|
| Nearest | 最近邻（锯齿） | 最近邻 | 最快 |
| Linear | 双线性插值（模糊） | 双线性 | 中等 |
| Trilinear | 双线性 | 三线性（Mipmap） | 较慢 |

**Mipmap**：GPU 自动生成一系列缩小版纹理（1/2, 1/4, 1/8...）。缩小时选择最接近的层级采样，避免走样（摩尔纹）。

```javascript
texture.minFilter = THREE.LinearMipMapLinearFilter; // 缩小时用三线性
texture.magFilter = THREE.LinearFilter;              // 放大时用双线性
texture.anisotropy = renderer.capabilities.getMaxAnisotropy(); // 各向异性过滤
```

**各向异性过滤 (Anisotropic Filtering)**：当纹理被倾斜观察时（比如地面），标准 Mipmap 会过度模糊。各向异性过滤沿多个方向采样，保持细节。对地面纹理效果提升极大。

### 3. Texture Format：存什么类型的数据？

| 格式 | 类型 | 精度 | 用途 |
|---|---|---|---|
| RGBA8 | UnsignedByte | 0~255 整数 | 颜色贴图 |
| RGBA16F | HalfFloat | 16 位浮点 | HDR、位置数据 |
| RGBA32F | Float | 32 位浮点 | GPGPU 数据 |
| Depth | Float | 24/32 位 | 阴影映射、DOF |

```javascript
// 普通颜色纹理
const colorTexture = new THREE.TextureLoader().load('color.jpg');
// 内部格式: RGBA8

// GPGPU 浮点纹理
const dataTexture = new THREE.DataTexture(float32Array, width, height);
dataTexture.format = THREE.RGBAFormat;
dataTexture.type = THREE.FloatType; // 关键：浮点精度
```

:::tip 为什么法线贴图是蓝紫色的？
法线贴图存的是切线空间法线。未扰动的法线是 (0, 0, 1)，映射到颜色就是 (128, 128, 255)——蓝紫色。偏红说明法线偏向 X+，偏绿说明偏向 Y+。
:::

## 三、纹理坐标变换：扭曲与特效

修改 UV 坐标 = 纹理变形。这是水波纹、热浪、马赛克等效果的原理。

### 1. 马赛克 (Pixelation)

把连续的 UV 变成离散的阶梯：

```glsl
vec2 pixelUV = floor(vUv * pixels) / pixels;
vec3 color = texture2D(uTexture, pixelUV).rgb;
```

<ShaderPreview title="Pixelation" code={`
varying vec2 vUv;

vec3 getTexture(vec2 uv) {
    return vec3(uv.x, uv.y, 0.5 + 0.5 * sin(uv.x * 10.0));
}

void main() {
    float pixels = 20.0;
    vec2 pixelUV = floor(vUv * pixels) / pixels;
    vec3 color = getTexture(pixelUV);
    gl_FragColor = vec4(color, 1.0);
}
`} />

### 2. 水波扭曲 (Distortion)

用 sin 让 UV 坐标偏移：

<ShaderPreview title="Water Ripple" code={`
uniform float uTime;
varying vec2 vUv;

vec3 getTexture(vec2 uv) {
    float d = length(uv - 0.5);
    float circles = step(0.5, sin(d * 40.0));
    return vec3(circles);
}

void main() {
    vec2 uv = vUv;
    uv.x += sin(uv.y * 10.0 + uTime) * 0.05;
    uv.y += cos(uv.x * 10.0 + uTime) * 0.05;
    vec3 color = getTexture(uv);
    gl_FragColor = vec4(color, 1.0);
}
`} />

### 3. 旋涡扭曲 (Vortex)

以某个点为中心，根据距离旋转 UV：

<ShaderPreview title="Vortex Distortion" code={`
uniform float uTime;
varying vec2 vUv;

vec3 getTexture(vec2 uv) {
    vec2 grid = step(0.5, fract(uv * 8.0));
    float check = mod(grid.x + grid.y, 2.0);
    return vec3(check * 0.8 + 0.1);
}

void main() {
    vec2 uv = vUv - 0.5; // 移到中心

    float dist = length(uv);
    float angle = atan(uv.y, uv.x);

    // 距离中心越近，旋转角度越大
    angle += (1.0 - dist) * uTime * 2.0;

    uv = vec2(cos(angle), sin(angle)) * dist + 0.5;

    vec3 color = getTexture(uv);
    gl_FragColor = vec4(color, 1.0);
}
`} />

## 四、程序化纹理：不需要图片

除了加载图片，还可以用代码生成纹理——无限分辨率，不占显存，可以动态变化。

### FBM (分形布朗运动)

FBM 通过叠加不同频率的噪声生成云层、地形等自然纹理。在 [读懂 The Book of Shaders](/posts/glsl/book-of-shaders-summary) 中有详细的噪声推导，这里直接使用：

<ShaderPreview title="Procedural Cloud" code={`
uniform float uTime;
varying vec2 vUv;

float random(vec2 st) {
    return fract(sin(dot(st, vec2(12.9898, 78.233))) * 43758.5453);
}

float noise(vec2 st) {
    vec2 i = floor(st);
    vec2 f = fract(st);
    vec2 u = f * f * (3.0 - 2.0 * f);
    float a = random(i);
    float b = random(i + vec2(1.0, 0.0));
    float c = random(i + vec2(0.0, 1.0));
    float d = random(i + vec2(1.0, 1.0));
    return mix(a, b, u.x) + (c - a) * u.y * (1.0 - u.x) + (d - b) * u.x * u.y;
}

float fbm(vec2 st) {
    float value = 0.0;
    float amplitude = 0.5;
    for (int i = 0; i < 5; i++) {
        value += amplitude * noise(st);
        st *= 2.0;
        amplitude *= 0.5;
    }
    return value;
}

void main() {
    vec2 st = vUv * 3.0;
    float n = fbm(st + vec2(uTime * 0.2, 0.0));
    vec3 color = mix(vec3(0.0, 0.4, 0.8), vec3(1.0), n);
    gl_FragColor = vec4(color, 1.0);
}
`} />

FBM 的核心：每次迭代，频率翻倍 (`st *= 2.0`)，振幅减半 (`amplitude *= 0.5`)。这模拟了自然界的自相似性——大尺度有大的起伏，小尺度有小的细节。

## 五、多种纹理配合工作

在 PBR 工作流中，多种纹理同时使用：

```javascript
const material = new THREE.MeshStandardMaterial({
  map: albedoTexture,           // RGB：基础颜色
  normalMap: normalTexture,     // RGB：法线扰动
  metalnessMap: metallicTexture, // R：金属度
  roughnessMap: roughnessTexture, // R：粗糙度
  aoMap: aoTexture,             // R：环境光遮蔽
  emissiveMap: emissiveTexture, // RGB：自发光
});
```

这些纹理在 Fragment Shader 中被依次采样，每个像素的最终颜色由所有纹理的值共同决定。
