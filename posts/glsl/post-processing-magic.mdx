# 后期魔法：让画面从"能看"变"电影感"

在电影制作中，拍完片子还要调色、特效合成。实时渲染也有同样的流程——**后期处理 (Post-Processing)**。

核心原理：**先渲染整个场景到一张纹理 (RenderTarget)，再用 Shader 处理这张纹理，最后显示到屏幕上。**

前置阅读：
- [图形学世界观](/posts/glsl/the-big-picture)——你需要理解渲染管线中 Fragment Shader 的输出
- [摄像机系统](/posts/glsl/camera-systems)——DOF 依赖深度信息，深度来自相机

## 一、后期处理的根基：RenderTarget

正常的渲染流程：画场景 → 直接显示到屏幕。

后期处理多了一步：

```
画场景 → 渲染到 RenderTarget（纹理） → Shader 处理纹理 → 显示到屏幕
```

### 1. Three.js 中的 RenderTarget

`WebGLRenderTarget` 就是一块"虚拟屏幕"——你可以往上面渲染，但用户看不到。渲染完成后，结果存在纹理中，可以被下一个 Shader 采样。

```javascript
import * as THREE from 'three';
import { EffectComposer } from 'three/examples/jsm/postprocessing/EffectComposer';
import { RenderPass } from 'three/examples/jsm/postprocessing/RenderPass';
import { ShaderPass } from 'three/examples/jsm/postprocessing/ShaderPass';

// 1. 创建 EffectComposer
const composer = new EffectComposer(renderer);

// 2. 第一 Pass：渲染场景到纹理
const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

// 3. 后续 Pass：各种后期处理 Shader
// 每个 ShaderPass 就是一个 Fragment Shader
const customPass = new ShaderPass({
  uniforms: {
    tDiffuse: { value: null },  // 上一个 Pass 的输出纹理
    uStrength: { value: 1.0 },
  },
  vertexShader: `
    varying vec2 vUv;
    void main() {
      vUv = uv;
      gl_Position = projectionMatrix * modelViewMatrix * vec4(position, 1.0);
    }
  `,
  fragmentShader: `
    uniform sampler2D tDiffuse;
    uniform float uStrength;
    varying vec2 vUv;
    void main() {
      vec4 color = texture2D(tDiffuse, vUv);
      // 在这里做后期处理...
      gl_FragColor = color;
    }
  `,
});
composer.addPass(customPass);

// 4. 渲染循环中用 composer 代替 renderer
function animate() {
  composer.render();  // 替代 renderer.render(scene, camera)
  requestAnimationFrame(animate);
}
```

**关键**：`tDiffuse` 是上一个 Pass 的输出纹理，Three.js 自动传递。每个 Pass 的输出自动成为下一个 Pass 的输入。

## 二、Bloom (辉光)：光的溢出

现实中极亮的光源（太阳、霓虹灯）周围有一圈光晕——这是镜头散射或人眼衍射。Bloom 模拟这种"光线溢出"。

### 1. Bloom 的三步

```
1. 提取高亮 (Threshold)：亮度超过阈值的像素保留，其他变黑
2. 高斯模糊 (Blur)：对高亮图做多次模糊
3. 叠加 (Add)：模糊图 + 原图
```

### 2. 高斯模糊：为什么要分两遍？

直接做 2D 模糊需要 $N^2$ 次采样（N×N 的核）。但高斯核是**可分离的**——先横向模糊一次（N 次采样），再纵向模糊一次（N 次采样），结果等价但只需 2N 次采样。

这是后期处理中最重要的优化：

```javascript
// 横向模糊 Pass
const hBlurPass = new ShaderPass({
  uniforms: {
    tDiffuse: { value: null },
    uResolution: { value: new THREE.Vector2(width, height) },
  },
  vertexShader: `...`,
  fragmentShader: `
    uniform sampler2D tDiffuse;
    uniform vec2 uResolution;
    varying vec2 vUv;

    void main() {
      vec2 texelSize = 1.0 / uResolution;
      vec3 sum = vec3(0.0);

      // 9 点高斯核（1D）
      // 权重：[0.05, 0.1, 0.15, 0.4, 0.15, 0.1, 0.05]（近似）
      float weights[7];
      weights[0] = 0.05;
      weights[1] = 0.1;
      weights[2] = 0.15;
      weights[3] = 0.4;
      weights[4] = 0.15;
      weights[5] = 0.1;
      weights[6] = 0.05;

      for (int i = -3; i <= 3; i++) {
        vec2 offset = vec2(float(i) * texelSize.x, 0.0); // 只横向
        sum += texture2D(tDiffuse, vUv + offset).rgb * weights[i + 3];
      }

      gl_FragColor = vec4(sum, 1.0);
    }
  `,
});

// 纵向模糊 Pass（代码类似，offset 改为 vec2(0, i * texelSize.y)）
```

**高斯核的权重**：中心权重最大，两边递减，总和为 1。这就是正态分布（钟形曲线）的离散化。

### 3. Bloom 的完整管线

```javascript
const composer = new EffectComposer(renderer);

// Pass 1: 渲染场景
composer.addPass(new RenderPass(scene, camera));

// Pass 2: 提取高亮
composer.addPass(new ShaderPass(LuminosityHighPassShader));

// Pass 3: 横向模糊
composer.addPass(hBlurPass);

// Pass 4: 纵向模糊
composer.addPass(vBlurPass);

// Pass 5: 叠加回原图
composer.addPass(new ShaderPass(CopyShader));
```

Three.js 内置了 `UnrealBloomPass`，自动完成所有步骤：

```javascript
import { UnrealBloomPass } from 'three/examples/jsm/postprocessing/UnrealBloomPass';

const bloomPass = new UnrealBloomPass(
  new THREE.Vector2(width, height),
  1.5,   // 强度 (strength)
  0.4,   // 半径 (radius)
  0.85   // 阈值 (threshold)
);
composer.addPass(bloomPass);
```

varying vec2 vUv;
uniform float uTime;

vec3 getScene(vec2 uv) {
    vec2 p = uv * 2.0 - 1.0;
    p.x += sin(uTime);
    float d = length(p);

    // 极亮的光源（亮度 > 1.0）
    float core = 1.0 - smoothstep(0.15, 0.2, d);
    vec3 color = vec3(3.0, 0.8, 0.1) * core; // HDR 橙色

    // 普通亮度的背景
    float grid = step(0.95, fract(uv.x * 10.0)) * 0.15;
    color += vec3(grid);

    return color;
}

vec3 extractBright(vec3 color, float threshold) {
    float brightness = dot(color, vec3(0.2126, 0.7152, 0.0722));
    return brightness > threshold ? color : vec3(0.0);
}

vec3 blur9(sampler2D tex, vec2 uv, vec2 resolution) {
    vec3 sum = vec3(0.0);
    vec2 texel = 1.0 / resolution;
    // 3x3 均值模糊（简化版，实际用高斯）
    for(float x = -1.0; x <= 1.0; x++) {
        for(float y = -1.0; y <= 1.0; y++) {
            vec2 offset = vec2(x, y) * texel * 4.0; // 模糊半径
            vec3 col = extractBright(getScene(uv + offset), 0.8);
            sum += col;
        }
    }
    return sum / 9.0;
}

void main() {
    vec2 uv = vUv;

    // 1. 原图
    vec3 original = getScene(uv);

    // 2. 提取高亮 + 模糊
    vec3 bloom = blur9(null, uv, vec2(800.0, 600.0));

    // 3. 叠加
    vec3 result = original + bloom * 1.5;

    // 简单的 tone mapping（防止过曝）
    result = result / (result + vec3(1.0));

    gl_FragColor = vec4(result, 1.0);
}
`} />

## 三、DOF (Depth of Field)：景深

大光圈拍摄时，焦点清晰，背景虚化。3D 渲染默认"无限景深"（全都清晰），需要手动制造虚化。

### 1. 原理

DOF 需要一张**深度图**（记录每个像素离相机的距离）。然后根据像素深度与焦平面的距离差，决定模糊程度：

```
CoC (Circle of Confusion) = |depth - focusDistance| × aperture
```

- CoC = 0 → 完全清晰
- CoC 越大 → 越模糊

### 2. 实现代码

```javascript
// 获取深度纹理
const depthTarget = new THREE.WebGLRenderTarget(width, height, {
  depthTexture: new THREE.DepthTexture(width, height),
  depthBuffer: true,
});

// DOF Shader
const dofFragmentShader = `
  uniform sampler2D tDiffuse;    // 场景颜色
  uniform sampler2D tDepth;      // 深度纹理
  uniform float uFocusDistance;  // 焦点距离
  uniform float uAperture;      // 光圈大小
  uniform float uMaxBlur;       // 最大模糊半径
  uniform vec2 uResolution;
  varying vec2 vUv;

  float getDepth(vec2 uv) {
    return texture2D(tDepth, uv).r;
  }

  void main() {
    float depth = getDepth(vUv);

    // 计算 CoC（模糊度）
    float coc = abs(depth - uFocusDistance) * uAperture;
    coc = min(coc, uMaxBlur);

    if (coc < 0.001) {
      // 焦点内，直接返回原图
      gl_FragColor = texture2D(tDiffuse, vUv);
      return;
    }

    // 根据 CoC 做盘形模糊 (Disk Blur)
    vec3 color = vec3(0.0);
    float totalWeight = 0.0;
    vec2 texelSize = 1.0 / uResolution;

    // 16 个采样点（盘形分布）
    for (int i = 0; i < 16; i++) {
      float angle = float(i) * 0.3927; // 2*PI/16
      float radius = coc * (0.5 + 0.5 * fract(sin(float(i) * 12.9898) * 43758.5453));
      vec2 offset = vec2(cos(angle), sin(angle)) * radius * texelSize;
      float weight = 1.0 - length(offset) / (coc * texelSize.x);
      color += texture2D(tDiffuse, vUv + offset).rgb * weight;
      totalWeight += weight;
    }

    gl_FragColor = vec4(color / totalWeight, 1.0);
  }
`;
```

```javascript
import { BokehPass } from 'three/examples/jsm/postprocessing/BokehPass';

const bokehPass = new BokehPass(scene, camera, {

composer.addPass(bokehPass);
```

## 四、抗锯齿 (Anti-Aliasing)

3D 渲染用方块像素逼近几何边缘，斜线必然有锯齿。

### 1. MSAA (Multisample AA)

在光栅化阶段，每个像素采样 4 次（硬件层面）。

- 优点：质量最好
- 缺点：显存和计算量 ×4，延迟渲染中难用

### 2. FXAA (Fast Approximate AA)

后期处理滤镜——找到对比度剧烈的边缘，沿边缘方向模糊。

- 优点：极快，几乎不掉帧
- 缺点：会模糊不该模糊的东西（如文字）

```javascript
import { FXAAShader } from 'three/examples/jsm/shaders/FXAAShader';

const fxaaPass = new ShaderPass(FXAAShader);
fxaaPass.uniforms['resolution'].value.set(1/width, 1/height);
composer.addPass(fxaaPass);
```

### 3. TAA (Temporal AA)

利用时间——当前帧复用上一帧（微小偏移后）的结果。

- 优点：效果极佳
- 缺点：快速移动时有鬼影 (Ghosting)

<ShaderPreview title="Anti-aliasing: Step vs Smoothstep" code={`
varying vec2 vUv;

void main() {
    vec2 uv = vUv;
    float d = length(uv - 0.5);

    // 左半：硬切 (step) → 锯齿
    // 右半：平滑过渡 (smoothstep) → 抗锯齿
    float isSmooth = step(0.5, uv.x);

    float aliased = step(d, 0.3);
    float antiAliased = 1.0 - smoothstep(0.29, 0.31, d);

    float shape = mix(aliased, antiAliased, isSmooth);

    vec3 color = vec3(shape);

    // 分割线
    if (abs(uv.x - 0.5) < 0.002) color = vec3(1.0, 0.3, 0.0);

    // 标签
    if (uv.y > 0.95) {
        color = isSmooth > 0.5 ? vec3(0.2, 0.8, 0.3) : vec3(0.8, 0.2, 0.2);
    }

    gl_FragColor = vec4(color, 1.0);
}
`} />

这个示例展示了最简单的抗锯齿原理：用 `smoothstep` 代替 `step`，在边缘产生 1-2 像素的渐变过渡，消除锯齿。FXAA 做的事情更复杂（检测边缘方向并沿边缘模糊），但核心思想相同——**在边缘做渐变而不是硬切**。

## 五、后期处理的性能考量

| 特效 | 性能开销 | 建议 |
|---|---|---|
| Bloom | 中（多次模糊 Pass） | 降低模糊分辨率可省 50% |
| DOF | 高（逐像素深度计算） | 只在必要时开启 |
| FXAA | 低（单 Pass） | 推荐始终开启 |
| SSAO | 中高（多次深度采样） | 减少采样核大小 |
| 色调映射 | 极低（单像素计算） | 始终开启 |

**经验法则**：后期处理的 Pass 数量与帧率成反比。移动端建议不超过 3 个 Pass，桌面端不超过 6 个。

## 总结

| 技术 | 原理 | 核心 Shader 操作 | Three.js 实现 |
|---|---|---|---|
| RenderTarget | 渲染到纹理 | `sampler2D tDiffuse` | `EffectComposer` |
| Bloom | 提取高亮 + 模糊 + 叠加 | Threshold + Blur + Add | `UnrealBloomPass` |
| DOF | 深度 → CoC → 模糊 | Depth 采样 + Disk Blur | `BokehPass` |
| FXAA | 边缘检测 + 沿边模糊 | Luma 梯度 + 混合 | `FXAAShader` |
| 分离模糊 | 2D 核 = 横向 1D × 纵向 1D | 两个 Pass | 自定义 ShaderPass |

后期处理是渲染管线的最后一道工序，也是性价比最高的——不改模型、不加光源，只是对像素做计算，就能大幅提升画面品质。
