# 深入理解法线 (Normal)：图形学光照的基石

在 3D 图形学中，有一个向量比位置 (`position`) 更重要，它决定了物体看起来是平的还是圆的，是凹的还是凸的。它就是**法线 (Normal)**。

如果你想理解光照、反射、凹凸贴图，或者任何涉及物体表面质感的技术，你必须先搞懂法线。

## 一、 什么是法线？

简单来说，**法线就是垂直于表面的方向。**

想象一个放在桌面上的皮球。
*   在球的最顶端，法线指向**正上方**。
*   在球的最右侧，法线指向**正右方**。

在 GLSL 中，法线通常是一个**归一化向量** (长度为 1.0)。

<ShaderPreview title="Normal Visualization" code={`
varying vec2 vUv;

void main() {
    // 1. 模拟一个球体表面
    vec2 p = vUv * 2.0 - 1.0;
    float r = length(p);
    
    if (r > 1.0) {
        gl_FragColor = vec4(0.0, 0.0, 0.0, 1.0);
        return;
    }
    
    // 2. 计算法线
    // 球面上任意一点的法线，就是从球心指向该点的向量
    float z = sqrt(1.0 - p.x*p.x - p.y*p.y);
    vec3 normal = vec3(p.x, p.y, z);
    
    // 3. 可视化法线
    // 法线范围是 -1 到 1，颜色范围是 0 到 1
    // 我们把法线映射到颜色： normal * 0.5 + 0.5
    gl_FragColor = vec4(normal * 0.5 + 0.5, 1.0);
}
`} />

**看懂法线颜色：**
*   **蓝色 (0, 0, 1)**：法线指向屏幕外 (Z+)，即正对着你。
*   **红色 (1, 0, 0)**：法线指向右边 (X+)。
*   **绿色 (0, 1, 0)**：法线指向上方 (Y+)。

这种五颜六色的球，在图形学调试中随处可见，它就是法线的身份证。

## 二、 面法线 vs 顶点法线

这是初学者最容易混淆的概念。

### 1. 面法线 (Face Normal)
**"这块三角形朝向哪？"**
对于一个平整的三角形，它上面所有点的法线都是一样的。
*   **效果**：物体看起来棱角分明，像钻石或低模 (Low Poly) 风格。

### 2. 顶点法线 (Vertex Normal)
**"这个角朝向哪？"**
我们只定义三角形三个顶点的法线。对于三角形内部的点，GPU 会自动在三个顶点之间进行**插值**（渐变）。
*   **效果**：物体看起来非常光滑，像一个圆滑的球，即使它其实是由三角形拼成的。

**结论**：大部分时候我们使用**顶点法线** (`varying vec3 vNormal`) 来获得平滑的光照效果。

## 三、 法线与光照

为什么法线这么重要？因为光照公式的核心就是**点积**：

`Brightness = dot(LightDirection, Normal)`

*   如果法线正对着光 (`angle = 0`), `dot = 1` (最亮)。
*   如果法线和光垂直 (`angle = 90`), `dot = 0` (黑)。

**这意味着：如果我们欺骗了法线，我们就欺骗了光照。**

## 四、 法线贴图 (Normal Mapping)

如果我想在一个光滑的球面上画出砖块的凹凸感，难道我要把模型的顶点加到几百万个吗？
不需要。我们只需要**修改法线**。

**法线贴图**就是一张特殊的图片（通常是蓝紫色的）。它不存颜色，它存的是**每个像素点的法线方向**。

*   **原理**：在 Fragment Shader 中，我们不再使用几何体的真实法线，而是去读取这张贴图里的法线。
*   **结果**：光照计算时，以为表面有凹凸，于是产生了明暗变化。实际上模型还是平的！

<ShaderPreview title="Fake Bump" code={`
varying vec2 vUv;
uniform float uTime;

void main() {
    // 1. 基础平面法线 (指向屏幕外)
    vec3 normal = vec3(0.0, 0.0, 1.0);
    
    // 2. 模拟法线贴图
    // 我们用正弦波来扰动法线
    // 让法线左右摇摆 (修改 x 分量)
    normal.x += sin(vUv.y * 20.0 + uTime) * 0.5;
    normal = normalize(normal); // 必须归一化！
    
    // 3. 计算光照
    vec3 lightDir = normalize(vec3(1.0, 1.0, 1.0));
    float diff = max(dot(normal, lightDir), 0.0);
    
    // 显示光照结果
    // 注意看：虽然只是平面，但看起来像是有波浪起伏
    vec3 color = vec3(0.2, 0.5, 1.0) * (diff + 0.2);
    
    gl_FragColor = vec4(color, 1.0);
}
`} />

## 五、 如何计算法线？(导数魔法)

在 Ray Marching 或一些程序化纹理中，我们没有模型，也没有贴图，怎么知道法线？
我们可以利用**导数 (Derivative)**。

法线其实就是**高度变化最剧烈的方向**。
我们可以采样当前点旁边极小距离的两个点，算出高度差，就能推导出法线。

```glsl
vec3 calcNormal(vec3 p) {
    float d = 0.001; // 极小距离
    // 算出 x, y, z 三个轴向的梯度
    float dx = map(p + vec3(d, 0, 0)) - map(p - vec3(d, 0, 0));
    float dy = map(p + vec3(0, d, 0)) - map(p - vec3(0, d, 0));
    float dz = map(p + vec3(0, 0, d)) - map(p - vec3(0, 0, d));
    
    return normalize(vec3(dx, dy, dz));
}
```

## 总结

法线是图形学的魔法棒。

1.  **几何定义**：垂直于表面的单位向量。
2.  **可视化**：映射到 RGB 颜色 (蓝色=正面)。
3.  **光照核心**：`dot(N, L)` 决定亮度。
4.  **法线贴图**：通过修改法线，在平面上伪造凹凸细节。

掌握了法线，你就掌握了控制光影的钥匙。
