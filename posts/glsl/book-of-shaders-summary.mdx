# 读懂《The Book of Shaders》：给前端开发者的图形学启蒙

[The Book of Shaders](https://thebookofshaders.com/) 是学习 Fragment Shader 的必读经典。它不像传统图形学教材那样堆砌公式，而是像"魔法书"——教你用数学在屏幕上"无中生有"。

本文梳理书中的核心脉络，并对重点概念进行扩展和实战。

## 第一部分：算法绘画 (Algorithmic Drawing)

Shader 的核心思维：**摒弃 Canvas 2D 的"画笔"，拥抱"函数"。**

Canvas 里你说"画一个圆"，Shader 里你问"当前像素在不在圆内？"

### 1. 造型函数 (Shaping Functions)

如何不用 `if`，只用数学函数画形状？

| 函数 | 行为 | 用途 |
|---|---|---|
| `step(edge, x)` | x < edge → 0，否则 → 1 | 硬切边缘 |
| `smoothstep(a, b, x)` | 在 a~b 之间平滑过渡 | 抗锯齿、柔和边缘 |
| `fract(x)` | 取小数部分 | 重复图案 |
| `mix(a, b, t)` | 线性插值 | 颜色/数值混合 |

**用 smoothstep 画一条发光的线**：

<ShaderPreview title="Glowing Line" code={`
varying vec2 vUv;

float plot(vec2 pos, float point, float width) {
  float left = smoothstep(point - width, point, pos.y);
  float right = 1.0 - smoothstep(point, point + width, pos.y);
  return left * right;
}

void main() {
  vec2 st = vUv;
  float y = pow(st.x, 5.0);
  float pct = plot(st, y, 0.02);
  vec3 color = vec3(y);
  color = (1.0 - pct) * color + pct * vec3(0.0, 1.0, 0.0);
  gl_FragColor = vec4(color, 1.0);
}
`} />

**plot 函数的原理**：
- `smoothstep(point - width, point, pos.y)` 在线的下边缘从 0 渐变到 1
- `1.0 - smoothstep(point, point + width, pos.y)` 在线的上边缘从 1 渐变到 0
- 两者相乘 → 只在两条边缘之间为 1，其余为 0 → 一条带状区域

### 2. HSB 颜色：为什么用极坐标画彩虹？

RGB 直觉上很难画彩虹。HSB (色相/饱和度/亮度) 更适合——色相 (Hue) 就是一个 0~1 的角度值，直接映射到极坐标的角度就能画出圆环。

<ShaderPreview title="Color Wheel" code={`
#define TWO_PI 6.28318530718
varying vec2 vUv;

// HSB → RGB 转换
vec3 hsb2rgb(in vec3 c) {
    // 核心算法：把色相角度分成 6 段，
    // 每段对应 R/G/B 不同的上升和下降
    vec3 rgb = clamp(
        abs(mod(c.x * 6.0 + vec3(0.0, 4.0, 2.0), 6.0) - 3.0) - 1.0,
        0.0, 1.0
    );
    // 应用饱和度曲线，让过渡更平滑
    rgb = rgb * rgb * (3.0 - 2.0 * rgb);
    // 应用亮度和饱和度
    return c.z * mix(vec3(1.0), rgb, c.y);
}

void main() {
    vec2 st = vUv - 0.5;
    float angle = atan(st.y, st.x);        // 极坐标角度
    float radius = length(st) * 2.0;       // 极坐标半径

    float hue = angle / TWO_PI + 0.5;      // 角度 → 0~1 的色相
    float sat = radius;                     // 半径 → 饱和度
    vec3 color = hsb2rgb(vec3(hue, sat, 1.0));

    gl_FragColor = vec4(color, 1.0);
}
`} />

**HSB → RGB 的核心算法拆解**：

色相 H 是 0~1 的值，代表色环上的角度。把它乘以 6，分成 6 段，每段 60°：

```
0°~60°:   R=1, G 上升, B=0  → 红到黄
60°~120°: R 下降, G=1, B=0  → 黄到绿
120°~180°: R=0, G=1, B 上升 → 绿到青
180°~240°: R=0, G 下降, B=1 → 青到蓝
240°~300°: R 上升, G=0, B=1 → 蓝到紫
300°~360°: R=1, G=0, B 下降 → 紫到红
```

代码中 `c.x * 6.0 + vec3(0.0, 4.0, 2.0)` 给 R/G/B 各加一个偏移，让三条波形错开 120°。`abs(mod(...) - 3.0) - 1.0` 构造出锯齿波，`clamp` 截断到 [0,1]。`rgb * rgb * (3.0 - 2.0 * rgb)` 是 Hermite 平滑，让颜色过渡更自然。

### 3. 形状 (Shapes)：距离场 (SDF)

画矩形不需要 `if`，用 `step` 的乘法：

<ShaderPreview title="Rectangle SDF" code={`
varying vec2 vUv;

void main() {
    vec2 st = vUv;

    // 底部+左侧：超过 0.1 的部分
    vec2 bl = step(vec2(0.2), st);
    // 顶部+右侧：距右边超过 0.1 的部分
    vec2 tr = step(vec2(0.2), 1.0 - st);

    // 四边相乘：全部满足才为 1
    float pct = bl.x * bl.y * tr.x * tr.y;

    vec3 color = vec3(pct);
    gl_FragColor = vec4(color, 1.0);
}
`} />

SDF (有向距离场) 是距离场的升级版——不仅知道在不在形状内，还知道**离边界有多远**。这使得描边 (`abs(dist) < 0.01`)、外发光 (`exp(-dist * 10.0)`)、形状融合 (`smin`) 都变得简单。

### 4. 矩阵变换：移动坐标系，不是移动形状

<ShaderPreview title="Rotating Cross" code={`
varying vec2 vUv;
uniform float uTime;

mat2 rotate2d(float angle) {
    return mat2(cos(angle), -sin(angle),
                sin(angle),  cos(angle));
}

float box(vec2 st, vec2 size) {
    size = vec2(0.5) - size * 0.5;
    vec2 uv = smoothstep(size, size + vec2(0.001), st);
    uv *= smoothstep(size, size + vec2(0.001), vec2(1.0) - st);
    return uv.x * uv.y;
}

void main() {
    vec2 st = vUv;
    st -= vec2(0.5);                // 1. 原点移到中心
    st = rotate2d(sin(uTime) * 3.14) * st;  // 2. 旋转
    st += vec2(0.5);                // 3. 移回

    vec3 color = vec3(0.0);
    color += vec3(box(st, vec2(0.7, 0.2)));
    color += vec3(box(st, vec2(0.2, 0.7)));

    gl_FragColor = vec4(color, 1.0);
}
`} />

**关键顺序**：先平移到原点 → 再旋转 → 再平移回去。如果直接旋转，形状会绕屏幕左下角转而不是绕自己中心转。

### 5. 图案 (Patterns)：用 fract 制造重复

`fract(st * 10.0)` 把 [0,1] 的空间切成 10×10 个 [0,1] 的小格子。每个小格子内部坐标从 0 到 1——你在每个格子里画的图案会自动重复。

## 第二部分：生成式设计 (Generative Designs)

### 1. 伪随机 (Pseudo-random)

Shader 没有 `Math.random()`。经典的单行随机函数：

```glsl
float random(vec2 st) {
    return fract(sin(dot(st, vec2(12.9898, 78.233))) * 43758.5453);
}
```

**原理**：`sin` 是周期函数，但当我们给它一个很大的乘数 (43758.5453)，再取 `fract`（小数部分），微小的输入差异会导致输出剧烈变化——看起来就像随机了。

`12.9898` 和 `78.233` 是"魔法数字"——它们的选择影响随机质量，但没有特殊含义，只是实验发现效果好的值。

<ShaderPreview title="TV Static" code={`
varying vec2 vUv;
uniform float uTime;

float random(vec2 st) {
    return fract(sin(dot(st, vec2(12.9898, 78.233))) * 43758.5453);
}

void main() {
    float rnd = random(vUv + uTime);
    gl_FragColor = vec4(vec3(rnd), 1.0);
}
`} />

### 2. Value Noise：从随机到平滑

纯随机太刺眼。自然界的随机是**平滑的**——云、山脉、水波。

Value Noise 的做法：在网格点上放随机数，然后在点之间**平滑插值**。

<ShaderPreview title="Value Noise" code={`
varying vec2 vUv;
uniform float uTime;

float random(vec2 st) {
    return fract(sin(dot(st, vec2(12.9898, 78.233))) * 43758.5453);
}

float noise(vec2 st) {
    vec2 i = floor(st);  // 网格索引
    vec2 f = fract(st);  // 网格内坐标

    // 四个角的随机值
    float a = random(i);
    float b = random(i + vec2(1.0, 0.0));
    float c = random(i + vec2(0.0, 1.0));
    float d = random(i + vec2(1.0, 1.0));

    // Hermite 平滑插值曲线：f² × (3 - 2f)
    // 比线性插值平滑（一阶导数连续）
    vec2 u = f * f * (3.0 - 2.0 * f);

    // 双线性插值
    return mix(a, b, u.x) +
           (c - a) * u.y * (1.0 - u.x) +
           (d - b) * u.x * u.y;
}

void main() {
    vec2 st = vUv * 5.0;
    float n = noise(st + vec2(uTime * 0.5));
    gl_FragColor = vec4(vec3(n), 1.0);
}
`} />

**Hermite 曲线 `f² × (3 - 2f)` 的作用**：

线性插值在网格边界处有"折角"（导数不连续）。Hermite 曲线让过渡更平滑——在 0 和 1 处导数都是 0，所以边界处不会出现突兀的变化。

### 3. FBM (分形布朗运动)：叠加噪声

单一频率的噪声太平坦。FBM 叠加多个频率的噪声：

```
fBM(x) = noise(x) + 0.5 × noise(2x) + 0.25 × noise(4x) + ...
```

每次频率翻倍，振幅减半。这模拟了自然界的自相似性——山脉有大起伏，也有小褶皱，还有细微的沙砾纹理。

<ShaderPreview title="FBM Interactive" code={`
uniform float uTime;
varying vec2 vUv;

float random(vec2 st) {
    return fract(sin(dot(st, vec2(12.9898, 78.233))) * 43758.5453);
}

float noise(vec2 st) {
    vec2 i = floor(st);
    vec2 f = fract(st);
    vec2 u = f * f * (3.0 - 2.0 * f);
    float a = random(i);
    float b = random(i + vec2(1.0, 0.0));
    float c = random(i + vec2(0.0, 1.0));
    float d = random(i + vec2(1.0, 1.0));
    return mix(a, b, u.x) + (c - a) * u.y * (1.0 - u.x) + (d - b) * u.x * u.y;
}

// FBM：叠加多个频率
float fbm(vec2 st) {
    float value = 0.0;
    float amplitude = 0.5;
    float frequency = 1.0;
    for (int i = 0; i < 6; i++) {
        value += amplitude * noise(st * frequency);
        frequency *= 2.0;    // 频率翻倍
        amplitude *= 0.5;    // 振幅减半
    }
    return value;
}

void main() {
    vec2 st = vUv * 4.0;

    // Domain Warping：用 FBM 的输出扭曲输入坐标
    // 产生更有机的图案
    vec2 q = vec2(
        fbm(st + vec2(0.0, 0.0)),
        fbm(st + vec2(5.2, 1.3))
    );

    // 用扭曲后的坐标再算一次 FBM
    float n = fbm(st + 4.0 * q + vec2(uTime * 0.1));

    // 颜色映射
    vec3 color = mix(vec3(0.1, 0.2, 0.4), vec3(0.8, 0.6, 0.3), n);
    color = mix(color, vec3(0.9, 0.9, 0.8), smoothstep(0.6, 0.8, n));

    gl_FragColor = vec4(color, 1.0);
}
`} />

**Domain Warping**（域扭曲）是 FBM 的高级用法：用一次 FBM 的输出来扭曲下一次 FBM 的输入。这产生了极其有机的、像大理石纹理或云层的效果。

### 4. FBM 的参数

| 参数 | 效果 | 典型值 |
|---|---|---|
| 层数 (octaves) | 细节丰富度 | 4~8 层 |
| 振幅衰减 (lacunarity) | 高频细节的强度 | 0.5 (每层减半) |
| 频率增长 (gain) | 高频的密度 | 2.0 (每层翻倍) |

## 总结

《The Book of Shaders》教给我们的不只是 GLSL 语法，而是一种**思维方式**：

- **函数思维**：不要"画一个圆"，问"这个像素在不在圆内"
- **坐标系思维**：移动坐标系，而不是移动形状
- **距离场思维**：用距离而不是布尔值描述形状
- **频率思维**：叠加不同频率的噪声，模拟自然界的层次

学习建议：在编辑器里多动手调试——把 `0.0` 改成 `1.0`，把 `sin` 改成 `cos`，你会发现意外的惊喜。
