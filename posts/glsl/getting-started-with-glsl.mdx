# GLSL 新手指南：带你走进 Shader 的奇妙世界

如果你是一个前端开发者，或者对计算机图形感兴趣，你可能听说过 "Shader"（着色器）这个词。也许你见过那些炫酷的 3D 网页背景，或者游戏里逼真的水面和火焰效果。

其实，这些魔法背后，大都是 **GLSL** (OpenGL Shading Language) 在发挥作用。

别被"图形学"这三个字吓跑了！本文就是专门为你准备的。我们将抛开枯燥的数学公式，用最直观的方式，带你一步步揭开 GLSL 的神秘面纱。

## 什么是 GLSL？

简单来说，GLSL 是一门**运行在显卡 (GPU) 上的编程语言**。

*   **CPU (你的电脑大脑)**：擅长逻辑判断，比如点击按钮跳转页面，处理复杂的业务逻辑。就像一个精通所有学科的博士，但他只有一个（或几个）。
*   **GPU (你的显卡)**：擅长做简单的数学题，但它可以同时做成千上万道题！就像一万个小学生，虽然只会加减乘除，但如果让他们同时计算一万个像素的颜色，速度快得惊人。

GLSL 就是用来指挥这"一万个小学生"的语言。

## 它能干什么？

GLSL 的主要工作就是**决定屏幕上每个像素显示什么颜色**。

你能用它实现：
1.  **滤镜效果**：像 Instagram 那样的图片处理（黑白、模糊、故障风）。
2.  **动态背景**：流动的波浪、闪烁的星空、燃烧的火焰。
3.  **3D 材质**：金属的光泽、玻璃的折射、皮肤的质感。
4.  **数据可视化**：将百万级的数据点瞬间渲染到屏幕上。

## 核心概念：像素工厂

想象一下，你的屏幕就是一个巨大的网格，里面填满了像素。

在 GLSL 中，我们写的程序（主要是 **Fragment Shader**，片元着色器）会**同时**在每一个像素上运行。

这和我们平时写的 JavaScript 很不一样：
*   **JavaScript**: `for (let i = 0; i < pixels.length; i++) { ... }` (一个一个画)
*   **GLSL**: `main() { ... }` (所有像素同时画！)

因为它们同时运行，互不干扰，所以你**不能**在画这个像素的时候，去问旁边的像素是什么颜色。你只能根据**当前像素的位置**，通过数学公式算出它的颜色。

## 动手时刻：你的第一个 Shader

让我们从最简单的开始。GLSL 的代码结构很像 C 语言。

### 1. 你好，色彩！

在 GLSL 中，颜色用 `vec4` (4维向量) 表示，分别是 **红(R)、绿(G)、蓝(B)、透明度(A)**。范围是 `0.0` 到 `1.0`。

下面的代码把所有像素都涂成**红色**。

<ShaderPreview title="Hello Color" code={`
// 这两个变量是系统自动传给我们的
varying vec2 vUv; // 当前像素的坐标 (0,0 到 1,1)

void main() {
  // R=1.0 (满), G=0.0 (无), B=0.0 (无), A=1.0 (不透明)
  gl_FragColor = vec4(1.0, 0.0, 0.0, 1.0);
}
`} />

**试试看**：虽然这里不能直接编辑，但你可以想象，如果把 `vec4(1.0, 0.0, 0.0, 1.0)` 改成 `vec4(0.0, 1.0, 0.0, 1.0)`，画面会变成什么颜色？（答案是绿色！）

### 2. 认识坐标 (UV)

如果所有像素颜色都一样，那太无聊了。怎么画出图案呢？

这就需要用到 `vUv`。它是一个 `vec2` 变量，包含了当前像素的坐标：
*   `vUv.x`: 从左到右，由 0.0 渐变到 1.0
*   `vUv.y`: 从下到上，由 0.0 渐变到 1.0

利用这个坐标，我们可以制作一个渐变色：

<ShaderPreview title="坐标渐变" code={`
varying vec2 vUv;

void main() {
  // 把 X 坐标的值直接作为红色分量
  // 左边 (x=0) 是黑的，右边 (x=1) 是红的
  float red = vUv.x;
  
  // 把 Y 坐标的值直接作为绿色分量
  // 下边 (y=0) 无绿，上边 (y=1) 满绿
  float green = vUv.y;
  
  gl_FragColor = vec4(red, green, 0.0, 1.0);
}
`} />

看！左下角是黑的 (0,0)，右上角是黄的 (1,1，红+绿=黄)。这就是最基础的**数学绘图**。

### 3. 混合颜色 (mix)

GLSL 提供了很多强大的内置函数。`mix` 就是其中之一，用于在两个值之间进行插值（混合）。

`mix(颜色A, 颜色B, 比例)`：
*   比例为 0 时，显示颜色A
*   比例为 1 时，显示颜色B
*   比例为 0.5 时，显示两者的中间色

<ShaderPreview title="颜色混合" code={`
varying vec2 vUv;

void main() {
  vec3 colorA = vec3(0.0, 0.0, 1.0); // 纯蓝
  vec3 colorB = vec3(1.0, 0.5, 0.0); // 橙色
  
  // 根据 X 坐标混合
  // 左边是蓝，右边是橙，中间自动过渡
  vec3 finalColor = mix(colorA, colorB, vUv.x);
  
  gl_FragColor = vec4(finalColor, 1.0);
}
`} />

### 4. 绘制形状：画一个圆

在 GLSL 里画圆，其实就是做一道数学题：**"如果当前像素距离中心的距离小于半径，就涂白色，否则涂黑色"**。

我们需要用到 `length()` 函数来计算距离，用 `step()` 或 `smoothstep()` 来做判断。

<ShaderPreview title="绘制圆形" code={`
varying vec2 vUv;

void main() {
  // 1. 把坐标原点从左下角移到中心
  // 现在的坐标范围是 -0.5 到 0.5
  vec2 center = vUv - 0.5;
  
  // 2. 计算当前像素到中心的距离
  float dist = length(center);
  
  // 3. 画圆
  // 如果 dist < 0.2，返回 1.0 (白)
  // 如果 dist > 0.2，返回 0.0 (黑)
  // 0.2 是半径
  float circle = 1.0 - step(0.2, dist);
  
  gl_FragColor = vec4(vec3(circle), 1.0);
}
`} />

**新手提示**：为什么不用 `if (dist < 0.2)`？
虽然可以用，但在 GPU 上，`if` 分支语句的效率通常不如数学函数高。习惯用数学公式来表达逻辑是 Shader 编程的一大特点。

### 5. 让画面动起来 (Time)

静止的画面不够酷？我们需要引入**时间**。

在 CPU 端（JavaScript），我们会记录时间流逝，并把它传给 GPU，通常命名为 `uTime` (Uniform Time)。

我们可以用 `sin(uTime)` 函数，它会输出一个在 -1 到 1 之间不断循环波动的数值，非常适合做呼吸、摆动等效果。

<ShaderPreview title="动态呼吸" code={`
uniform float uTime; // 从 JS 传进来的时间
varying vec2 vUv;

void main() {
  vec2 center = vUv - 0.5;
  float dist = length(center);
  
  // 让半径随时间变化
  // sin(uTime) 范围是 -1 ~ 1
  // * 0.1 + 0.2 范围变成 0.1 ~ 0.3
  float radius = sin(uTime * 2.0) * 0.1 + 0.2;
  
  // 使用 smoothstep 让边缘变柔和
  float circle = 1.0 - smoothstep(radius, radius + 0.01, dist);
  
  // 加上颜色：随时间变色的圆
  vec3 color = vec3(circle) * vec3(0.5 + sin(uTime)*0.5, 0.5, 1.0);
  
  gl_FragColor = vec4(color, 1.0);
}
`} />

## 常见疑问 (Q&A)

**Q: 学习 GLSL 需要很好的数学基础吗？**
A: 入门不需要。你只需要理解加减乘除和基本的坐标系概念。当你想要做非常复杂的效果（如光线追踪、分形）时，才会用到高级数学。对于初学者，**向量**和**三角函数** (sin/cos) 是最重要的两个工具。

**Q: 我应该在哪里写 GLSL？**
A: 
1.  **Web 环境**: 使用 `Three.js` 或 `React Three Fiber` (本文演示用的就是这个)。
2.  **练习平台**: [ShaderToy](https://www.shadertoy.com/) 是最著名的 Shader 社区，你可以在浏览器里直接写代码看效果。
3.  **游戏引擎**: Unity 和 Unreal 也大量使用 Shader（语法略有不同，但原理通通）。

**Q: 为什么代码里变量名有时候是 vec3 有时候是 vec4？**
A: 
*   `vec3`: 通常表示 RGB 颜色，或者 XYZ 坐标。
*   `vec4`: 通常表示 RGBA 颜色（多一个透明度），或者 XYZW 坐标。
*   GLSL 允许你灵活转换，比如 `vec4(colorVec3, 1.0)` 就是把一个 3维颜色变成 4维颜色（加上透明度 1.0）。

## 下一步学什么？

恭喜你！你已经迈出了 Shader 编程的第一步。虽然我们今天只画了几个简单的图形，但原理是通用的。

接下来的学习建议：
1.  **玩转 ShaderToy**: 去看看别人写的 Shader，试着修改其中的数字，看看会发生什么。
2.  **学习《The Book of Shaders》**: 这是一本公认的最好的 GLSL 免费互动电子书，非常适合初学者。
3.  **尝试纹理 (Texture)**: 学习如何把图片传进 Shader，对其进行扭曲、马赛克等处理。

Shader 的世界充满了无限可能，从模仿现实到创造梦境，一切尽在你的指尖！
