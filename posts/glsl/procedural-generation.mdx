# 造物主的算法：程序化生成 (Procedural Generation)

在《我的世界》或《无人深空》中，地图是无限的。开发者没有手动放置每一棵树——他们写了**规则**，让计算机自己"生长"世界。

这就是**程序化生成 (PCG)**。今天介绍两个最经典的算法：L-System（生成植物）和 Marching Cubes（生成地形）。

前置阅读：
- [GLSL 语法速查](/posts/glsl/glsl-syntax-cheatsheet)——你需要熟悉 sin/cos/fract/step 等基础函数
- [几何工坊](/posts/glsl/geometry-deep-dive)——Marching Cubes 的输出就是 BufferGeometry

## 一、L-System：数字植物学

1968 年，生物学家 Lindenmayer 发明了一套系统模拟藻类生长。后来它成了计算机图形学生成树木的标准算法。

### 1. 核心原理：字符串重写

L-System 本质是一个**字符串替换游戏**，由三部分组成：

| 组成 | 含义 | 例子 |
|---|---|---|
| 公理 (Axiom) | 初始状态 | `"F"` (一根茎) |
| 规则 (Rule) | 生长法则 | `F → F[+F]F[-F]` |
| 迭代次数 | 重复几轮 | 4 次 |

规则的含义：每一段茎 (F) 长大后变成一段主茎，向右分出一根侧枝 `[+F]`，再向左分出一根侧枝 `[-F]`。

**迭代过程**：

```
迭代 0: F
迭代 1: F[+F]F[-F]
迭代 2: F[+F]F[-F][+F[+F]F[-F]]F[+F]F[-F][-F[+F]F[-F]]
...越来越复杂
```

### 2. 乌龟绘图 (Turtle Graphics)

生成字符串后，用"乌龟绘图"把它画出来：

| 符号 | 乌龟的动作 |
|---|---|
| F | 向前走一步，画一条线 |
| + | 右转 θ 度 |
| - | 左转 θ 度 |
| [ | 保存当前状态（位置+角度入栈） |
| ] | 恢复之前状态（出栈，回到分叉点） |

### 3. JavaScript 实现

因为 L-System 需要递归字符串替换，这在 GLSL 中几乎不可能（GLSL 没有动态字符串和递归）。我们用 JavaScript 生成字符串，然后渲染：

```javascript
class LSystem {
  constructor(axiom, rules, angle = 25) {
    this.axiom = axiom;
    this.rules = rules;
    this.angle = angle;
    this.current = axiom;
  }

  // 迭代一次
  iterate() {
    let next = '';
    for (const char of this.current) {
      next += this.rules[char] || char;
    }
    this.current = next;
  }

  // 迭代 N 次
  generate(n) {
    this.current = this.axiom;
    for (let i = 0; i < n; i++) {
      this.iterate();
    }
    return this.current;
  }

  // 转换为线段列表（乌龟绘图）
  toSegments(length = 1, shrink = 0.7) {
    const segments = [];
    const stack = [];
    let x = 0, y = 0, angle = 90; // 初始朝上
    let currentLength = length;

    for (const char of this.current) {
      switch (char) {
        case 'F':
          const newX = x + Math.cos(angle * Math.PI / 180) * currentLength;
          const newY = y + Math.sin(angle * Math.PI / 180) * currentLength;
          segments.push({ x1: x, y1: y, x2: newX, y2: newY });
          x = newX;
          y = newY;
          break;
        case '+':
          angle += this.angle;
          break;
        case '-':
          angle -= this.angle;
          break;
        case '[':
          stack.push({ x, y, angle, currentLength });
          currentLength *= shrink;
          break;
        case ']':
          const state = stack.pop();
          x = state.x;
          y = state.y;
          angle = state.angle;
          currentLength = state.currentLength;
          break;
      }
    }

    return segments;
  }
}

// 使用示例：生成一棵分形树
const tree = new LSystem('F', {
  'F': 'FF+[+F-F-F]-[-F+F+F]',
}, 22.5);

tree.generate(4);
const segments = tree.toSegments(0.5, 0.5);
console.log(`生成了 ${segments.length} 条线段`);
```

### 4. 常见规则集

| 名称 | 公理 | 规则 | 角度 | 效果 |
|---|---|---|---|---|
| 分形树 | F | F → FF+[+F-F-F]-[-F+F+F] | 22.5° | 树冠茂密的树 |
| 灌木 | F | F → F[+F]F[-F]F | 25.7° | 对称的灌木 |
| 龙曲线 | FX | X → X+YF+, Y → -FX-Y | 90° | 龙形曲线 |
| Koch 雪花 | F | F → F+F-F-F+F | 90° | 方形雪花 |

### 5. 在 Shader 中用 SDF 模拟分形树

GLSL 不能做字符串重写，但可以用**空间折叠**模拟分形结构：

<ShaderPreview title="SDF Fractal Tree" code={`
varying vec2 vUv;
uniform float uTime;

mat2 rot(float a) {
    float s = sin(a), c = cos(a);
    return mat2(c, -s, s, c);
}

float sdSegment(vec2 p, vec2 a, vec2 b) {
    vec2 pa = p - a, ba = b - a;
    float h = clamp(dot(pa, ba) / dot(ba, ba), 0.0, 1.0);
    return length(pa - ba * h);
}

void main() {
    vec2 uv = vUv * 2.0 - 1.0;
    uv.y += 0.8; // 移到底部

    float d = 1e5;
    float width = 0.015;
    vec2 p = uv;
    float scale = 1.0;

    // 用空间折叠模拟 4 级分形
    for (int i = 0; i < 5; i++) {
        // 1. 画主干
        float len = 0.4 / scale;
        d = min(d, sdSegment(p, vec2(0.0), vec2(0.0, len)) - width / scale);

        // 2. 移动到末端
        p.y -= len;

        // 3. 分形折叠：左右分叉
        p.x = abs(p.x); // 折叠到右边

        // 4. 旋转（分叉角度，随风摆动）
        float angle = 0.5 + sin(uTime * 2.0 + float(i) * 1.5) * 0.1;
        p = rot(angle) * p;

        // 5. 缩小坐标系
        scale *= 1.8;
    }

    // 着色
    float tree = smoothstep(0.002, 0.0, d);

    // 根据深度变色：底部棕色，顶部绿色
    float depth = (uv.y + 0.8) / 1.6;
    vec3 trunkColor = vec3(0.4, 0.25, 0.1);
    vec3 leafColor = vec3(0.2, 0.7, 0.15);
    vec3 color = mix(trunkColor, leafColor, depth) * tree;

    // 背景
    color += vec3(0.05, 0.08, 0.12) * (1.0 - tree);

    gl_FragColor = vec4(color, 1.0);
}
`} />

**空间折叠的原理**：

1. `p.x = abs(p.x)` 把空间沿 Y 轴折叠——左边和右边变成镜像。这等价于"同时画左枝和右枝"。
2. `p = rot(angle) * p` 旋转坐标系——等价于"分叉后枝条的方向偏转"。
3. 每次迭代，坐标系缩小 `1.8` 倍——等价于"越分越细"。

这种技巧比真正的递归 L-System 简单得多，但只能画对称的分形。对于更复杂的植物，还是需要 JS 端的 L-System 实现。

## 二、Marching Cubes：体素世界的构建者

《我的世界》的地形是方块状的。如果想要**平滑**的地形呢？你需要 **Marching Cubes**。

### 1. 标量场 (Scalar Field)

把 3D 空间切成小格子（体素），每个格子的 8 个顶点都有一个"密度值"：

- 值 > 阈值（0.5）→ 地下（实体）
- 值 < 阈值 → 空气

密度值可以用 3D 噪声函数生成，模拟自然地形。

### 2. 查表法

一个立方体有 8 个顶点，每个顶点要么在地下、要么在空气中 → $2^8 = 256$ 种情况。

Marching Cubes 预先计算好这 256 种情况下，**表面应该怎么穿过这个立方体**（生成哪些三角形），存在一个查找表里。

实际运行时，只需要查表就知道该画哪些三角形——不需要实时计算。

### 3. JavaScript 实现的核心逻辑

```javascript
// Marching Cubes 核心步骤

function marchingCubes(field, size, threshold) {
  const vertices = [];
  const indices = [];

  for (let z = 0; z < size - 1; z++) {
    for (let y = 0; y < size - 1; y++) {
      for (let x = 0; x < size - 1; x++) {
        // 1. 采样 8 个角的密度值
        const corners = [
          field[x][y][z],           // 0: 左下前
          field[x+1][y][z],         // 1: 右下前
          field[x+1][y][z+1],       // 2: 右下后
          field[x][y][z+1],         // 3: 左下后
          field[x][y+1][z],         // 4: 左上前
          field[x+1][y+1][z],       // 5: 右上前
          field[x+1][y+1][z+1],     // 6: 右上后
          field[x][y+1][z+1],       // 7: 左上后
        ];

        // 2. 计算 8 位索引：每个角在内部=1，外部=0
        let cubeIndex = 0;
        for (let i = 0; i < 8; i++) {
          if (corners[i] < threshold) cubeIndex |= (1 << i);
        }

        // 3. 查表：这个立方体要生成哪些边上的交点
        const edgeBits = EDGE_TABLE[cubeIndex];
        if (edgeBits === 0) continue; // 完全在内部或外部

        // 4. 对每条边做线性插值，算出表面交点
        const vertexList = new Array(12);
        for (let i = 0; i < 12; i++) {
          if (edgeBits & (1 << i)) {
            const [a, b] = EDGE_VERTICES[i];
            const t = (threshold - corners[a]) /
                      (corners[b] - corners[a]);
            vertexList[i] = lerp3D(
              cornerPosition(a, x, y, z),
              cornerPosition(b, x, y, z),
              t
            );
          }
        }

        // 5. 查三角表，生成三角形
        const triRows = TRI_TABLE[cubeIndex];
        for (let i = 0; triRows[i] !== -1; i += 3) {
          const idx = vertices.length / 3;
          vertices.push(...vertexList[triRows[i]]);
          vertices.push(...vertexList[triRows[i+1]]);
          vertices.push(...vertexList[triRows[i+2]]);
        }
      }
    }
  }

  return { vertices, indices };
}
```

**EDGE_TABLE 和 TRI_TABLE** 就是那 256 种情况的查找表。它们太大不便在此列出，但可以在 [Paul Bourke 的经典实现](http://paulbourke.net/geometry/polygonise/) 中找到完整版本。

### 4. 2D 版本：Marching Squares

<ShaderPreview title="Marching Squares (2D)" code={`
varying vec2 vUv;
uniform float uTime;

float noise(vec2 p) {
    return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
}

float smoothNoise(vec2 p) {
    vec2 i = floor(p);
    vec2 f = fract(p);
    f = f * f * (3.0 - 2.0 * f); // smoothstep

    float a = noise(i);
    float b = noise(i + vec2(1.0, 0.0));
    float c = noise(i + vec2(0.0, 1.0));
    float d = noise(i + vec2(1.0, 1.0));

    return mix(mix(a, b, f.x), mix(c, d, f.x), f.y);
}

float map(vec2 p) {
    // Metaballs：两个移动的场源
    vec2 c1 = vec2(0.3 + sin(uTime) * 0.2, 0.5);
    vec2 c2 = vec2(0.7 + cos(uTime * 0.7) * 0.2, 0.5 + sin(uTime * 0.8) * 0.2);

    float d1 = length(p - c1);
    float d2 = length(p - c2);

    return 0.08 / d1 + 0.08 / d2;
}

void main() {
    vec2 uv = vUv;

    float val = map(uv);
    float threshold = 1.0;

    // 1. 标量场可视化
    vec3 col = vec3(val * 0.15);

    // 2. Marching Squares 网格
    float gridSize = 12.0;
    vec2 gridUV = floor(uv * gridSize) / gridSize;
    vec2 cellUV = fract(uv * gridSize);

    // 网格线
    float gridLine = step(0.95, cellUV.x) + step(0.95, cellUV.y);
    col += vec3(0.1) * gridLine;

    // 3. 等值线（Marching Squares 的输出）
    float d = abs(val - threshold);
    float isoLine = 1.0 - smoothstep(0.0, 0.03, d);
    col = mix(col, vec3(1.0, 0.5, 0.0), isoLine);

    // 4. 内部/外部着色
    float inside = smoothstep(threshold - 0.1, threshold, val);
    col = mix(col, vec3(0.2, 0.5, 0.8) * inside, inside * 0.5);

    gl_FragColor = vec4(col, 1.0);
}
`} />

**看懂这个图**：

- **橙色线**：等值线（isoline），就是 Marching Squares 找到的"表面"
- **蓝色区域**：标量场值超过阈值的区域（"地下"）
- **网格**：Marching Squares 的格子

3D 版本（Marching Cubes）做的事情完全一样，只是把 2D 网格换成 3D 网格，把等值线换成三角形面片。

### 5. Three.js 中的 Marching Cubes

Three.js 内置了 Marching Cubes 实现：

```javascript
import { MarchingCubes } from 'three/examples/jsm/objects/MarchingCubes';

const resolution = 32; // 网格分辨率
const material = new THREE.MeshPhongMaterial({ color: 0xffffff });
const mesh = new MarchingCubes(resolution, material);

// 添加球体（metaball）
mesh.addBall(0.5, 0.5, 0.5, 0.3, 0.5); // x, y, z, strength, subtract

// 每帧更新
function animate() {
  mesh.reset();
  mesh.addBall(
    0.5 + Math.sin(time) * 0.2,
    0.5,
    0.5,
    0.3,
    0.5
  );
  renderer.render(scene, camera);
}
```

## 总结

| 算法 | 输入 | 输出 | 适用场景 |
|---|---|---|---|
| L-System | 字符串规则 | 线段/分支结构 | 树木、植物、分形 |
| SDF 折叠 | 坐标变换 | SDF 距离场 | Shader 中的对称分形 |
| Marching Cubes | 3D 标量场 | 三角形网格 | 地形、Metaball、CT 重建 |
| Marching Squares | 2D 标量场 | 等值线 | 2D 轮廓、热力图 |

L-System 适合生成**有结构**的东西（植物有枝干和分支），Marching Cubes 适合生成**无定形**的东西（地形、液体、云朵）。
