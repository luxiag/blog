# GLSL 实战演练：从入门到入土

欢迎来到 GLSL 训练场。
这里没有枯燥的理论，只有代码和像素。我们将通过四个循序渐进的案例，带你领略 Shader 编程的无限可能。

在开始之前，你需要了解一个关键前提：**Fragment Shader 是逐像素执行的**。你写的 `main()` 函数会对屏幕上的每一个像素各运行一次，`gl_FragColor` 就是你给这个像素上的颜色。你的任务就是：给定像素坐标，算出颜色。

每个案例都会按照"先讲原理，再给代码，最后逐行拆解"的方式展开。

## Level 1: 简单 —— 雷达扫描 (Radar Scan)

**目标**：制作一个科幻风格的雷达扫描效果。

**核心知识点**：极坐标、距离场、时间动画。

### 原理：为什么用极坐标？

雷达是圆形的，而 Shader 默认给我们的是直角坐标系 (x, y)。如果用 x、y 来画圆，你需要写 `x² + y² < r²` 之类的表达式，做旋转更是麻烦。

极坐标用 (r, θ) 表示点：r 是到圆心的距离，θ 是与正 x 轴的夹角。在极坐标下：

- 画同心圆 → 只需判断 `r` 的值
- 画旋转扫描线 → 只需让 `θ` 随时间偏移

这就是为什么雷达效果天然适合极坐标。

### 完整代码

<ShaderPreview title="Level 1: Radar" code={`
varying vec2 vUv;
uniform float uTime;

#define PI 3.14159265359

void main() {
    // 1. 转换坐标系：中心为 (0,0)
    vec2 st = vUv - 0.5;
    
    // 2. 转换为极坐标
    // 距离 r
    float r = length(st) * 2.0;
    // 角度 a (-PI 到 PI)
    float a = atan(st.y, st.x);
    
    // 3. 扫描线逻辑
    // 让扫描线随时间旋转
    // 归一化角度到 0-1 范围
    float angle = fract(a / (2.0 * PI) - uTime * 0.5);
    
    // 扫描拖尾效果：越接近 1.0 (扫描线位置) 越亮
    float beam = smoothstep(0.8, 1.0, angle);
    
    // 4. 雷达圈
    // 使用 fract 和 step 制作同心圆
    float circles = 1.0 - step(0.02, fract(r * 5.0));
    
    // 5. 限制雷达范围
    float mask = 1.0 - step(1.0, r);
    
    // 合成颜色
    vec3 color = vec3(0.0, 1.0, 0.5) * (beam + circles * 0.3) * mask;
    
    gl_FragColor = vec4(color, 1.0);
}
`} />

### 逐行拆解

#### 第 1 步：把坐标系中心移到画面正中

```glsl
vec2 st = vUv - 0.5;
```

`vUv` 是纹理坐标，范围是 `[0, 1]`，左下角是 (0,0)，右上角是 (1,1)。减去 0.5 后，`st` 的范围变成 `[-0.5, 0.5]`，画面中心变成了 (0, 0)。

**为什么？** 因为极坐标的计算需要以圆心为原点。如果不做这步偏移，你的雷达会以左下角为圆心，而不是画面中心。

#### 第 2 步：转换为极坐标

```glsl
float r = length(st) * 2.0;
float a = atan(st.y, st.x);
```

- `length(st)` 计算的是 `sqrt(st.x² + st.y²)`，即当前像素到原点的距离。乘以 2.0 是为了让 `r` 的范围从 `[0, 0.5]` 映射到 `[0, 1]`（因为 `st` 最大是 0.5），这样画面边缘恰好是 `r = 1`。
- `atan(st.y, st.x)` 就是反正切函数，返回角度 θ，范围是 `[-π, π]`。比如正 x 轴方向是 0，正 y 轴方向是 π/2。

#### 第 3 步：扫描线逻辑

```glsl
float angle = fract(a / (2.0 * PI) - uTime * 0.5);
float beam = smoothstep(0.8, 1.0, angle);
```

这是整个雷达效果最精妙的部分，我们拆开来看：

**`a / (2.0 * PI)`**：把角度从 `[-π, π]` 归一化到大约 `[−0.5, 0.5]` 的范围（因为 2π 是一圈，除以 2π 就得到"这是第几圈"的小数部分）。

**`- uTime * 0.5`**：减去时间值，让角度随时间递增，效果就是扫描线顺时针旋转。0.5 是旋转速度，你可以改成 1.0 让它转更快。

**`fract(...)`**：取小数部分，把值映射到 `[0, 1]`。想象一个 0 到 1 的色带首尾相连形成圆环，`fract` 确保值不会超出 0-1。

此时 `angle` 的含义是：**当前像素的角度距离扫描线有多远**。`angle = 1.0` 的位置就是扫描线本身，`angle = 0.0` 是扫描线刚扫过去的位置。

**`smoothstep(0.8, 1.0, angle)`**：这是一个平滑阶梯函数：
- 当 `angle < 0.8` 时，返回 0.0（完全暗）
- 当 `angle > 1.0` 时，返回 1.0（完全亮）
- 在 0.8 到 1.0 之间平滑过渡

这样就形成了一个从暗到亮的"拖尾"效果。越接近扫描线越亮，扫描线扫过后逐渐变暗。`0.8` 控制拖尾的长度——越小拖尾越长。

#### 第 4 步：同心圆

```glsl
float circles = 1.0 - step(0.02, fract(r * 5.0));
```

逐层拆解：

- `r * 5.0`：把距离放大 5 倍，这样从中心到边缘会有 5 圈
- `fract(r * 5.0)`：取小数部分，产生 0→1→0→1 的锯齿波。每个"0→1"对应一个同心圆环
- `step(0.02, ...)`：当值大于 0.02 时返回 1，否则返回 0。这就在每个圆环的最内侧画了一条细线
- `1.0 - ...`：取反，让线条位置变亮（1），其余位置变暗（0）

结果就是 5 个均匀分布的同心圆细线。

#### 第 5 步：圆形遮罩

```glsl
float mask = 1.0 - step(1.0, r);
```

- `step(1.0, r)`：当 `r >= 1.0`（超出圆形范围）时返回 1
- `1.0 - ...`：取反，圆形内为 1，圆形外为 0

这样就把效果限制在一个正圆里，圆外全黑。

#### 第 6 步：合成

```glsl
vec3 color = vec3(0.0, 1.0, 0.5) * (beam + circles * 0.3) * mask;
```

- `vec3(0.0, 1.0, 0.5)` 是青绿色，定义雷达的色调
- `beam` 是扫描线亮度，`circles * 0.3` 是同心圆亮度（乘以 0.3 让它比扫描线暗很多）
- 两者相加后乘以色调，再乘以遮罩

最终的视觉效果：一个青绿色的圆形区域，同心圆细线若隐若现，一条扫描线带着拖尾在旋转。

## Level 2: 中等 —— 能量护盾 (Energy Shield)

**目标**：制作一个流动的、带边缘发光的能量护盾。

**核心知识点**：噪声纹理、UV 扭曲、边缘光 (Rim Light)。

### 原理：三个关键概念

1. **模拟球体法线**：虽然我们画的是 2D 圆，但可以假设它是一个 3D 球体的俯视图，通过数学算出每个像素对应的球面法线方向。

2. **菲涅尔效应 (Fresnel)**：现实中，从正上方看球面，中心反射弱、边缘反射强。这正好适合做"边缘发光"效果——法线与视线越接近垂直（即越靠近边缘），发光越强。

3. **值噪声 (Value Noise)**：用伪随机数生成平滑的流动纹理，让护盾表面不是死板的纯色。

### 完整代码

<ShaderPreview title="Level 2: Force Field" code={`
varying vec2 vUv;
uniform float uTime;

// 简单的 2D 噪声
float noise(vec2 st) {
    return fract(sin(dot(st.xy, vec2(12.9898,78.233))) * 43758.5453123);
}

// 值噪声 (平滑版)
float valueNoise(vec2 st) {
    vec2 i = floor(st);
    vec2 f = fract(st);
    float a = noise(i);
    float b = noise(i + vec2(1.0, 0.0));
    float c = noise(i + vec2(0.0, 1.0));
    float d = noise(i + vec2(1.0, 1.0));
    vec2 u = f * f * (3.0 - 2.0 * f);
    return mix(a, b, u.x) + (c - a)* u.y * (1.0 - u.x) + (d - b) * u.x * u.y;
}

void main() {
    // 1. 模拟球体法线 (用于边缘光)
    vec2 p = vUv * 2.0 - 1.0;
    float r = length(p);
    if (r > 1.0) discard;
    float z = sqrt(1.0 - r*r);
    vec3 normal = vec3(p.x, p.y, z);
    
    // 2. 边缘光 (Fresnel)
    // 视线方向是 (0,0,1)，点积越小说明越靠近边缘
    float fresnel = 1.0 - dot(normal, vec3(0.0, 0.0, 1.0));
    fresnel = pow(fresnel, 3.0); // 增强边缘对比度
    
    // 3. 流动纹理
    // 使用两层噪声叠加，方向相反
    float n1 = valueNoise(vUv * 10.0 + vec2(0.0, uTime));
    float n2 = valueNoise(vUv * 15.0 - vec2(uTime * 0.5, 0.0));
    float energy = n1 * n2;
    
    // 4. 合成
    // 核心颜色 + 边缘高光
    vec3 coreColor = vec3(0.2, 0.5, 1.0);
    vec3 glow = coreColor * (energy * 2.0 + fresnel * 3.0);
    
    // 增加一点透明度变化
    float alpha = energy * 0.5 + fresnel;
    
    gl_FragColor = vec4(glow, alpha);
}
`} />

### 逐行拆解

#### 噪声函数

```glsl
float noise(vec2 st) {
    return fract(sin(dot(st.xy, vec2(12.9898,78.233))) * 43758.5453123);
}
```

这是 GLSL 中最经典的**伪随机数生成器**。原理：
- `dot(st.xy, vec2(12.9898, 78.233))`：把 2D 坐标映射为一个标量
- `sin(...)`：取正弦，利用其非线性产生混乱的值
- `* 43758.5453123`：放大，让 sin 的微小变化被放大成巨大的差异
- `fract(...)`：取小数部分，映射到 [0, 1]

那个 `12.9898` 和 `43758.5453123` 是经验魔法数字，没有特殊含义，只是测试发现这组值分布比较均匀。

```glsl
float valueNoise(vec2 st) {
    vec2 i = floor(st);
    vec2 f = fract(st);
    float a = noise(i);
    float b = noise(i + vec2(1.0, 0.0));
    float c = noise(i + vec2(0.0, 1.0));
    float d = noise(i + vec2(1.0, 1.0));
    vec2 u = f * f * (3.0 - 2.0 * f);
    return mix(a, b, u.x) + (c - a)* u.y * (1.0 - u.x) + (d - b) * u.x * u.y;
}
```

纯随机数的问题是：相邻像素的值完全不相关，看起来像电视雪花。**值噪声**的思路是：

1. `floor(st)` 取整数格点，在每个格点放一个随机值（a, b, c, d 是四个角的随机值）
2. `fract(st)` 得到当前像素在格子内的小数位置
3. 用 `f * f * (3.0 - 2.0 * f)`（Hermite 平滑）对 `f` 做平滑，避免线性插值的生硬
4. 在四个角之间做**双线性插值**，得到平滑过渡的值

结果：每个像素的噪声值是周围四个格点的平滑混合，整体看起来像连绵的山丘。

#### 第 1 步：模拟球体法线

```glsl
vec2 p = vUv * 2.0 - 1.0;
float r = length(p);
if (r > 1.0) discard;
float z = sqrt(1.0 - r*r);
vec3 normal = vec3(p.x, p.y, z);
```

**`vUv * 2.0 - 1.0`**：把 UV 从 [0,1] 映射到 [-1,1]，这样画面中心是 (0,0)。

**`discard`**：如果像素到中心的距离 `r > 1.0`，说明在圆外面，直接丢弃（不绘制），形成圆形护盾轮廓。

**`z = sqrt(1.0 - r*r)`**：这是关键。假设我们有一个半径为 1 的球体，球面方程是 $x^2 + y^2 + z^2 = 1$，所以 $z = \sqrt{1 - x^2 - y^2} = \sqrt{1 - r^2}$。

- 在圆心处 r=0，z=1（法线指向正上方）
- 在边缘处 r≈1，z≈0（法线几乎水平，指向侧面）

**`vec3 normal = vec3(p.x, p.y, z)`**：x、y 直接用像素坐标，z 用上面算出的值，就得到了一个指向球面外侧的法线向量。

#### 第 2 步：菲涅尔边缘光

```glsl
float fresnel = 1.0 - dot(normal, vec3(0.0, 0.0, 1.0));
fresnel = pow(fresnel, 3.0);
```

- `vec3(0.0, 0.0, 1.0)` 是视线方向（我们正对屏幕看）
- `dot(normal, 视线方向)`：点积衡量两个方向的相似度。中心处法线朝上，点积最大（≈1）；边缘处法线水平，点积最小（≈0）
- `1.0 - ...`：取反，让边缘值大、中心值小
- `pow(fresnel, 3.0)`：三次方增强对比度，让发光更集中在边缘

#### 第 3 步：流动纹理

```glsl
float n1 = valueNoise(vUv * 10.0 + vec2(0.0, uTime));
float n2 = valueNoise(vUv * 15.0 - vec2(uTime * 0.5, 0.0));
float energy = n1 * n2;
```

- `vUv * 10.0`：缩放 UV 让噪声更密集（细节更多）
- `+ vec2(0.0, uTime)`：随时间偏移 y 方向，噪声向上流动
- 第二层 `vUv * 15.0` 更密集，且向左流动（`- uTime * 0.5`）
- 两层噪声相乘 `n1 * n2`：乘法会让两个噪声的"亮区"重叠的地方特别亮，单独亮的地方变暗，产生更复杂的流动图案

#### 第 4 步：合成

```glsl
vec3 coreColor = vec3(0.2, 0.5, 1.0);
vec3 glow = coreColor * (energy * 2.0 + fresnel * 3.0);
float alpha = energy * 0.5 + fresnel;
```

- `energy * 2.0`：流动纹理贡献亮度，乘以 2 增强效果
- `fresnel * 3.0`：边缘光贡献亮度，乘以 3 让边缘更醒目
- 两者相加后乘以蓝色基调
- 透明度 `alpha`：中心处 fresnel 小，纹理暗 → 半透明；边缘处 fresnel 大 → 不透明

## Level 3: 困难 —— 分形地貌 (Fractal Terrain)

**目标**：用纯数学公式生成一个俯视的群山地貌。

**核心知识点**：FBM (分形布朗运动)、光照计算、颜色映射。

### 原理：FBM —— 自然的密码

自然界的地形不是完全随机的，它有一个重要特征：**在不同尺度上都有相似的细节**。你拉近看一座山，看到的是小山丘；拉近看一个小山丘，看到的是小土包。这种"自相似性"就是分形。

FBM (Fractal Brownian Motion) 就是模拟这种特性的算法：叠加多个不同频率、不同振幅的噪声层，每一层频率翻倍（更细的细节），振幅减半（更弱的影响）。就像画一幅画：先画大轮廓，再画中细节，最后画小纹理。

### 完整代码

<ShaderPreview title="Level 3: Fractal Land" code={`
varying vec2 vUv;
uniform float uTime;

float random(vec2 st) {
    return fract(sin(dot(st.xy, vec2(12.9898,78.233))) * 43758.5453123);
}

float noise(vec2 st) {
    vec2 i = floor(st);
    vec2 f = fract(st);
    float a = random(i);
    float b = random(i + vec2(1.0, 0.0));
    float c = random(i + vec2(0.0, 1.0));
    float d = random(i + vec2(1.0, 1.0));
    vec2 u = f * f * (3.0 - 2.0 * f);
    return mix(a, b, u.x) + (c - a)* u.y * (1.0 - u.x) + (d - b) * u.x * u.y;
}

// FBM: 叠加多层噪声，模拟地形细节
float fbm(vec2 st) {
    float v = 0.0;
    float a = 0.5;
    mat2 rot = mat2(cos(0.5), sin(0.5), -sin(0.5), cos(0.5));
    for (int i = 0; i < 5; i++) {
        v += a * noise(st);
        st = rot * st * 2.0 + vec2(100.0); // 旋转以减少网格感
        a *= 0.5;
    }
    return v;
}

void main() {
    vec2 st = vUv * 3.0 + vec2(uTime * 0.1, 0.0); // 缓慢飞行
    
    // 1. 生成高度图
    float h = fbm(st);
    
    // 2. 颜色映射 (Color Grading)
    vec3 col = vec3(0.0);
    
    // 水面 (深蓝)
    vec3 water = vec3(0.0, 0.3, 0.6);
    // 沙滩 (黄色)
    vec3 sand = vec3(0.8, 0.7, 0.4);
    // 森林 (绿色)
    vec3 forest = vec3(0.1, 0.4, 0.1);
    // 雪山 (白色)
    vec3 snow = vec3(0.9, 0.9, 1.0);
    
    // 根据高度混合颜色
    if (h < 0.45) col = water;
    else if (h < 0.5) col = mix(water, sand, (h - 0.45) / 0.05);
    else if (h < 0.7) col = mix(sand, forest, (h - 0.5) / 0.2);
    else col = mix(forest, snow, (h - 0.7) / 0.3);
    
    // 3. 简单的假光照
    // 计算导数来模拟法线
    float d = 0.01;
    float h_dx = fbm(st + vec2(d, 0.0)) - h;
    float h_dy = fbm(st + vec2(0.0, d)) - h;
    vec3 normal = normalize(vec3(-h_dx, -h_dy, d));
    
    vec3 lightDir = normalize(vec3(1.0, 1.0, 0.5));
    float diff = max(dot(normal, lightDir), 0.0);
    
    // 阴影加深
    col *= (0.5 + 0.5 * diff);
    
    gl_FragColor = vec4(col, 1.0);
}
`} />

### 逐行拆解

#### FBM 函数

```glsl
float fbm(vec2 st) {
    float v = 0.0;
    float a = 0.5;
    mat2 rot = mat2(cos(0.5), sin(0.5), -sin(0.5), cos(0.5));
    for (int i = 0; i < 5; i++) {
        v += a * noise(st);
        st = rot * st * 2.0 + vec2(100.0);
        a *= 0.5;
    }
    return v;
}
```

循环 5 次，每次做的事情：

| 迭代 | 振幅 a | 频率 | 贡献 |
|---|---|---|---|
| i=0 | 0.5 | 1x | 大轮廓（山脊走势） |
| i=1 | 0.25 | 2x | 中等细节（山坡起伏） |
| i=2 | 0.125 | 4x | 小细节（岩石纹理） |
| i=3 | 0.0625 | 8x | 微细节 |
| i=4 | 0.03125 | 16x | 最细微的纹理 |

**`st = rot * st * 2.0`**：频率翻倍（`* 2.0`），同时旋转坐标（`rot * st`）。旋转的原因是：如果不旋转，每层噪声的网格方向都一样，叠加后会出现明显的对齐痕迹（像格子一样）。旋转 0.5 弧度约 28.6°，足以打破对齐。

**`+ vec2(100.0)`**：偏移坐标，避免不同层的噪声值恰好对齐。

#### 第 1 步：生成高度图

```glsl
vec2 st = vUv * 3.0 + vec2(uTime * 0.1, 0.0);
float h = fbm(st);
```

- `vUv * 3.0`：缩放 3 倍，让地形更广阔（缩放越大，同一屏幕里看到的"地图"越多）
- `+ vec2(uTime * 0.1, 0.0)`：x 方向随时间缓慢偏移，模拟"飞行掠过"效果
- `h = fbm(st)`：得到一个 0 到 1 之间的"高度值"

#### 第 2 步：颜色映射

```glsl
if (h < 0.45) col = water;
else if (h < 0.5) col = mix(water, sand, (h - 0.45) / 0.05);
else if (h < 0.7) col = mix(sand, forest, (h - 0.5) / 0.2);
else col = mix(forest, snow, (h - 0.7) / 0.3);
```

根据高度分配颜色，模仿真实地形的海拔分布：

| 高度范围 | 地形 | 颜色 |
|---|---|---|
| 0 ~ 0.45 | 水面 | 深蓝 |
| 0.45 ~ 0.5 | 水陆过渡 | 蓝→黄渐变 |
| 0.5 ~ 0.7 | 陆地/森林 | 黄→绿渐变 |
| 0.7 ~ 1.0 | 高山/雪山 | 绿→白渐变 |

**`mix(a, b, t)`** 是线性插值：`a * (1-t) + b * t`。`(h - 0.45) / 0.05` 这种写法是在把局部高度范围归一化到 [0, 1]，比如 h=0.45 时 t=0（纯水面色），h=0.5 时 t=1（纯沙滩色）。

:::tip 为什么过渡带这么窄？
0.45 到 0.5 只有 0.05 的宽度，这意味着沙滩是一条窄带。这模拟了真实地貌中海岸线通常很窄的特征。如果你想让沙滩更宽，把 0.5 改成 0.55 就行。
:::

#### 第 3 步：假光照

```glsl
float d = 0.01;
float h_dx = fbm(st + vec2(d, 0.0)) - h;
float h_dy = fbm(st + vec2(0.0, d)) - h;
vec3 normal = normalize(vec3(-h_dx, -h_dy, d));
```

这是**有限差分法**求法线。思路是：

- 往右偏移一点点（d=0.01），看高度变了多少 → `h_dx` 就是高度在 x 方向的变化率（即偏导数 ∂h/∂x）
- 往上偏移一点点，看高度变了多少 → `h_dy` 就是 y 方向的偏导数

有了偏导数，法线就是 `(-∂h/∂x, -∂h/∂y, 1)` 的归一化。这里 `d` 取代了 1 的角色，它控制"地形起伏相对于平面的比例"——d 越小，同样的高度差产生的法线偏移越大，看起来山越"陡"。

```glsl
vec3 lightDir = normalize(vec3(1.0, 1.0, 0.5));
float diff = max(dot(normal, lightDir), 0.0);
col *= (0.5 + 0.5 * diff);
```

- `lightDir` 是光源方向（右上方偏前），归一化为单位向量
- `dot(normal, lightDir)` 计算法线和光线方向的夹角余弦，越平行越亮
- `max(..., 0.0)` 确保背面不受光（余弦为负时取 0）
- `0.5 + 0.5 * diff`：环境光 0.5 + 漫反射光 0.5，防止背面全黑

## Level 4: 入神 —— 光线追踪 (Ray Tracing)

**目标**：在一个 Shader 里实现真正的光线反射。

**核心知识点**：Ray Tracing 核心循环、反射、材质。

### 原理：光线追踪怎么工作？

光线追踪的思路是反向模拟光的传播：不是从光源出发算光去哪，而是**从相机出发，往每个像素发射一条射线**，看它打到什么物体，再算那个点的颜色。

如果物体是镜面的，光线会在击中点反射，继续往前走，打到下一个物体。这个过程可以反复弹射，每次弹射都积累一点颜色。

核心循环：

```
发射射线 → 求交（找到最近的物体）→ 计算击中点颜色 → 反射 → 重复
```

这不是 Ray Marching（步进式距离场），而是**解析求交**——直接用数学公式算出射线和球体的精确交点。

### 完整代码

<ShaderPreview title="Level 4: Ray Tracer" code={`
varying vec2 vUv;
uniform float uTime;

// 射线结构体
struct Ray { vec3 ro; vec3 rd; };

// 球体求交函数
// 返回距离，如果没有击中返回 -1.0
float iSphere(Ray ray, vec3 pos, float r) {
    vec3 oc = ray.ro - pos;
    float b = dot(oc, ray.rd);
    float c = dot(oc, oc) - r*r;
    float h = b*b - c;
    if (h < 0.0) return -1.0;
    return -b - sqrt(h);
}

void main() {
    // 1. 相机设置
    vec2 uv = vUv * 2.0 - 1.0;
    vec3 ro = vec3(0.0, 0.0, 3.0); // 相机位置
    vec3 rd = normalize(vec3(uv, -1.5)); // 射线方向
    
    vec3 col = vec3(0.0); // 最终颜色
    vec3 ref = vec3(1.0); // 反射衰减系数
    
    // 场景定义：一个大球和一个移动的小球
    vec3 sphere1 = vec3(0.0, -100.5, -1.0); // 地面(超大球)
    float r1 = 100.0;
    vec3 sphere2 = vec3(sin(uTime), 0.0, -1.0); // 浮动球
    float r2 = 0.8;
    
    // 光源
    vec3 light = normalize(vec3(0.5, 0.8, 0.5));
    
    // 2. 光线弹射循环 (最多弹射 3 次)
    for(int i = 0; i < 3; i++) {
        // 求交
        float t1 = iSphere(Ray(ro, rd), sphere1, r1);
        float t2 = iSphere(Ray(ro, rd), sphere2, r2);
        
        float t = 10000.0;
        vec3 pos = vec3(0.0);
        vec3 n = vec3(0.0);
        vec3 matCol = vec3(0.0);
        float id = -1.0;
        
        // 找到最近的交点
        if(t1 > 0.0 && t1 < t) { t = t1; id = 1.0; }
        if(t2 > 0.0 && t2 < t) { t = t2; id = 2.0; }
        
        // 如果没击中任何物体，渲染天空并退出
        if(id < 0.0) {
            vec3 sky = mix(vec3(0.5, 0.7, 1.0), vec3(0.1, 0.3, 0.6), rd.y*0.5+0.5);
            col += ref * sky;
            break;
        }
        
        // 计算击中点信息
        pos = ro + rd * t;
        
        if(id == 1.0) { // 地面
            n = normalize(pos - sphere1);
            // 棋盘格材质
            float check = mod(floor(pos.x*2.0) + floor(pos.z*2.0), 2.0);
            matCol = vec3(0.3 + check * 0.3);
        } else { // 球体
            n = normalize(pos - sphere2);
            matCol = vec3(1.0, 0.2, 0.2); // 红色镜面球
        }
        
        // 简单的漫反射光照
        float diff = max(dot(n, light), 0.0);
        vec3 color = matCol * diff;
        
        // 累加颜色
        col += ref * color * 0.5; // 0.5 是因为物体也会吸收光
        
        // 准备下一次弹射
        ref *= 0.5; // 每次反射能量减半 (如果是完美镜面则不减)
        if(id == 2.0) ref *= vec3(1.0, 0.5, 0.5); // 红色球反射红光
        
        ro = pos + n * 0.001; // 防止自我遮挡
        rd = reflect(rd, n); // 反射方向
    }
    
    // Gamma 校正
    col = pow(col, vec3(0.4545));
    
    gl_FragColor = vec4(col, 1.0);
}
`} />

### 逐行拆解

#### 射线-球体求交

```glsl
float iSphere(Ray ray, vec3 pos, float r) {
    vec3 oc = ray.ro - pos;
    float b = dot(oc, ray.rd);
    float c = dot(oc, oc) - r*r;
    float h = b*b - c;
    if (h < 0.0) return -1.0;
    return -b - sqrt(h);
}
```

这是整个光线追踪的数学核心。推导过程：

射线方程：$P = ro + t \cdot rd$（ro 是起点，rd 是方向，t 是距离）

球体方程：$|P - center|^2 = r^2$

把射线代入球体方程：

$|ro + t \cdot rd - center|^2 = r^2$

令 $oc = ro - center$（射线起点到球心的向量）：

$|oc + t \cdot rd|^2 = r^2$

展开：

$dot(rd, rd) \cdot t^2 + 2 \cdot dot(oc, rd) \cdot t + dot(oc, oc) - r^2 = 0$

因为 `rd` 是单位向量，`dot(rd, rd) = 1`，所以：

$t^2 + 2b \cdot t + c = 0$

其中 `b = dot(oc, rd)`，`c = dot(oc, oc) - r²`。

判别式 $h = b^2 - c$：
- `h < 0`：射线没碰到球，返回 -1
- `h >= 0`：射线碰到球，取较近的交点 $t = -b - \sqrt{h}$

:::note 为什么是 $-b - \sqrt{h}$ 而不是 $-b + \sqrt{h}$？
二次方程有两个根：$t = -b \pm \sqrt{h}$。`-b - sqrt(h)` 是较小的值，即射线最先碰到的点。`-b + sqrt(h)` 是射线穿过球后从另一侧出去的点。我们只需要第一个碰到的点。
:::

#### 相机设置

```glsl
vec2 uv = vUv * 2.0 - 1.0;
vec3 ro = vec3(0.0, 0.0, 3.0);
vec3 rd = normalize(vec3(uv, -1.5));
```

- `ro = vec3(0, 0, 3)`：相机在 z=3 的位置，往 z 负方向看
- `rd = normalize(vec3(uv, -1.5))`：射线方向。`uv` 的 x、y 分量决定了射线往左右上下偏多少，`-1.5` 是"焦距"——值越大视角越窄（像长焦镜头），越小视角越宽（像广角镜头）

**焦距直觉**：想象你站在窗户后面看风景。窗户离你越远（-1.5 的绝对值越大），你能看到的范围越小，但物体看起来越大。

#### 场景定义

```glsl
vec3 sphere1 = vec3(0.0, -100.5, -1.0);
float r1 = 100.0;
vec3 sphere2 = vec3(sin(uTime), 0.0, -1.0);
float r2 = 0.8;
```

- **sphere1**：一个半径 100 的超大球，球心在 y=-100.5。因为球体顶部在 y = -100.5 + 100 = -0.5，它暴露出来的那一小部分顶部就是一个近乎平坦的"地面"。这是一个经典技巧：**用一个超大球来模拟无限平面**。
- **sphere2**：半径 0.8 的正常球，x 位置随时间做正弦摆动

#### 反射循环

```glsl
for(int i = 0; i < 3; i++) {
```

最多弹射 3 次。第 1 次是直接看到的物体，第 2 次是物体上反射的其他物体，第 3 次是反射的反射。

```glsl
    float t1 = iSphere(Ray(ro, rd), sphere1, r1);
    float t2 = iSphere(Ray(ro, rd), sphere2, r2);
```

对场景中的两个球分别求交。

```glsl
    float t = 10000.0;
    ...
    if(t1 > 0.0 && t1 < t) { t = t1; id = 1.0; }
    if(t2 > 0.0 && t2 < t) { t = t2; id = 2.0; }
```

找最近的交点。`t1 > 0` 确保交点在射线前方（不是后方），取最小的 `t` 就是最近的物体。

```glsl
    if(id < 0.0) {
        vec3 sky = mix(vec3(0.5, 0.7, 1.0), vec3(0.1, 0.3, 0.6), rd.y*0.5+0.5);
        col += ref * sky;
        break;
    }
```

如果没打到任何物体，渲染天空。`rd.y*0.5+0.5` 把方向 y 分量从 [-1,1] 映射到 [0,1]：往上看偏深蓝，平视偏浅蓝。

```glsl
    pos = ro + rd * t;
```

计算击中点坐标：射线起点 + 方向 × 距离。

#### 材质和颜色

```glsl
    if(id == 1.0) {
        n = normalize(pos - sphere1);
        float check = mod(floor(pos.x*2.0) + floor(pos.z*2.0), 2.0);
        matCol = vec3(0.3 + check * 0.5);
    }
```

地面的法线就是击中点减去球心方向（球面法线永远指向外侧）。

棋盘格材质的原理：把世界坐标 x、z 分别取整，相加后取模 2。如果结果是 0 和 1 交替出现，就形成黑白格子。`0.3 + check * 0.5` 让格子不是纯黑白，而是灰白交替，看起来更自然。

```glsl
    else {
        n = normalize(pos - sphere2);
        matCol = vec3(1.0, 0.2, 0.2); // 红色球
    }
```

红色球体，法线同理。

#### 颜色累加和反射

```glsl
    float diff = max(dot(n, light), 0.0);
    vec3 color = matCol * diff;
    col += ref * color * 0.5;
```

漫反射光照后，乘以 `ref`（反射衰减系数）和 0.5（物体吸收一半光）。`ref` 初始是白色 `(1,1,1)`，所以第一次弹射时不衰减。

```glsl
    ref *= 0.5;
    if(id == 2.0) ref *= vec3(1.0, 0.5, 0.5);
```

每次反射，能量减半。如果打到红色球，反射光也偏红——这就是为什么红色球上的反射也带红色调。

```glsl
    ro = pos + n * 0.001;
    rd = reflect(rd, n);
```

- `pos + n * 0.001`：把新的射线起点沿法线方向稍微偏移一点点。如果不做这个偏移，新射线会从物体表面内部出发，立刻又和自己求交（自我遮挡），产生黑色噪点。0.001 是经验值，足够小不影响视觉，足够大避免自交。
- `reflect(rd, n)`：GLSL 内置函数，计算反射方向。原理是 $rd - 2 \cdot dot(rd, n) \cdot n$，入射角等于反射角。

#### Gamma 校正

```glsl
col = pow(col, vec3(0.4545));
```

显示器输出的亮度和输入电压不是线性关系，而是幂函数（gamma ≈ 2.2）。我们在 Shader 里做的光照计算都是线性的，直接输出会偏暗。`pow(col, 1/2.2 ≈ 0.4545)` 做逆 gamma 校正，让颜色在屏幕上显示正确。

从画圆圈到模拟光线反弹，GLSL 的上限取决于你的数学想象力。
这四个例子涵盖了 Shader 编程的四大流派：**2D 图形**、**特效/VFX**、**程序化生成**、**物理渲染**。
