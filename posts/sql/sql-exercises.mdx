## 0. 数据集速览

你会用到 5 张表：

- `users(id, name, city, signup_date)`：用户
- `products(id, name, category, price)`：商品
- `orders(id, user_id, order_date, status)`：订单（含取消、退款、待支付）
- `order_items(order_id, product_id, quantity, unit_price)`：订单明细（成交价以 unit_price 为准）
- `payments(id, order_id, paid_at, amount, method, status)`：支付（SUCCESS / PENDING / FAILED / REFUNDED）

## 2. 聚合与分组（GROUP BY / HAVING）

### 练习 5：分组统计

目标：统计每个城市有多少用户，返回 `city, user_cnt`，按 `user_cnt` 降序。

<SqlSimulator
  dataset="commerce"
  description="涉及表：users"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT city, COUNT(*) AS user_cnt
FROM users
GROUP BY city
ORDER BY user_cnt DESC, city;`}
/>

### 练习 6：分组后过滤（HAVING）

目标：找出用户数不少于 2 的城市。

<SqlSimulator
  dataset="commerce"
  description="涉及表：users"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT city, COUNT(*) AS user_cnt
FROM users
GROUP BY city
HAVING COUNT(*) >= 2
ORDER BY user_cnt DESC, city;`}
/>

### 练习 7：订单状态分布

目标：统计 `orders` 每种 `status` 的订单数，返回 `status, order_cnt`，按订单数降序。

<SqlSimulator
  dataset="commerce"
  description="涉及表：orders"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT status, COUNT(*) AS order_cnt
FROM orders
GROUP BY status
ORDER BY order_cnt DESC, status;`}
/>

### 练习 8：只统计成功支付的收入

目标：计算 `payments` 中 `status = 'SUCCESS'` 的总收入（`SUM(amount)`），输出为 `revenue`。

<SqlSimulator
  dataset="commerce"
  description="涉及表：payments"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT SUM(amount) AS revenue
FROM payments
WHERE status = 'SUCCESS';`}
/>

### 练习 9：每种支付方式的成功支付总额

目标：按 `method` 分组，统计成功支付的金额总和，返回 `method, total_amount`，按金额降序。

<SqlSimulator
  dataset="commerce"
  description="涉及表：payments"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT method, SUM(amount) AS total_amount

## 3. 多表关联（JOIN）

### 练习 10：订单列表（JOIN users）

目标：列出每笔订单的 `order_id, user_name, city, order_date, status`。

<SqlSimulator
  dataset="commerce"
  description="涉及表：orders、users"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT
  o.id AS order_id,
  u.name AS user_name,
  u.city,
  o.order_date,
  o.status
FROM orders o
JOIN users u ON u.id = o.user_id
ORDER BY o.order_date, o.id;`}
/>

### 练习 11：订单明细（JOIN 多表）

目标：列出订单明细行：`order_id, user_name, product_name, quantity, unit_price`。

<SqlSimulator
  dataset="commerce"
  description="涉及表：order_items、orders、users、products"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT
  oi.order_id,
  u.name AS user_name,
  p.name AS product_name,
  oi.quantity,
  oi.unit_price
FROM order_items oi
JOIN orders o ON o.id = oi.order_id
JOIN users u ON u.id = o.user_id
JOIN products p ON p.id = oi.product_id
ORDER BY oi.order_id, p.id;`}
/>

### 练习 12：每个用户的订单金额

目标：每笔订单的金额 = `SUM(quantity * unit_price)`，关联用户信息后输出 `user_name, order_id, order_amount`，按用户和订单排序。

<SqlSimulator
  dataset="commerce"
  description="涉及表：orders、users、order_items"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT
  u.name AS user_name,
  o.id AS order_id,
  SUM(oi.quantity * oi.unit_price) AS order_amount
FROM orders o
JOIN users u ON u.id = o.user_id
JOIN order_items oi ON oi.order_id = o.id
GROUP BY o.id, u.name
ORDER BY u.name, o.id;`}
/>

## 4. 反连接（NOT EXISTS / LEFT JOIN ... IS NULL）

### 练习 13：找出从未下过单的用户

目标：输出 `user_id, name`。

<SqlSimulator
  dataset="commerce"
  description="涉及表：users、orders"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT u.id, u.name
FROM users u
WHERE NOT EXISTS (
  SELECT 1
  FROM orders o
  WHERE o.user_id = u.id
)
ORDER BY u.id;`}
/>

### 练习 14：找出从未被购买过的商品

目标：输出 `product_id, name`。

<SqlSimulator
  dataset="commerce"
  description="涉及表：products、order_items"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT p.id AS product_id, p.name
FROM products p
WHERE NOT EXISTS (
  SELECT 1
  FROM order_items oi
  WHERE oi.product_id = p.id
)
ORDER BY p.id;`}
/>

### 练习 15：买过 Furniture 类商品的用户

目标：输出去重后的 `user_id, name`，只列出买过 `category = 'Furniture'` 商品的用户。

<SqlSimulator
  dataset="commerce"
  description="涉及表：users、orders、order_items、products"
  defaultQuery="-- 在此输入你的 SQL 查询"
  answerSql={`SELECT DISTINCT u.id, u.name
FROM users u
JOIN orders o ON o.user_id = u.id
JOIN order_items oi ON oi.order_id = o.id
JOIN products p ON p.id = oi.product_id
WHERE p.category = 'Furniture'
ORDER BY u.id;`}
/>

## 总结

通过这 15 道题，你已经覆盖了日常业务中最常用的 SQL 操作：

1. **查数据与过滤**：`SELECT`, `WHERE`, `BETWEEN`, `IN`, `ORDER BY`, `LIMIT`
2. **聚合与分组**：`COUNT`, `SUM`, `GROUP BY`, `HAVING`
3. **多表关联**：`JOIN`（INNER JOIN），多表 JOIN
4. **反连接**：`NOT EXISTS`，`LEFT JOIN ... IS NULL`

如果你能独立做完这些题，说明你已经具备了处理日常业务查询的能力。

**下一步：** 这些题覆盖的是"取数和统计"的场景。真实业务中还有更复杂的需求——对账、排名、累计、多维度报表——需要用到 CTE、窗口函数等高级技巧。继续 [Part 3 · 实战练习（二）：复杂业务](/posts/sql/sql-practice-lab)，12 道题帮你攻克这些难题。
