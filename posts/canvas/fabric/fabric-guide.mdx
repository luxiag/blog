# Fabric.js 完全指南

## 为什么需要 Fabric.js？

想象一下，你用原生 Canvas API 画了一个红色矩形。现在你想把它移动到另一个位置，或者改变它的颜色。怎么办？

**原生 Canvas 的困境：**
```javascript
// 绘制一个矩形
ctx.fillStyle = 'red';
ctx.fillRect(100, 100, 150, 100);

// 想要移动它？抱歉，你需要：
// 1. 清空整个画布
// 2. 重新计算新位置
// 3. 重新绘制所有内容
ctx.clearRect(0, 0, canvas.width, canvas.height);
ctx.fillStyle = 'red';
ctx.fillRect(200, 150, 150, 100); // 新位置
```

这就是原生 Canvas 的本质：**一旦绘制，像素就"死"了**。你操作的是像素，而不是"对象"。

**Fabric.js 的解决方案：**
```javascript
// 创建一个矩形对象
const rect = new fabric.Rect({
  left: 100,
  top: 100,
  width: 150,
  height: 100,
  fill: 'red'
});

canvas.add(rect);

// 想要移动？直接改属性！
rect.set({ left: 200, top: 150 });
canvas.requestRenderAll();

// 想要改颜色？
rect.set({ fill: 'blue' });
canvas.requestRenderAll();
```

Fabric.js 在 Canvas 之上构建了一个**对象模型**，让你像操作 DOM 元素一样操作图形。

**关键概念：**
- `new fabric.Canvas(element, options)`: 将普通 `<canvas>` 元素升级为 Fabric 画布
- `canvas.add(object)`: 添加对象到画布
- `canvas.dispose()`: 销毁画布，释放内存（React 中很重要！）

在 Fabric.js 中，一切都是对象。每个对象都有一系列属性，你可以随时修改。

### 对象的通用属性

每个 Fabric 对象都有这些核心属性：

| 属性 | 说明 | 示例 |
|------|------|------|
| `left` / `top` | 位置（左上角坐标） | `left: 100, top: 50` |
| `width` / `height` | 尺寸 | `width: 200, height: 100` |
| `fill` | 填充颜色 | `fill: 'red'` 或 `fill: '#3b82f6'` |
| `stroke` | 描边颜色 | `stroke: 'blue'` |
| `strokeWidth` | 描边宽度 | `strokeWidth: 3` |
| `opacity` | 透明度 (0-1) | `opacity: 0.5` |
| `angle` | 旋转角度 | `angle: 45` |
| `scaleX` / `scaleY` | 缩放比例 | `scaleX: 1.5, scaleY: 2` |
| `selectable` | 是否可选中 | `selectable: false` |
| `visible` | 是否可见 | `visible: false` |

**三种文本对象的区别：**
- **`fabric.Text`**: 静态文本，只能通过代码修改
- **`fabric.IText`**: 可交互文本，用户可以双击编辑
- **`fabric.Textbox`**: 文本框，支持固定宽度和自动换行

## 事件系统：让画布动起来

Fabric.js 拥有强大的事件系统，你可以监听各种交互。

<CodePenDemo
  title="事件监听实战"
  height="500px"
  code={`const EventsDemo = () => {
  const canvasEl = React.useRef(null);
  const [log, setLog] = React.useState([]);

  const addLog = (message) => {
    setLog(prev => [
      \`[\${new Date().toLocaleTimeString()}] \${message}\`,
      ...prev.slice(0, 9)
    ]);
  };

  React.useEffect(() => {
    const canvas = new fabric.Canvas(canvasEl.current, {
      width: 600,
      height: 300,
      backgroundColor: '#fafafa'
    });

    // 创建几个对象
    const rect = new fabric.Rect({
      left: 100,
      top: 100,
      width: 100,
      height: 80,
      fill: '#3b82f6'
    });

    const circle = new fabric.Circle({
      left: 300,
      top: 100,
      radius: 50,
      fill: '#10b981'
    });

    canvas.add(rect, circle);

    // 1. 对象被选中
    canvas.on('selection:created', (e) => {
      addLog(\`✅ 选中了对象\`);
    });

    // 2. 对象移动中
    canvas.on('object:moving', (e) => {
      const obj = e.target;
      addLog(\`🚚 移动中: (\${Math.round(obj.left)}, \${Math.round(obj.top)})\`);
    });

    // 3. 对象旋转中
    canvas.on('object:rotating', (e) => {
      const obj = e.target;
      addLog(\`🔄 旋转中: \${Math.round(obj.angle)}°\`);
    });

    // 4. 对象缩放中
    canvas.on('object:scaling', (e) => {
      const obj = e.target;
      addLog(\`📏 缩放中: \${(obj.scaleX * 100).toFixed(0)}%\`);
    });

    // 5. 对象修改完成
    canvas.on('object:modified', (e) => {
      addLog(\`✨ 修改完成\`);
    });

    // 6. 鼠标点击画布
    canvas.on('mouse:down', (e) => {
      if (!e.target) {
        addLog(\`👆 点击了空白区域\`);
      }
    });

    return () => canvas.dispose();
  }, []);

  return (
    <div className="flex flex-col items-center gap-3">
      <canvas ref={canvasEl} />
      <div className="w-full max-w-[600px] h-32 bg-gray-900 text-green-400 p-3 rounded font-mono text-xs overflow-auto">
        {log.length === 0 ? (
          <div className="text-gray-500">等待事件...</div>
        ) : (
          log.map((item, i) => <div key={i}>{item}</div>)
        )}
      </div>
      <p className="text-sm text-gray-600">
        💡 拖拽、旋转、缩放对象，观察事件日志
      </p>
    </div>
  );
}

render(<EventsDemo />)`}
/>

**常用事件列表：**

| 事件名 | 触发时机 |
|--------|----------|
| `selection:created` | 对象被选中 |
| `selection:cleared` | 取消选中 |
| `object:moving` | 对象移动中 |
| `object:rotating` | 对象旋转中 |
| `object:scaling` | 对象缩放中 |
| `object:modified` | 对象修改完成 |
| `mouse:down` | 鼠标按下 |
| `mouse:move` | 鼠标移动 |
| `mouse:up` | 鼠标抬起 |

## 序列化：保存与加载

Fabric.js 最强大的功能之一：可以将整个画布序列化为 JSON，然后在任何地方恢复。

<CodePenDemo
  title="序列化与反序列化"
  height="500px"
  code={`const SerializationDemo = () => {
  const canvasEl = React.useRef(null);
  const canvasRef = React.useRef(null);
  const [jsonData, setJsonData] = React.useState('');

  React.useEffect(() => {
    const canvas = new fabric.Canvas(canvasEl.current, {
      width: 600,
      height: 300,
      backgroundColor: '#f5f5f5'
    });
    canvasRef.current = canvas;

    // 添加一些初始对象
    const rect = new fabric.Rect({
      left: 100,
      top: 100,
      width: 100,
      height: 80,
      fill: '#3b82f6'
    });

    const text = new fabric.Text('Hello Fabric', {
      left: 250,
      top: 120,
      fontSize: 24,
      fill: '#ef4444'
    });

    canvas.add(rect, text);

    return () => canvas.dispose();
  }, []);

  const saveToJSON = () => {
    const canvas = canvasRef.current;
    const json = JSON.stringify(canvas.toJSON(), null, 2);
    setJsonData(json);
  };

  const loadFromJSON = () => {
    if (!jsonData) return;
    const canvas = canvasRef.current;
    
    canvas.loadFromJSON(JSON.parse(jsonData)).then(() => {
      canvas.requestRenderAll();
    });
  };

  const clearCanvas = () => {
    const canvas = canvasRef.current;
    canvas.clear();
    canvas.backgroundColor = '#f5f5f5';
    canvas.requestRenderAll();
  };

  return (
    <div className="flex flex-col items-center gap-3">
      <canvas ref={canvasEl} />
      
      <div className="flex gap-2">
        <button 
          onClick={saveToJSON}
          className="px-4 py-2 bg-green-500 text-white rounded hover:bg-green-600 transition"
        >
          💾 保存为 JSON
        </button>
        <button 
          onClick={clearCanvas}
          className="px-4 py-2 bg-orange-500 text-white rounded hover:bg-orange-600 transition"
        >
          🗑️ 清空画布
        </button>
        <button 
          onClick={loadFromJSON}
          className="px-4 py-2 bg-blue-500 text-white rounded hover:bg-blue-600 transition"
          disabled={!jsonData}
        >
          📂 从 JSON 恢复
        </button>
      </div>

      {jsonData && (
        <div className="w-full max-w-[600px]">
          <div className="text-sm font-medium mb-1">JSON 数据：</div>
          <pre className="bg-gray-900 text-green-400 p-3 rounded text-xs overflow-auto max-h-40">
            {jsonData}
          </pre>
        </div>
      )}

      <p className="text-sm text-gray-600">
        💡 试试：修改画布 → 保存 → 清空 → 恢复
      </p>
    </div>
  );
}

render(<SerializationDemo />)`}
/>

**序列化的应用场景：**
- 💾 **保存草稿**：用户可以保存设计，下次继续编辑
- ↩️ **撤销/重做**：记录每次操作的 JSON 快照
- 🌐 **跨平台同步**：在服务器存储 JSON，多设备共享
- 📤 **导出/导入**：让用户导出设计文件

        shape = new fabric.Triangle({
          left: 50,
          top: 50,
          width: 100,
          height: 100,
          fill: selectedColor
        });
        break;
      case 'text':
        shape = new fabric.IText('双击编辑', {
          left: 50,
          top: 50,
          fontSize: 24,
          fill: selectedColor
        });
        break;
    }

    if (shape) {
      canvas.add(shape);
      canvas.setActiveObject(shape);
    }
  };

  const deleteSelected = () => {
    const canvas = canvasRef.current;
    const activeObject = canvas.getActiveObject();
    if (activeObject) {
      canvas.remove(activeObject);
    }
  };

  const clearAll = () => {
    const canvas = canvasRef.current;
    canvas.clear();
    canvas.backgroundColor = '#ffffff';
    canvas.requestRenderAll();
  };

  const colors = ['#3b82f6', '#10b981', '#f59e0b', '#ef4444', '#8b5cf6', '#ec4899'];

  return (
    <div className="flex flex-col items-center gap-4">
      <div className="border-2 border-gray-300 rounded shadow-lg">
        <canvas ref={canvasEl} />
      </div>

      <div className="flex flex-wrap gap-3 items-center justify-center max-w-[700px] p-4 bg-gray-100 rounded">
        <div className="flex gap-2">
          <button onClick={() => addShape('rect')} className="px-3 py-2 bg-blue-500 text-white rounded hover:bg-blue-600 text-sm">
            ⬜ 矩形
          </button>
          <button onClick={() => addShape('circle')} className="px-3 py-2 bg-green-500 text-white rounded hover:bg-green-600 text-sm">
            ⭕ 圆形
          </button>
          <button onClick={() => addShape('triangle')} className="px-3 py-2 bg-purple-500 text-white rounded hover:bg-purple-600 text-sm">
            🔺 三角形
          </button>
          <button onClick={() => addShape('text')} className="px-3 py-2 bg-yellow-500 text-white rounded hover:bg-yellow-600 text-sm">
            📝 文字
          </button>
        </div>

        <div className="w-px h-8 bg-gray-300"></div>

        <div className="flex gap-2 items-center">
          <span className="text-sm font-medium">颜色:</span>
          {colors.map(color => (
            <button
              key={color}
              onClick={() => setSelectedColor(color)}
              className={\`w-8 h-8 rounded border-2 transition \${
                selectedColor === color ? 'border-gray-800 scale-110' : 'border-gray-300'
              }\`}
              style={{ backgroundColor: color }}
            />
          ))}
        </div>

        <div className="w-px h-8 bg-gray-300"></div>

        <div className="flex gap-2">
          <button onClick={deleteSelected} className="px-3 py-2 bg-red-500 text-white rounded hover:bg-red-600 text-sm">
            🗑️ 删除
          </button>
          <button onClick={clearAll} className="px-3 py-2 bg-orange-500 text-white rounded hover:bg-orange-600 text-sm">
            🔄 清空
          </button>
        </div>
      </div>
    </div>
  );
}

render(<DrawingBoard />)`}
