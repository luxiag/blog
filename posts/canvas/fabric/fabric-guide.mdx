# Fabric.js：让 Canvas 动起来

原生的 Canvas API 虽然强大，但它是基于过程的（Procedural），一旦绘制完成，像素就“死”在画布上了，你无法直接选中、移动或修改某个已经绘制的图形。

**Fabric.js** 解决了这个问题。它在 Canvas 之上构建了一个**对象模型**（Object Model），让你可以以面向对象的方式操作图形。所有的图形（矩形、圆形、图片等）都是对象，你可以轻松地改变它们的属性、监听事件、进行拖拽缩放等操作。

## 1. 快速上手

首先，我们需要创建一个 `canvas` 元素，然后用 Fabric 初始化它。注意，Fabric 会在你的原生 canvas 外面包裹一层 wrapper，因此样式布局时要注意。

<CodePenDemo
  title="Fabric.js Hello World"
  height="400px"
  code={`const FabricIntro = () => {
  const canvasEl = React.useRef(null);
  const fabricCanvas = React.useRef(null);

  React.useEffect(() => {
    // 1. 初始化 Fabric Canvas
    if (canvasEl.current) {
        // dispose old instance if exists to prevent duplicate canvases
        if (fabricCanvas.current) {
            fabricCanvas.current.dispose();
        }
        
        const canvas = new fabric.Canvas(canvasEl.current, {
            width: 500,
            height: 300,
            backgroundColor: '#f3f3f3'
        });
        
        fabricCanvas.current = canvas;

        // 2. 创建一个矩形对象
        const rect = new fabric.Rect({
            left: 100,
            top: 100,
            fill: 'red',
            width: 100,
            height: 100,
            angle: 45,
            cornerColor: 'blue',
            transparentCorners: false
        });

        // 3. 添加到画布
        canvas.add(rect);
        
        // 4. 创建一个圆形
        const circle = new fabric.Circle({
            radius: 50,
            fill: 'green',
            left: 250,
            top: 100
        });
        
        canvas.add(circle);
        
        // 选中矩形
        canvas.setActiveObject(rect);
    }

    // Cleanup
    return () => {
        if (fabricCanvas.current) {
            fabricCanvas.current.dispose();
            fabricCanvas.current = null;
        }
    }
  }, []);

  return (
    <div className="flex justify-center p-4 bg-white">
      <canvas ref={canvasEl} />
    </div>
  );
}

render(<FabricIntro />)`}
/>

试着鼠标点击选中上面的红色矩形，你会发现它自带了控制点（Controls），你可以直接**拖拽、旋转、缩放**它！这就是 Fabric.js 的魅力。

## 2. 基础对象 (Basic Shapes)

Fabric 提供了丰富的内置图形对象：

*   `fabric.Rect`: 矩形
*   `fabric.Circle`: 圆形
*   `fabric.Triangle`: 三角形
*   `fabric.Ellipse`: 椭圆
*   `fabric.Line`: 线条
*   `fabric.Polyline`: 多折线
*   `fabric.Path`: 路径（SVG Path）

<CodePenDemo
  title="基础图形展示"
  height="400px"
  code={`const FabricShapes = () => {
  const canvasEl = React.useRef(null);
  const canvasRef = React.useRef(null);

  React.useEffect(() => {
    if (!canvasEl.current) return;
    
    // 初始化画布
    const canvas = new fabric.Canvas(canvasEl.current, {
      width: 600,
      height: 350,
      backgroundColor: '#fff',
      selection: true // 开启框选
    });
    canvasRef.current = canvas;

    // 1. 三角形
    const triangle = new fabric.Triangle({
      width: 100, 
      height: 100, 
      fill: '#7c4dff', 
      left: 50, 
      top: 50
    });

    // 2. 椭圆
    const ellipse = new fabric.Ellipse({
      rx: 80, // x轴半径
      ry: 40, // y轴半径
      fill: '#ff4081',
      stroke: '#c51162',
      strokeWidth: 5,
      left: 200,
      top: 50
    });

    // 3. 线条
    const line = new fabric.Line([50, 200, 200, 300], {
      stroke: 'rgba(0,0,0,0.5)',
      strokeWidth: 5
    });
    
    // 4. 虚线边框的矩形
    const dashedRect = new fabric.Rect({
        left: 250,
        top: 200,
        width: 150,
        height: 100,
        fill: 'transparent',
        stroke: 'orange',
        strokeWidth: 3,
        strokeDashArray: [10, 5] // 虚线模式：10px实线，5px间隔
    });

    canvas.add(triangle, ellipse, line, dashedRect);

    return () => {
      canvas.dispose();
    };
  }, []);

  return (
    <div className="flex justify-center p-4 bg-white shadow-sm border border-neutral-200 rounded">
      <canvas ref={canvasEl} />
    </div>
  );
}

render(<FabricShapes />)`}

## 3. 图片与文本 (Images & Text)

### 图片 (fabric.IText)

加载图片有两种主要方式：
1.  `fabric.Image.fromURL(url, callback)`: 从 URL 加载。
2.  `new fabric.Image(imgElement)`: 从现有的 `<img>` 标签创建。

### 文本 (fabric.IText)

Fabric 支持两种文本：
*   `fabric.Text`: 静态文本。
*   `fabric.IText`: **可交互式文本**，用户可以直接双击编辑内容！

<CodePenDemo
  title="图片与可编辑文本"
  height="450px"
  code={`const FabricImageText = () => {
  const canvasEl = React.useRef(null);

  React.useEffect(() => {
    const canvas = new fabric.Canvas(canvasEl.current, {
        width: 600,
        height: 400,
        backgroundColor: '#f0f2f5'
    });

    // 1. 添加可编辑文本
    const text = new fabric.IText('双击编辑我\nHello World', {
        fontFamily: 'arial',
        fill: '#333',
        fontSize: 40,
        left: 100,
        top: 50,
        fontWeight: 'bold',
        shadow: 'rgba(0,0,0,0.3) 5px 5px 5px'
    });
    canvas.add(text);

    // 2. 加载图片 (跨域图片需要注意 CORS)
    // 这里我们用一个色块代替图片演示，原理一样，fabric.Image.fromURL 用法类似
    const rectAsImage = new fabric.Rect({
        left: 150,
        top: 200,
        fill: '#00b894',
        width: 200,
        height: 150,
        rx: 10,
        ry: 10,
        opacity: 0.8
    });
    
    // 模拟图片对象的一些滤镜或操作
    // 给它加一个标签
    const label = new fabric.Text('假装我是张图片', {
        fontSize: 20,
        fill: 'white',
        left: 170,
        top: 260,
        selectable: false
    });
    
    // 组合 (Group)
    const group = new fabric.Group([rectAsImage, label], {
        left: 150,
        top: 200,
        angle: -10
    });
    
    canvas.add(group);

    return () => canvas.dispose();
  }, []);

  return (
    <div className="flex justify-center">
      <canvas ref={canvasEl} />
    </div>
  );
}

render(<FabricImageText />)`}
/>

## 4. 事件系统 (Events)

Fabric 拥有强大的事件系统，你可以监听鼠标事件（点击、移动、按下）、对象事件（选中、旋转、缩放、修改）等。

常见事件：
*   `mouse:down`, `mouse:move`, `mouse:up`
*   `object:added`, `object:removed`, `object:modified`
*   `object:rotating`, `object:scaling`, `object:moving`
*   `selection:created`, `selection:cleared`

<CodePenDemo
  title="事件监听演示"
  height="400px"
  code={`const FabricEvents = () => {
  const canvasEl = React.useRef(null);
  const [log, setLog] = React.useState('操作画布以查看事件...');

  React.useEffect(() => {
    const canvas = new fabric.Canvas(canvasEl.current, {
        width: 500,
        height: 300,
        backgroundColor: '#eee'
    });

    const rect = new fabric.Rect({
        left: 200, 
        top: 100, 
        width: 100, 
        height: 100, 
        fill: 'orange' 
    });
    canvas.add(rect);

    // 辅助函数：更新日志
    // 注意：React State 在 useEffect 闭包中可能是旧的，这里我们直接操作 DOM 或者用 useRef 也可以
    // 为了演示简单，我们通过 dispatchEvent 或者直接 console
    
    const updateLog = (msg) => {
        // 使用自定义事件通知 React 组件更新（或者这里简化处理）
        setLog(prev => msg + '\\n' + prev.split('\\n').slice(0, 4).join('\\n'));
    };

    // 监听对象移动
    canvas.on('object:moving', (e) => {
        const obj = e.target;
        updateLog(\`Moving: [x:\${Math.round(obj.left)}, y:\${Math.round(obj.top)}]\`);
    });

    // 监听对象旋转
    canvas.on('object:rotating', (e) => {
        const obj = e.target;
        updateLog(\`Rotating: \${Math.round(obj.angle)}°\`);
    });

    // 监听选中事件
    canvas.on('selection:created', (e) => {
        updateLog('对象被选中');
        e.selected[0].set('fill', 'red');
        canvas.requestRenderAll();
    });
    
    canvas.on('selection:cleared', (e) => {
        updateLog('取消选中');
        // 恢复颜色需要遍历，这里略过
    });

    return () => canvas.dispose();
  }, []); // 依赖项为空，只运行一次

  return (
    <div className="flex flex-col items-center gap-4">
      <div className="border border-neutral-300">
          <canvas ref={canvasEl} />
      </div>
      <div className="w-full max-w-[500px] h-32 bg-gray-900 text-green-400 p-2 font-mono text-xs overflow-hidden rounded">
        <pre>{log}</pre>
      </div>
    </div>
  );
}

render(<FabricEvents />)`}
/>

## 5. 动画 (Animation)

Fabric 对象拥有 `animate` 方法，可以丝滑地改变属性值。

```javascript
rect.animate('left', 500, {
  onChange: canvas.renderAll.bind(canvas),
  duration: 1000,
  easing: fabric.util.ease.easeOutBounce
});
```

<CodePenDemo
  title="Fabric 动画"
  height="300px"
  code={`const FabricAnimate = () => {
  const canvasEl = React.useRef(null);
  const canvasRef = React.useRef(null);

  React.useEffect(() => {
    const canvas = new fabric.Canvas(canvasEl.current, {
        width: 600,
        height: 200,
        backgroundColor: '#fff'
    });
    canvasRef.current = canvas;

    const rect = new fabric.Rect({
        left: 50,
        top: 50,
        width: 100,
        height: 100,
        fill: 'purple',
        rx: 10,
        ry: 10
    });
    canvas.add(rect);

    return () => canvas.dispose();
  }, []);

  const playAnimation = () => {
    const canvas = canvasRef.current;
    const obj = canvas.getObjects()[0];
    
    if (obj) {
        // 确保先复位
        obj.set({ left: 50, angle: 0 });
        
        obj.animate('left', 450, {
            onChange: canvas.renderAll.bind(canvas),
            duration: 1000,
            easing: fabric.util.ease.easeOutBounce
        });
        
        obj.animate('angle', 360, {
            duration: 1000
        });
    }
  };

  return (
    <div className="flex flex-col items-center">
      <canvas ref={canvasEl} />
      <button 
        onClick={playAnimation}
        className="mt-4 px-4 py-2 bg-blue-600 text-white rounded hover:bg-blue-700 active:scale-95 transition"
      >
        播放动画
      </button>
    </div>
  );
}

render(<FabricAnimate />)`}
/>

## 6. 序列化与反序列化 (JSON)

这也是 Fabric 的核心优势之一。你可以将整个画布的状态保存为 JSON，然后在任何地方（甚至在 Node.js 服务端）恢复它。

*   `canvas.toJSON()`: 导出 JSON 对象。
*   `canvas.loadFromJSON(json, callback)`: 从 JSON 恢复。

这使得实现“保存草稿”、“撤销重做”等功能变得非常简单。

## 结语

Fabric.js 极大地降低了 Canvas 的操作门槛，特别是对于需要用户交互（编辑器、绘图工具、配置器）的场景。如果你想做一个在线图片编辑器、海报设计工具或者拖拽式图形应用，Fabric.js 绝对是首选库之一。
