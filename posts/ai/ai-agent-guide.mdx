# AI Agent 完全指南：从概念到实战

当 ChatGPT 横空出世时，我们惊叹于它的对话能力。但很快我们发现了它的局限：**它只能聊天，不能行动**。它不能帮你订机票、不能查询数据库、不能执行代码。

而 **AI Agent（智能体）** 的出现，打破了这个限制。Agent 不仅能理解你的意图，还能**自主规划、调用工具、执行任务**，真正成为你的智能助手。

---

## 1. 什么是 AI Agent？

### 1.1 定义

**AI Agent** 是一个能够感知环境、自主决策并采取行动以实现目标的智能系统。

与传统的 LLM（大语言模型）对话不同，Agent 具备以下特性：

| 特性 | 传统 LLM | AI Agent |
| :--- | :--- | :--- |
| **交互方式** | 一问一答 | 多轮对话 + 自主行动 |
| **能力边界** | 仅限文本生成 | 可调用外部工具（API、数据库、代码执行） |
| **任务规划** | 无 | 能够分解复杂任务并逐步执行 |
| **记忆** | 仅限当前对话 | 可持久化记忆（短期 + 长期） |

### 1.2 核心组件

一个完整的 Agent 系统通常包含以下部分：

```
┌─────────────────────────────────────┐
│          AI Agent 架构              │
├─────────────────────────────────────┤
│  1. 大脑 (LLM)                      │
│     - 理解意图                       │
│     - 规划任务                       │
│     - 生成响应                       │
├─────────────────────────────────────┤
│  2. 记忆 (Memory)                   │
│     - 短期记忆：当前对话上下文        │
│     - 长期记忆：历史交互、知识库      │
├─────────────────────────────────────┤
│  3. 工具箱 (Tools)                  │
│     - 搜索引擎                       │
│     - 数据库查询                     │
│     - 代码执行器                     │
│     - API 调用                       │
├─────────────────────────────────────┤
│  4. 规划器 (Planner)                │
│     - 任务分解                       │
│     - 执行顺序                       │
│     - 错误处理                       │
└─────────────────────────────────────┘
```

## 2. Agent 的工作流程

让我们通过一个实际例子来理解 Agent 是如何工作的。

### 2.1 示例场景

**用户请求**："帮我查一下明天北京的天气，如果会下雨就提醒我带伞。"

**传统 LLM 的回答**：
> "抱歉，我无法实时查询天气信息。建议您查看天气预报 App。"

**AI Agent 的执行流程**：

```
1. 理解意图
   └─> 需要查询天气 + 条件判断 + 提醒

2. 规划任务
   └─> Step 1: 调用天气 API 查询明天北京天气
   └─> Step 2: 判断是否有雨
   └─> Step 3: 如果有雨，生成提醒

3. 执行工具调用
   └─> 调用 get_weather(city="北京", date="明天")
   └─> 返回：{ "weather": "小雨", "temp": "15-22°C" }

4. 生成响应
   └─> "明天北京有小雨，气温 15-22°C，记得带伞哦！"
```

## 3. Agent 架构模式

### 3.1 ReAct 模式（Reasoning + Acting）

这是目前最流行的 Agent 架构，由 Google 提出。核心思想是**推理与行动交替进行**。

**流程**：
```
Thought (思考) → Action (行动) → Observation (观察) → Thought → ...
```

**示例**：

```
User: 帮我找出 2024 年票房最高的电影，并告诉我它的导演是谁。

Thought 1: 我需要先搜索 2024 年票房排行榜
Action 1: search("2024年票房排行榜")
Observation 1: 《热辣滚烫》以 34.5 亿票房位居第一

Thought 2: 现在我需要查询这部电影的导演
Action 2: search("《热辣滚烫》导演")
Observation 2: 导演是贾玲

Thought 3: 我已经获得了所有信息，可以回答了
Final Answer: 2024 年票房最高的电影是《热辣滚烫》（34.5 亿），导演是贾玲。
```

### 3.2 Plan-and-Execute 模式

先制定完整计划，再逐步执行。适合复杂的多步骤任务。

```
User: 帮我分析公司最近一个月的销售数据，生成报告并发送给老板。

Plan:
  1. 从数据库查询最近 30 天的销售记录
  2. 使用 Python 进行数据分析（总销售额、增长率、TOP 产品）
  3. 生成可视化图表
  4. 撰写分析报告
  5. 发送邮件给老板

Execute:
  [执行步骤 1] → [执行步骤 2] → ... → [完成]
```

## 4. 工具调用（Function Calling）

工具是 Agent 的"手和脚"。现代 LLM（如 GPT-4、Claude）都支持 Function Calling。

### 4.1 定义工具

以 OpenAI 的格式为例：

```json
{
  "name": "get_weather",
  "description": "获取指定城市的天气信息",
  "parameters": {
    "type": "object",
    "properties": {
      "city": {
        "type": "string",
        "description": "城市名称，如'北京'"
      },
      "date": {
        "type": "string",
        "description": "日期，如'今天'、'明天'或具体日期"
      }
    },
    "required": ["city"]
  }
}
```

### 4.2 实现工具

```python
def get_weather(city: str, date: str = "今天") -> dict:
    """调用天气 API"""
    # 实际应该调用真实的天气 API
    return {
        "city": city,
        "date": date,
        "weather": "晴",
        "temperature": "20-28°C"
    }
```

### 4.3 Agent 调用流程

```python
import openai

# 1. 定义可用工具
tools = [
    {
        "type": "function",
        "function": {
            "name": "get_weather",
            "description": "获取天气信息",
            "parameters": {
                "type": "object",
                "properties": {
                    "city": {"type": "string"},
                    "date": {"type": "string"}
                },
                "required": ["city"]
            }
        }
    }
]

# 2. 发送请求
response = openai.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "明天北京天气怎么样？"}
    ],
    tools=tools
)

# 3. LLM 返回需要调用的工具
tool_call = response.choices[0].message.tool_calls[0]
# tool_call.function.name = "get_weather"
# tool_call.function.arguments = '{"city": "北京", "date": "明天"}'

# 4. 执行工具
result = get_weather(city="北京", date="明天")

# 5. 将结果返回给 LLM
final_response = openai.chat.completions.create(
    model="gpt-4",
    messages=[
        {"role": "user", "content": "明天北京天气怎么样？"},
        response.choices[0].message,
        {
            "role": "tool",
            "tool_call_id": tool_call.id,
            "content": str(result)
        }
    ]
)

print(final_response.choices[0].message.content)
# 输出："明天北京天气晴朗，气温 20-28°C。"
```

## 5. 记忆系统

Agent 需要记住之前的对话和执行过的任务。

### 5.1 短期记忆（对话历史）

```python
class ConversationMemory:
    def __init__(self, max_tokens=4000):
        self.messages = []
        self.max_tokens = max_tokens
    
    def add_message(self, role, content):
        self.messages.append({"role": role, "content": content})
        # 如果超过 token 限制，删除最早的消息
        self._trim_messages()
    
    def get_messages(self):
        return self.messages
```

### 5.2 长期记忆（向量数据库）

对于需要记住大量信息的场景（如客服 Agent），可以使用向量数据库。

```python
from langchain.vectorstores import Chroma
from langchain.embeddings import OpenAIEmbeddings

# 存储历史对话
vectorstore = Chroma(embedding_function=OpenAIEmbeddings())

# 添加记忆
vectorstore.add_texts([
    "用户喜欢喝咖啡",
    "用户的生日是 3 月 15 日",
    "用户上次购买了 MacBook Pro"
])

# 检索相关记忆
relevant_memories = vectorstore.similarity_search("用户喜欢什么饮料？", k=3)
```

## 6. 实战：构建一个简单的 Agent

让我们用 LangChain 框架构建一个能够搜索网络和执行计算的 Agent。

### 6.1 安装依赖

```bash
pip install langchain openai langchain-community
```

### 6.2 实现代码

```python
from langchain.agents import initialize_agent, Tool, AgentType
from langchain.llms import OpenAI
from langchain.utilities import SerpAPIWrapper
from langchain.tools import tool

# 1. 定义工具
@tool
def calculator(expression: str) -> str:
    """执行数学计算。输入应该是一个数学表达式，如 '2 + 2'"""
    try:
        return str(eval(expression))
    except Exception as e:
        return f"计算错误: {str(e)}"

search = SerpAPIWrapper()

tools = [
    Tool(
        name="Search",
        func=search.run,
        description="当需要查询实时信息或最新数据时使用"
    ),
    Tool(
        name="Calculator",
        func=calculator,
        description="执行数学计算"
    )
]

# 2. 初始化 Agent
llm = OpenAI(temperature=0)
agent = initialize_agent(
    tools=tools,
    llm=llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION,
    verbose=True  # 显示思考过程
)

# 3. 运行 Agent
result = agent.run(
    "特斯拉今天的股价是多少？如果我买 100 股需要多少钱？"
)

print(result)
```

**输出示例**：
```
> Entering new AgentExecutor chain...

Thought: 我需要先查询特斯拉的当前股价
Action: Search
Action Input: "特斯拉股价 今天"
Observation: 特斯拉 (TSLA) 当前股价为 $245.32

Thought: 现在我需要计算 100 股的总价
Action: Calculator
Action Input: 245.32 * 100
Observation: 24532.0

Thought: 我现在知道最终答案了
Final Answer: 特斯拉今天的股价是 $245.32，购买 100 股需要 $24,532。
```

## 7. Agent 的应用场景

### 7.1 个人助理

- **日程管理**：自动安排会议、设置提醒
- **邮件处理**：分类、回复、总结邮件
- **信息聚合**：每日新闻摘要、股票监控

### 7.2 企业应用

- **客服 Agent**：24/7 智能客服，处理常见问题
- **数据分析 Agent**：自动生成业务报告
- **代码助手**：代码审查、Bug 修复、文档生成

### 7.3 垂直领域

- **医疗 Agent**：辅助诊断、药物查询

## 8. Agent 的挑战与未来

### 8.1 当前挑战

1. **可靠性**：Agent 可能会"幻觉"，执行错误的操作
2. **成本**：频繁调用 LLM 和工具成本较高
3. **安全性**：需要严格控制 Agent 的权限，防止误操作
4. **可解释性**：复杂任务的决策过程难以追踪

### 8.2 最佳实践

- ✅ **明确边界**：限制 Agent 的操作范围
- ✅ **人工审核**：关键操作需要人工确认
- ✅ **错误处理**：设计完善的异常处理机制
- ✅ **日志记录**：记录所有决策和操作

### 8.3 未来展望

- **多 Agent 协作**：多个专业 Agent 协同工作
- **自我进化**：Agent 能够从经验中学习并改进
- **具身智能**：Agent 控制机器人，与物理世界交互
