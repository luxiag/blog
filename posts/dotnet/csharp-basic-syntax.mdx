# C# 基础语法：程序结构、变量、运算符与流程控制

学习 C# 不应该一上来就从 ASP.NET Core、EF Core 或微服务开始。那些上层框架都建立在语言基础之上：程序怎么启动、变量怎么声明、类型怎么区分、条件和循环怎么写、方法怎么组织逻辑。

这篇文章是 C# 语言系列的入门篇，适合刚开始学 C#，或者从 JavaScript、Java、Python 等语言转过来的读者。

## 第一个 C# 程序

现代 .NET 项目可以使用顶级语句，最简单的程序只需要一行代码。

```csharp
Console.WriteLine("Hello, C#!");
```

创建并运行控制台项目：

```bash
dotnet new console -n CSharpBasics
cd CSharpBasics
dotnet run
```

如果写成传统完整结构，大概是这样：

```csharp
using System;

namespace CSharpBasics;

public class Program
{
    public static void Main(string[] args)
    {
        Console.WriteLine("Hello, C#!");
    }
}
```

几个关键点：

- `using System;` 引入命名空间
- `namespace` 用来组织类型，避免命名冲突
- `class Program` 定义一个类
- `Main` 是传统控制台程序入口
- `Console.WriteLine` 向控制台输出内容

## 注释

注释用于解释代码意图，不会被编译执行。

```csharp
// 单行注释
Console.WriteLine("开始执行");

/*
 多行注释
 适合临时说明较长内容
*/
Console.WriteLine("执行完成");
```

注释应该解释“为什么这样做”，不要重复代码本身已经表达清楚的内容。

## 变量与常量

变量用于保存数据，常量用于保存不会变化的数据。

```csharp
string name = "Alice";
int age = 18;
decimal balance = 99.5m;

const double Pi = 3.1415926;

Console.WriteLine($"姓名：{name}，年龄：{age}，余额：{balance}");
Console.WriteLine($"圆周率：{Pi}");
```

`const` 的值必须在编译期确定。如果值来自配置、数据库或运行时计算，不能用 `const`。

## var 类型推断

`var` 让编译器根据右侧表达式推断变量类型。

```csharp
var name = "Alice";       // string
var age = 18;             // int
var total = 100.5m;       // decimal
var isActive = true;      // bool
```

`var` 不是动态类型。类型一旦推断完成，就不能再赋值为其他类型。

```csharp
var count = 10;
// count = "ten"; // 编译错误
```

## 常用基础类型

C# 是强类型语言。变量类型决定了它能保存什么数据，也决定了能执行哪些操作。

| 类型 | 用途 | 示例 |
|---|---|---|
| `int` | 整数 | `18` |
| `long` | 更大范围整数 | `10000000000L` |
| `decimal` | 金额等高精度小数 | `99.9m` |
| `double` | 科学计算小数 | `3.14` |
| `bool` | 布尔值 | `true` / `false` |
| `char` | 单个字符 | `'A'` |
| `string` | 字符串 | `"hello"` |
| `DateTime` | 日期时间 | `DateTime.Now` |

```csharp
int quantity = 3;
decimal price = 19.9m;
bool paid = false;
DateTime createdAt = DateTime.Now;

decimal amount = quantity * price;

Console.WriteLine($"金额：{amount}，已支付：{paid}，创建时间：{createdAt}");
```

金额计算优先使用 `decimal`，不要用 `double` 表示钱。

## 字符串插值

字符串插值用 `$"..."`，可以把变量直接放进字符串里。

```csharp
string productName = "键盘";
decimal price = 199m;

Console.WriteLine($"商品：{productName}，价格：{price:C}");
```

`{price:C}` 会按当前区域设置格式化为货币。实际项目里金额展示通常还会结合文化区域配置。

## 运算符

常见算术运算：

```csharp
int a = 10;
int b = 3;

Console.WriteLine(a + b); // 13
Console.WriteLine(a - b); // 7
Console.WriteLine(a * b); // 30
Console.WriteLine(a / b); // 3，整数除法会丢弃小数部分
Console.WriteLine(a % b); // 1，取余
```

比较运算返回 `bool`。

```csharp
int age = 20;

Console.WriteLine(age >= 18); // True
Console.WriteLine(age == 18); // False
Console.WriteLine(age != 18); // True
```

逻辑运算用于组合多个条件。

```csharp
bool isVip = true;
decimal amount = 600m;

bool freeShipping = isVip || amount >= 500m;
bool canPay = amount > 0 && amount <= 1000m;

Console.WriteLine(freeShipping);
Console.WriteLine(canPay);
```

## if 条件判断

`if` 用来根据条件执行不同逻辑。

```csharp
decimal amount = 1200m;

if (amount >= 1000m)
{
    Console.WriteLine("大额订单");
}
else if (amount >= 100m)
{
    Console.WriteLine("普通订单");
}
else
{
    Console.WriteLine("小额订单");
}
```

条件表达式必须是 `bool`，不能像 JavaScript 那样把数字或字符串自动当作真假值。

## switch 分支

当一个值有多个固定分支时，可以使用 `switch`。

```csharp
string status = "Paid";

switch (status)
{
    case "Pending":
        Console.WriteLine("待支付");
        break;
    case "Paid":
        Console.WriteLine("已支付");
        break;
    case "Canceled":
        Console.WriteLine("已取消");
        break;
    default:
        Console.WriteLine("未知状态");
        break;
}
```

现代 C# 更常用 `switch` 表达式返回结果。

```csharp
string text = status switch
{
    "Pending" => "待支付",
    "Paid" => "已支付",
    "Canceled" => "已取消",
    _ => "未知状态"
};

Console.WriteLine(text);
```

## for 循环

`for` 适合知道循环次数的场景。

```csharp
for (int i = 1; i <= 5; i++)
{
    Console.WriteLine($"第 {i} 次执行");
}
```

## while 循环

`while` 适合根据条件持续执行。

```csharp
int retryCount = 0;

while (retryCount < 3)
{
    retryCount++;
    Console.WriteLine($"第 {retryCount} 次重试");
}
```

## foreach 循环

`foreach` 适合遍历集合。

```csharp
string[] names = { "Alice", "Bob", "Cindy" };

foreach (string name in names)
{
    Console.WriteLine(name);
}
```

后续学习 LINQ 时，你会看到很多集合遍历可以改成声明式查询。

## 方法

方法用于封装一段可复用逻辑。

```csharp
decimal CalculateTotal(decimal price, int quantity)
{
    return price * quantity;
}

decimal total = CalculateTotal(19.9m, 3);
Console.WriteLine(total);
```

方法可以没有返回值，用 `void` 表示。

```csharp
void PrintOrder(string orderNo, decimal amount)
{
    Console.WriteLine($"订单号：{orderNo}，金额：{amount}");
}

PrintOrder("NO-001", 99m);
```

## 参数默认值和命名参数

参数可以设置默认值。

```csharp
decimal CalculateShippingFee(decimal amount, bool isVip = false)
{
    if (isVip || amount >= 500m)
    {
        return 0m;
    }

    return 20m;
}

Console.WriteLine(CalculateShippingFee(300m));
Console.WriteLine(CalculateShippingFee(amount: 300m, isVip: true));
```

命名参数可以提升调用时的可读性，尤其是布尔参数较多时。

## 基础输入输出

控制台程序可以用 `Console.ReadLine` 读取输入。

```csharp
Console.Write("请输入姓名：");
string? name = Console.ReadLine();

Console.WriteLine($"你好，{name ?? "未命名用户"}");
```

`ReadLine` 返回 `string?`，因为用户输入可能为空。可空引用类型会在后面的现代 C# 语法文章里继续展开。

## 一个完整小练习

下面用基础语法实现一个订单金额计算器。

```csharp
Console.Write("请输入商品单价：");
string? priceText = Console.ReadLine();

Console.Write("请输入购买数量：");
string? quantityText = Console.ReadLine();

if (!decimal.TryParse(priceText, out decimal price) || price <= 0)
{
    Console.WriteLine("单价不合法");
    return;
}

if (!int.TryParse(quantityText, out int quantity) || quantity <= 0)
{
    Console.WriteLine("数量不合法");
    return;
}

decimal total = price * quantity;
decimal discount = total >= 500m ? 50m : 0m;
decimal finalAmount = total - discount;

Console.WriteLine($"原始金额：{total}");
Console.WriteLine($"优惠金额：{discount}");
Console.WriteLine($"应付金额：{finalAmount}");
```

这个例子串起了输入、类型转换、条件判断、变量计算和输出。

## 总结

C# 基础语法的核心是：用类型描述数据，用变量保存状态，用运算符计算结果，用条件和循环控制流程，用方法组织逻辑。

掌握这些之后，再学习类、对象、集合、异常、泛型和 LINQ，会顺畅很多。
