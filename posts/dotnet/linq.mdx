# LINQ 完全指南

## 什么是 LINQ

LINQ（Language Integrated Query，集成查询语言）是 .NET 框架的一项革命性功能，它将强大的查询能力直接集成到 C# 和 VB.NET 等语言中。在 LINQ 出现之前，对集合、数据库、XML 等数据进行查询需要使用不同的语法和方法，学习成本高且代码难以维护。LINQ 的出现彻底改变了这一局面，它提供了一种统一、声明式的查询方式，让开发者能够以类似 SQL 语句的方式操作各种数据源。

LINQ 的核心优势在于其强大的抽象能力和类型安全性。无论数据源是内存中的集合、数据库表、XML 文档还是外部服务，LINQ 都提供了统一的查询语法。这意味着开发者只需要学习一种查询模式，就可以应用到多种场景中。此外，由于 LINQ 是完全集成在 .NET 类型系统中的，所有查询都会在编译时进行类型检查，大大减少了运行时错误的发生。

```csharp
// 传统方式：手动遍历和筛选
var results = new List<int>();
foreach (var number in numbers)
{
    if (number % 2 == 0)
    {
        results.Add(number * 2);
    }
}

// LINQ 方式：声明式查询
var linqResults = numbers
    .Where(n => n % 2 == 0)
    .Select(n => n * 2);
```

## LINQ 的两种语法形式

LINQ 提供了两种主要的语法形式：查询语法（Query Syntax）和方法语法（Method Syntax）。这两种形式在功能上完全等价，只是在书写方式上有所不同。理解这两种语法的特点及其适用场景，对于编写清晰、高效的 LINQ 代码至关重要。

### 查询语法（Query Syntax）

查询语法采用了类似 SQL 的声明式风格，以 `from` 关键字开始，以 `select` 或 `group` 关键字结束。这种语法对于熟悉 SQL 的开发者来说非常自然直观，特别适合编写复杂的、多步骤的查询操作。查询语法在编译时会被编译器转换成对应的方法语法调用，因此两者在性能上没有任何差异。

```csharp
// 基本查询结构
var query = from n in numbers
            where n > 10
            orderby n descending
            select n * 2;

// 多数据源查询
var joinQuery = from person in people
                join dept in departments on person.DeptId equals dept.Id
                where dept.Name == "技术部"
                select new
                {
                    PersonName = person.Name,
                    DeptName = dept.Name
                };

// 分组查询
var groupQuery = from fruit in fruits
                 group fruit by fruit.Color into colorGroup
                 where colorGroup.Count() > 2
                 select new
                 {
                     Color = colorGroup.Key,
                     Count = colorGroup.Count()
                 };
```

### 方法语法（Method Syntax）

方法语法使用扩展方法和 Lambda 表达式来构建查询，这种方式更加函数式，也更符合 C# 开发者日常使用集合操作的习惯。方法语法通常更加紧凑，适合简单的查询操作。对于复杂的查询，方法语法可以通过方法链的方式保持代码的连贯性和可读性。

```csharp
// 基本方法链
var result = numbers
    .Where(n => n > 10)
    .OrderByDescending(n => n)
    .Select(n => n * 2)
    .ToList();

// 使用聚合方法
var sum = numbers.Sum();
var average = numbers.Average();
var max = numbers.Max();
var count = numbers.Count(n => n > 20);

// 使用 Aggregate 进行自定义聚合
var product = numbers.Aggregate(1, (acc, n) => acc * n);

// 使用 let 关键字在查询语法中创建中间变量
var letQuery = from n in numbers
               let doubled = n * 2
               let squared = doubled * doubled
               where doubled > 50
               select squared;
```

### 两种语法的混合使用

在实际开发中，查询语法和方法语法可以自由混合使用，这为开发者提供了极大的灵活性。通常，对于查询的主要部分使用查询语法可以提高可读性，而对于某些特定的操作（如聚合、分页）则使用方法语法更加便捷。

```csharp
// 混合使用示例
var mixedQuery = from student in students
                 where student.Score >= 60
                 orderby student.Score descending
                 select new
                 {
                     student.Name,
                     student.Score,
                     Grade = student.Score >= 90 ? "A" :
                             student.Score >= 80 ? "B" :
                             student.Score >= 70 ? "C" : "D"
                 };

// 转换为方法语法添加额外处理
var finalResult = mixedQuery
    .Skip((pageNumber - 1) * pageSize)
    .Take(pageSize)
    .ToList();
```

## 延迟执行详解

延迟执行（Deferred Execution）是 LINQ 最重要的特性之一，也是最容易导致误解的特性。理解延迟执行的工作原理，对于避免常见的性能陷阱和编写高效的 LINQ 代码至关重要。很多开发者在初次接触 LINQ 时会遇到查询结果不符合预期的情况，这通常是因为对延迟执行理解不够深入。

### 延迟执行的工作原理

当使用 LINQ 方法（如 `Where`、`Select`、`OrderBy` 等）时，这些方法并不会立即执行查询或遍历数据源。相反，它们会创建一个包含查询逻辑的表达式树（Expression Tree）或委托（Delegate）。实际的遍历和计算操作只会在两种情况下发生：遍历结果（如使用 `foreach` 循环）或调用终止方法（如 `ToList`、`ToArray`、`Count` 等）。

```csharp
// 这个阶段不会执行任何查询操作
var query = numbers.Where(n => n > 10);

// 直到这里才开始实际执行查询
foreach (var num in query)
{
    Console.WriteLine(num);
}

// 或者调用终止方法时执行
var list = query.ToList();
```

这种设计带来了显著的性能优势。首先，对于大型数据集，如果查询后只需要获取部分结果，延迟执行可以避免不必要的完整遍历。其次，延迟执行使得 LINQ 能够支持流式处理（Streaming），即每次只处理一个元素，而不是将所有元素一次性加载到内存中。

```csharp
// 演示延迟执行的实际效果
var random = new Random();
var infiniteSequence = Enumerable.Range(1, int.MaxValue)
    .Select(n => random.Next(100));

// 这个查询不会真正生成无限序列
var filteredQuery = infiniteSequence.Where(n => n > 50);

// 只会获取前 5 个符合条件的元素
var firstFive = filteredQuery.Take(5).ToList();
```

### 重新执行查询

由于延迟执行的特性，每次遍历 LINQ 查询结果时都会重新执行查询逻辑。这意味着如果数据源在两次查询之间发生了变化，第二次遍历将获得不同的结果。这一特性在某些场景下非常有用，但也可能导致意外的行为。

```csharp
var numbers = new List<int> { 1, 2, 3, 4, 5 };

// 创建查询
var query = numbers.Where(n => n > 2);

// 第一次遍历
Console.WriteLine("第一次遍历：");
foreach (var n in query)
    Console.WriteLine(n); // 输出：3, 4, 5

// 修改数据源
numbers.Add(6);
numbers.Add(1);

// 第二次遍历 - 注意结果已经改变
Console.WriteLine("\n修改数据后第二次遍历：");
foreach (var n in query)
    Console.WriteLine(n); // 输出：3, 4, 5, 6
```

### 立即执行与终止操作符

某些 LINQ 操作会触发立即执行，这些操作通常被称为"终止操作符"或"终止方法"。调用这些方法会立即遍历数据源并返回结果，之后对数据源的修改不会影响已经返回的结果。

```csharp
// 常见的终止方法
var list = numbers.ToList();           // 转换为 List
var array = numbers.ToArray();         // 转换为数组
var first = numbers.First();           // 获取第一个元素
var firstOrDefault = numbers.FirstOrDefault(); // 获取第一个或默认值
var single = numbers.Single();         // 获取唯一元素
var count = numbers.Count();           // 计数
var any = numbers.Any(n => n > 10);    // 是否存在满足条件的元素
var all = numbers.All(n => n > 0);     // 是否所有元素都满足条件
var dict = numbers.ToDictionary(n => n); // 转换为字典

// 使用 ElementAt 获取指定索引的元素
var element = numbers.ElementAt(3);

// 使用 Aggregate 进行自定义聚合
var product = numbers.Aggregate((a, b) => a * b);
```

## 常见查询操作符详解

LINQ 提供了丰富的查询操作符，覆盖了从简单的筛选、投影到复杂的分组、连接等各种查询需求。深入理解这些操作符的工作原理和使用场景，是编写高效 LINQ 代码的基础。每个操作符都有其特定的用途和性能特点，选择合适的操作符可以显著提升代码的效率和可读性。

### 筛选操作符（Filtering）

筛选操作符用于从数据源中选择满足特定条件的元素。最常用的是 `Where` 操作符，它接受一个返回布尔值的委托（Predicate），返回所有满足条件的元素。

```csharp
// 基本筛选
var evenNumbers = numbers.Where(n => n % 2 == 0);

// 多条件筛选
var primeNumbers = numbers.Where(n =>
{
    if (n < 2) return false;
    for (int i = 2; i <= Math.Sqrt(n); i++)
        if (n % i == 0) return false;
    return true;
});

// 使用索引进行筛选
var indexedFilter = numbers.Where((n, index) => n > index);

// OfType 筛选特定类型
var strings = objects.OfType<string>();
var integers = objects.OfType<int>();

// 使用 TakeWhile 和 SkipWhile
var takeWhile = numbers.TakeWhile(n => n < 10); // 遇到 >=10 停止
var skipWhile = numbers.SkipWhile(n => n < 10); // 跳过所有 <10 的元素
```

### 投影操作符（Projection）

投影操作符用于将数据源中的元素转换为另一种形式。`Select` 是最基础的投影操作符，而 `SelectMany` 则用于扁平化嵌套集合。

```csharp
// 基本投影
var names = people.Select(p => p.Name);
var squares = numbers.Select(n => n * n);

// 索引投影
var indexed = numbers.Select((n, i) => new { Number = n, Index = i });

// 复合投影
var projections = people.Select(p => new PersonDto
{
    FullName = $"{p.FirstName} {p.LastName}",
    Age = DateTime.Now.Year - p.BirthYear
});

// SelectMany 扁平化嵌套集合
var allTags = posts.SelectMany(post => post.Tags);
var allComments = posts.SelectMany(
    post => post.Comments,
    (post, comment) => new { post.Title, comment.Content }
);

// 使用 Let 创建中间变量
var query = from person in people
            let currentYear = DateTime.Now.Year
            let age = currentYear - person.BirthYear
            where age >= 18
            select new { person.Name, Age = age };
```

### 排序操作符（Ordering）

排序操作符用于对元素进行排序，支持单字段和多字段排序，以及升序和降序排列。

```csharp
// 基本升序排序
var ascending = numbers.OrderBy(n => n);

// 降序排序
var descending = numbers.OrderByDescending(n => n);

// 多级排序
var multiSort = people
    .OrderBy(p => p.Department)
    .ThenBy(p => p.Salary)
    .ThenByDescending(p => p.HireDate);

// 使用 ThenBy 进行链式多字段排序
var complexSort = products
    .OrderBy(p => p.Category)
    .ThenByDescending(p => p.SalesCount)
    .ThenBy(p => p.Price);

// 使用 IComparer 进行自定义排序
var customSort = numbers.OrderBy(n => n, new CustomComparer());

// Reverse 反转序列
var reversed = numbers.Reverse();
```

### 分组操作符（Grouping）

分组操作符用于将元素按照某个键值进行分组，这在数据分析场景中非常常用。

```csharp
// 基本分组
var groupedByCategory = products.GroupBy(p => p.Category);

// 带元素转换的分组
var groupedWithCount = products
    .GroupBy(p => p.Category)
    .Select(g => new
    {
        Category = g.Key,
        Count = g.Count(),
        TotalValue = g.Sum(p => p.Price)
    });

// 多字段分组
var multiGroup = people.GroupBy(
    p => new { p.Department, p.Position },
    p => p.Salary
);

// 使用 GroupJoin 进行分组连接
var departmentStats = departments
    .GroupJoin(
        employees,
        d => d.Id,
        e => e.DepartmentId,
        (d, emps) => new
        {
            Department = d.Name,
            EmployeeCount = emps.Count(),
            TotalSalary = emps.Sum(e => e.Salary)
        }
    );

// 在查询语法中分组
var querySyntax = from order in orders
                  group order by order.CustomerId into customerGroup
                  where customerGroup.Count() > 5
                  select new
                  {
                      CustomerId = customerGroup.Key,
                      OrderCount = customerGroup.Count(),
                      TotalAmount = customerGroup.Sum(o => o.Amount)
                  };
```

### 连接操作符（Join）

连接操作用于组合来自不同数据源的元素，类似于 SQL 中的 JOIN 语句。

```csharp
// 内连接（Inner Join）
var innerJoin = from person in people
                join dept in departments on person.DeptId equals dept.Id
                select new { person.Name, DeptName = dept.Name };

// 方法语法内连接
var methodInnerJoin = people.Join(
    departments,
    p => p.DeptId,
    d => d.Id,
    (p, d) => new { p.Name, DeptName = d.Name }
);

// 左外连接（Left Outer Join）
var leftJoin = from person in people
               join dept in departments on person.DeptId equals dept.Id into deptGroup
               from dept in deptGroup.DefaultIfEmpty()
               select new { person.Name, DeptName = dept?.Name ?? "未分配" };

// 右外连接需要反转数据源顺序
var rightJoin = from dept in departments
                join person in people on dept.Id equals person.DeptId into personGroup
                from person in personGroup.DefaultIfEmpty()
                select new { person?.Name ?? "无员工", DeptName = dept.Name };

// 多条件连接
var multiJoin = from order in orders
                join customer in customers
                    on new { order.CustomerId, order.OrderDate.Date }
                    equals new { c.CustomerId, c.RegisterDate }
                select new { order.Id, customer.Name };

// 交叉连接（Cross Join）
var crossJoin = from person in people
                from dept in departments
                select new { person.Name, dept.Name };
```

### 集合操作符（Set Operations）

集合操作用于对两个序列进行交集、差集、并集等运算。

```csharp
// 并集（Union）- 自动去重
var union = numbers1.Union(numbers2);

// 交集（Intersect）
var intersect = numbers1.Intersect(numbers2);

// 差集（Except）
var except = numbers1.Except(numbers2);

// 重复并集（Concat）- 不去重
var concat = numbers1.Concat(numbers2);

// 去除重复（Distinct）
var distinct = numbers.Distinct();

// 使用自定义相等比较器
var distinctBy = numbers.DistinctBy(n => n % 10);

// 检查是否相等（SequenceEqual）
var isEqual = list1.SequenceEqual(list2);

// 检查是否为子集或超集
var isSubset = numbers1.All(n => numbers2.Contains(n));
```

### 生成操作符（Generation）

生成操作用于创建新的序列。

```csharp
// 创建连续整数序列
var range = Enumerable.Range(1, 100);

// 创建重复元素序列
var repeat = Enumerable.Repeat("Hello", 5);

// 创建空序列
var empty = Enumerable.Empty<int>();

// 使用 Yield 创建自定义序列
public IEnumerable<int> Fibonacci(int count)
{
    yield return 0;
    yield return 1;
    for (int i = 2; i < count; i++)
    {
        yield return i;
    }
}
```

### 量词操作符（Quantifiers）

量词操作符返回布尔值，表示序列中元素是否满足某种条件。

```csharp
// Any - 是否存在满足条件的元素
var hasEven = numbers.Any(n => n % 2 == 0);
var hasAny = numbers.Any(); // 序列是否为空

// All - 是否所有元素都满足条件
var allPositive = numbers.All(n => n > 0);

// Contains - 是否包含指定元素
var containsFive = numbers.Contains(5);
var containsCustom = list.Contains(item, customComparer);
```

### 元素操作符（Element Operators）

元素操作用于获取序列中的特定元素。

```csharp
// First 和 FirstOrDefault
var first = numbers.First(); // 无元素则抛出异常
var firstOrDefault = numbers.FirstOrDefault(); // 返回默认值

// Last 和 LastOrDefault
var last = numbers.Last();
var lastOrDefault = numbers.LastOrDefault();

// Single 和 SingleOrDefault
var single = numbers.Single(); // 必须恰好一个元素
var singleOrDefault = numbers.SingleOrDefault();

// ElementAt 和 ElementAtOrDefault
var element = numbers.ElementAt(5);
var elementOrDefault = numbers.ElementAtOrDefault(5);

// DefaultIfEmpty
var withDefault = empty.DefaultIfEmpty(-1);
```

### 聚合操作符（Aggregation）

聚合操作符对序列中的元素进行计算，返回单个值。

```csharp
// 基本聚合
var sum = numbers.Sum();
var average = numbers.Average();
var count = numbers.Count();
var max = numbers.Max();
var min = numbers.Min();

// 带条件的聚合
var sumOfEvens = numbers.Sum(n => n % 2 == 0 ? n : 0);
var countOfPrimes = numbers.Count(n => IsPrime(n));

// MaxBy 和 MinBy
var oldestPerson = people.MaxBy(p => p.Age);
var cheapestProduct = products.MinBy(p => p.Price);

// Aggregate - 自定义聚合
var product = numbers.Aggregate(1, (acc, n) => acc * n);
var sentence = words.Aggregate((a, b) => $"{a} {b}");
var groupedSum = numbers.Aggregate(
    new Dictionary<int, int>(),
    (dict, n) => {
        int key = n % 10;
        dict[key] = dict.TryGetValue(key, out var sum) ? sum + n : n;
        return dict;
    }
);

// Chunk - 将序列分块
var chunks = numbers.Chunk(5); // 每5个元素一组
```

### 分区操作符（Partitioning）

分区操作符用于将序列分成两部分或多部分。

```csharp
// Take 和 TakeLast
var first5 = numbers.Take(5);
var last5 = numbers.TakeLast(5);

// Skip 和 SkipLast
var skip5 = numbers.Skip(5);

// TakeWhile 和 SkipWhile
var takeWhile = numbers.TakeWhile(n => n < 10);
var skipWhile = numbers.SkipWhile(n => n < 10);

// 使用索引的分区
var indexedTake = numbers.TakeWhile((n, i) => n > i);

// Chunk - 分块
var chunked = numbers.Chunk(100); // 每100个一组
```

## LINQ 与数据库查询（LINQ to SQL / Entity Framework）

LINQ 最强大的应用之一是与数据库查询的集成。通过 LINQ to SQL 或 Entity Framework，开发者可以使用 LINQ 查询语法来操作数据库，而无需编写原生 SQL 语句。这种方式不仅提高了开发效率，还提供了编译时类型检查和代码重构支持。

### 基本查询映射

```csharp
// Entity Framework Core 示例
var activeUsers = await context.Users
    .Where(u => u.IsActive)
    .OrderBy(u => u.JoinDate)
    .Select(u => new UserDto
    {
        Id = u.Id,
        Name = u.UserName,
        JoinDate = u.JoinDate
    })
    .ToListAsync();

// 翻译生成的 SQL：
-- SELECT [u].[Id], [u].[UserName], [u].[JoinDate]
-- FROM [Users] AS [u]
-- WHERE [u].[IsActive] = CAST(1 AS bit)
-- ORDER BY [u].[JoinDate]

// 复杂查询
var orders = await context.Orders
    .Include(o => o.Customer)
    .Include(o => o.OrderItems)
    .Where(o => o.OrderDate >= startDate && o.OrderDate <= endDate)
    .OrderByDescending(o => o.TotalAmount)
    .Skip((page - 1) * pageSize)
    .Take(pageSize)
    .ToListAsync();
```

### 编译查询优化性能

对于频繁执行的查询，可以使用编译查询来提高性能。

```csharp
// 定义编译查询
private static readonly Func<AppDbContext, DateTime, IEnumerable<Order>>
    GetOrdersByDate = EF.CompileQuery(
        (context, date) => context.Orders
            .Where(o => o.OrderDate.Date == date)
            .Include(o => o.Customer)
            .ToList());

// 使用编译查询
var todayOrders = GetOrdersByDate(context, DateTime.Today);
```

### 原生 SQL 查询

在某些复杂场景下，可能需要直接使用原生 SQL。

```csharp
// FromSqlRaw 用于查询
var users = await context.Users
    .FromSqlRaw("SELECT * FROM Users WHERE IsActive = 1")
    .ToListAsync();

// 参数化查询
var user = await context.Users
    .FromSqlRaw("SELECT * FROM Users WHERE Id = {0}", userId)
    .FirstOrDefaultAsync();

// 执行非查询操作
await context.Database
    .ExecuteSqlRawAsync("UPDATE Users SET LastLogin = GETDATE() WHERE Id = {0}", userId);
```

## 性能优化技巧

编写高效的 LINQ 查询需要对 LINQ 的执行机制有深入理解。以下是一些重要的性能优化技巧，帮助你在实际开发中避免常见的性能陷阱。

### 理解执行时机

```csharp
// 延迟执行示例
var query = products.Where(p => p.Price > 100); // 不执行

// 终止操作触发执行
var list = query.ToList(); // 实际执行查询

// 多次遍历会导致多次查询
foreach (var p in query) { } // 第一次遍历
foreach (var p in query) { } // 第二次遍历 - 再次执行

// 尽早执行并缓存结果
var cachedList = query.ToList();
```

```csharp
// 生成斐波那契数列
public static IEnumerable<int> Fibonacci()
{
    int a = 0, b = 1;
    while (true)
    {
        yield return a;
        int temp = a + b;
        a = b;
        b = temp;
    }
}

// 生成质数
public static IEnumerable<int> Primes()
{
    var primes = new List<int>();
    int n = 2;
    while (true)
    {
        bool isPrime = true;
        int limit = (int)Math.Sqrt(n);
        for (int i = 2; i <= limit; i++)
        {
            if (n % i == 0)
            {
                isPrime = false;
                break;
            }
        }
        if (isPrime)
        {
            primes.Add(n);
            yield return n;
        }
        n++;
    }
}
```

```csharp
// 电商数据分析示例
public class OrderAnalyzer
{
    private readonly List<Order> _orders;
    private readonly List<Customer> _customers;

    public OrderAnalyzer(List<Order> orders, List<Customer> customers)
    {
        _orders = orders;
        _customers = customers;
    }

    // 1. 分析每个客户的订单统计
    public Dictionary<int, CustomerOrderStats> GetCustomerOrderStats()
    {
        return _orders
            .GroupBy(o => o.CustomerId)
            .ToDictionary(
                g => g.Key,
                g => new CustomerOrderStats
                {
                    OrderCount = g.Count(),
                    TotalAmount = g.Sum(o => o.Amount),
                    AverageAmount = g.Average(o => o.Amount),
                    FirstOrderDate = g.Min(o => o.OrderDate),
                    LastOrderDate = g.Max(o => o.OrderDate)
                });
    }

    // 2. 找出高价值客户
    public List<Customer> GetHighValueCustomers(decimal threshold)
    {
        return _customers
            .Join(
                _orders.GroupBy(o => o.CustomerId)
                    .Where(g => g.Sum(o => o.Amount) >= threshold)
                    .Select(g => new { CustomerId = g.Key, Total = g.Sum(o => o.Amount) }),
                c => c.Id,
                o => o.CustomerId,
                (c, o) => c)
            .Distinct()
            .OrderByDescending(c => c.Level)
            .ToList();
    }

    // 3. 分析月度销售趋势
    public List<MonthlySales> GetMonthlySalesTrend(int year)
    {
        return _orders
            .Where(o => o.OrderDate.Year == year)
            .GroupBy(o => new { o.OrderDate.Year, o.OrderDate.Month })
            .Select(g => new MonthlySales
            {
                Year = g.Key.Year,
                Month = g.Key.Month,
                OrderCount = g.Count(),
                TotalSales = g.Sum(o => o.Amount),
                AverageOrderValue = g.Average(o => o.Amount)
            })
            .OrderBy(m => m.Month)
            .ToList();
    }

    // 4. 查找流失风险客户
    public List<Customer> GetChurnRiskCustomers(int daysInactive)
    {
        var cutoffDate = DateTime.Now.AddDays(-daysInactive);
        var activeCustomerIds = _orders
            .Where(o => o.OrderDate >= cutoffDate)
            .Select(o => o.CustomerId)
            .Distinct();

        return _customers
            .Where(c => !activeCustomerIds.Contains(c.Id))
            .OrderByDescending(c => c.LastPurchaseDate ?? c.JoinDate)
            .ToList();
    }

    // 5. 产品交叉销售分析
    public List<ProductPairAnalysis> GetProductPairAnalysis()
    {
        // 获取经常一起购买的产品组合
        var orderProducts = _orders
            .SelectMany(o => o.Items.Select(i => new { o.Id, i.ProductId }))
            .ToList();

        return orderProducts
            .GroupBy(x => x.Id)
            .Where(g => g.Count() > 1) // 订单中有多个产品
            .SelectMany(g => g.Select(x => x.ProductId).ToPairs())
            .Where(pair => pair.First != pair.Second)
            .GroupBy(pair => (First: pair.First, Second: pair.Second))
            .OrderByDescending(g => g.Count())
            .Take(20)
            .Select(g => new ProductPairAnalysis
            {
                ProductId1 = g.Key.First,
                ProductId2 = g.Key.Second,
                CoPurchaseCount = g.Count()
            })
            .ToList();
    }

    // 辅助方法：生成产品对
    private static IEnumerable<(T First, T Second)> ToPairs<T>(
        this IEnumerable<T> source)
    {
        var list = source.ToList();
        for (int i = 0; i < list.Count; i++)
        {
            for (int j = i + 1; j < list.Count; j++)
            {
                yield return (list[i], list[j]);
            }
        }
    }
}

public record CustomerOrderStats
{
    public int OrderCount { get; init; }
    public decimal TotalAmount { get; init; }
    public decimal AverageAmount { get; init; }
    public DateTime FirstOrderDate { get; init; }
    public DateTime LastOrderDate { get; init; }
}

public record MonthlySales(int Year, int Month, int OrderCount, decimal TotalSales, decimal AverageOrderValue);

public record ProductPairAnalysis(int ProductId1, int ProductId2, int CoPurchaseCount);
```
