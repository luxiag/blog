# OpenLayers 完全指南：企业级 WebGIS 开发实战

## 为什么选择 OpenLayers？

OpenLayers 是一个功能强大的开源 JavaScript 库，专为构建企业级 WebGIS 应用而设计。与 Leaflet 的轻量简洁不同，OpenLayers 提供了更全面的 GIS 功能。

**OpenLayers 的核心优势：**

- 🌍 **多投影支持**：内置数十种坐标系统，支持任意投影转换
- 📊 **丰富的数据源**：WMS、WMTS、WFS、GeoJSON、KML、GPX...
- 🎨 **强大的渲染引擎**：Canvas、WebGL 双引擎，性能卓越
- 🛠️ **企业级功能**：空间查询、要素编辑、测量工具、打印导出
- 📱 **移动端优化**：触摸手势、响应式设计
- 🔧 **高度可定制**：灵活的 API，满足复杂业务需求

## 快速开始：第一个地图

让我们从最简单的示例开始，创建一个基础地图。

<CodePenDemo
  title="OpenLayers 基础地图"
  height="450px"
  code={`const BasicMap = () => {
  const mapRef = React.useRef(null);
  const mapInstanceRef = React.useRef(null);

  React.useEffect(() => {
    // 1. 创建地图视图
    const view = new ol.View({
      center: ol.proj.fromLonLat([116.4074, 39.9042]), // 北京天安门
      zoom: 10,
      minZoom: 3,
      maxZoom: 18
    });

    // 2. 创建 OSM 瓦片图层
    const osmLayer = new ol.layer.Tile({
      source: new ol.source.OSM()
    });

    // 3. 创建地图实例
    const map = new ol.Map({
      target: mapRef.current,
      layers: [osmLayer],
      view: view
    });

    mapInstanceRef.current = map;

    // 清理函数
    return () => {
      map.setTarget(null);
    };
  }, []);

  const zoomIn = () => {
    const view = mapInstanceRef.current.getView();
    view.animate({ zoom: view.getZoom() + 1, duration: 300 });
  };

  const zoomOut = () => {
    const view = mapInstanceRef.current.getView();
    view.animate({ zoom: view.getZoom() - 1, duration: 300 });
  };

  const goToBeijing = () => {
    const view = mapInstanceRef.current.getView();
    view.animate({
      center: ol.proj.fromLonLat([116.4074, 39.9042]),
      zoom: 12,
      duration: 1000
    });
  };

  const goToShanghai = () => {
    const view = mapInstanceRef.current.getView();
    view.animate({
      center: ol.proj.fromLonLat([121.4737, 31.2304]),
      zoom: 12,
      duration: 1000
    });
  };

  return (
    <div className="flex flex-col gap-3">
      <div 
        ref={mapRef} 
        className="w-full h-80 border-2 border-gray-300 rounded-lg"

**核心概念解析：**

1. **`ol.View`**：定义地图的视图（中心点、缩放级别、投影）
2. **`ol.layer.Tile`**：瓦片图层，用于显示栅格地图
3. **`ol.source.OSM`**：OpenStreetMap 数据源
4. **`ol.proj.fromLonLat()`**：将经纬度坐标转换为地图投影坐标

## 图层管理：多图层叠加

<CodePenDemo

    satellite: false,

    });

      source: new ol.source.XYZ({
        url: 'https://server.arcgisonline.com/ArcGIS/rest/services/Reference/World_Boundaries_and_Places/MapServer/tile/{z}/{y}/{x}',
        attributions: '© Esri'
      }),
      visible: layers.labels
    });

      target: mapRef.current,

## 矢量图层：点、线、面绘制

矢量图层用于显示可交互的地理要素，如标记点、路线、区域等。

**矢量要素类型：**

- **`ol.geom.Point`**：点要素（标记、POI）
- **`ol.geom.LineString`**：线要素（道路、河流）
- **`ol.geom.Polygon`**：面要素（建筑、行政区）
- **`ol.geom.Circle`**：圆形要素（缓冲区）
- **`ol.geom.MultiPoint/MultiLineString/MultiPolygon`**：多要素组合

  const drawRef = React.useRef(null);
  const [drawType, setDrawType] = React.useState('Point');

  React.useEffect(() => {
    const vectorSource = new ol.source.Vector();

    const vectorLayer = new ol.layer.Vector({

    });

      target: mapRef.current,

        new ol.layer.Tile({ source: new ol.source.OSM() }),
        vectorLayer
      ],
      view: new ol.View({
        center: ol.proj.fromLonLat([116.4074, 39.9042]),
        zoom: 12
      })
    });

    mapInstanceRef.current = map;

    // 监听要素添加
    vectorSource.on('addfeature', () => {
      setFeatureCount(vectorSource.getFeatures().length);
    });

    return () => map.setTarget(null);

            }\`}

- **Polygon**：点击多次，双击闭合
- **Circle**：点击起点，拖拽确定半径

        new ol.layer.Tile({ source: new ol.source.OSM() }),
        vectorLayer
      ],
      view: new ol.View({
        center: ol.proj.fromLonLat([116.4074, 39.9042]),
        zoom: 12
      })
    });

    mapInstanceRef.current = map;

    return () => map.setTarget(null);
  }, []);

  React.useEffect(() => {
    if (!mapInstanceRef.current || !measureType) return;

    // 移除旧的绘制交互
    if (drawRef.current) {
      mapInstanceRef.current.removeInteraction(drawRef.current);
    }

    const vectorLayer = mapInstanceRef.current.getLayers().getArray()[1];
    const source = vectorLayer.getSource();

    const draw = new ol.interaction.Draw({
      source: source,
      type: measureType === 'distance' ? 'LineString' : 'Polygon'
    });

    draw.on('drawend', (evt) => {
      const geometry = evt.feature.getGeometry();
      
      if (measureType === 'distance') {
        const length = ol.sphere.getLength(geometry);
        const output = length > 1000 
          ? (length / 1000).toFixed(2) + ' km'
          : length.toFixed(2) + ' m';
        setResult(\`距离: \${output}\`);
      } else {
        const area = ol.sphere.getArea(geometry);
        const output = area > 1000000
          ? (area / 1000000).toFixed(2) + ' km²'
          : area.toFixed(2) + ' m²';
        setResult(\`面积: \${output}\`);
      }
    });

    drawRef.current = draw;
    mapInstanceRef.current.addInteraction(draw);

    return () => {
      if (drawRef.current) {
        mapInstanceRef.current.removeInteraction(drawRef.current);
      }
    };
  }, [measureType]);

  const startMeasure = (type) => {
    setMeasureType(type);
    setResult('');
    // 清空之前的测量
    const vectorLayer = mapInstanceRef.current.getLayers().getArray()[1];
    vectorLayer.getSource().clear();
  };

  const stopMeasure = () => {
    setMeasureType(null);
    if (drawRef.current) {
      mapInstanceRef.current.removeInteraction(drawRef.current);
    }
  };

  const clearAll = () => {
    const vectorLayer = mapInstanceRef.current.getLayers().getArray()[1];
    vectorLayer.getSource().clear();
    setResult('');
  };

  return (
    <div className="flex flex-col gap-3">
      <div 
        ref={mapRef} 
        className="w-full h-80 border-2 border-gray-300 rounded-lg"
      />
      
      <div className="bg-white border-2 border-gray-300 rounded-lg p-4">
        <h3 className="font-bold mb-3 text-gray-800">测量工具</h3>
        <div className="flex gap-2 flex-wrap mb-3">
          <button 
            onClick={() => startMeasure('distance')}
            className={\`px-4 py-2 rounded transition \${
              measureType === 'distance' 
                ? 'bg-orange-600 text-white' 
                : 'bg-gray-200 text-gray-700 hover:bg-gray-300'
            }\`}
          >
            📏 测距离
          </button>
          <button 
            onClick={() => startMeasure('area')}
            className={\`px-4 py-2 rounded transition \${
              measureType === 'area' 
                ? 'bg-orange-600 text-white' 
                : 'bg-gray-200 text-gray-700 hover:bg-gray-300'
            }\`}
          >
            📐 测面积
          </button>

```javascript
    url: '/tiles/{z}/{x}/{y}.png'
  })

```

### Q3: 如何导出地图为图片？

```javascript
map.once('rendercomplete', () => {
  const mapCanvas = document.createElement('canvas');
  const size = map.getSize();
  mapCanvas.width = size[0];
  mapCanvas.height = size[1];
  const mapContext = mapCanvas.getContext('2d');
  
  Array.from(
    document.querySelectorAll('.ol-layer canvas')
  ).forEach((canvas) => {
    mapContext.drawImage(canvas, 0, 0);
  });
  
  // 下载图片
  mapCanvas.toBlob((blob) => {
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = 'map.png';
    a.click();
  });
});

map.renderSync();
```
