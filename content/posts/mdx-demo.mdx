# MDX 组件演示

这是一个 MDX 文件，可以在 Markdown 中直接使用 React 组件。

## 基础 Markdown

普通的 Markdown 语法仍然可用：

- 列表项 1
- 列表项 2
- 列表项 3

> 这是一个引用块

## 代码示例

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}

console.log(greet('World'));
```

## 使用 JSX 组件

下面是一个交互式按钮组件：

<button onClick={() => alert('Hello from MDX!')}>
  点击我
</button>

## 自定义组件

你可以在 `mdx-components.tsx` 中定义自定义组件，然后直接在 MDX 文件中使用。

<CodeRunner code="console.log('Hello from CodeRunner!');" language="javascript" />
